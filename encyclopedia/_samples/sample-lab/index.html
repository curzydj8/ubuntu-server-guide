    样例骨架：读取硬盘 SMART 信息（实验教程类）¶

    本页是实验教程模板的样例骨架：只写结构，不写成正式文章，不进导航。 本实验为只读操作，不写盘、不改配置；命令中的盘符须替换为实际设备，操作前先确认盘符。

    1. 实验目标¶

    （示例）学会用 SMART 工具读取一块硬盘的健康信息，并判断哪些字段值得关注。

    2. 实验环境¶

    • 系统 / 版本：（示例）Ubuntu 26.04，实测环境待填入
    • 所需软件：（示例）smartmontools，官方仓库安装
    • 权限要求：（示例）读取 SMART 信息需要 root 或磁盘组权限，原因是直接读设备信息
    • 风险提示：本实验只读，不改数据；但盘符写错不会造成写破坏，仍须先确认盘符再执行

    3. 实验步骤¶

    步骤 1：确认硬盘设备名¶

    lsblk

    预期结果：（待实测后填入示例输出；只认盘符，不执行写操作）

    步骤 2：读取 SMART 信息¶

    sudo smartctl -a /dev/sdX

    预期结果：（待实测后填入；重点看通电时间、重映射扇区数等字段，字段含义成文时逐项核实）

    4. 结果分析¶

    （示例结构）SMART 字段分三类：当前状态、历史累计、厂商自定义；单看一个字段下结论不可靠，要结合多个字段。

    5. 清理与恢复¶

    本实验无持久改动，无需清理。

    6. 常见失败¶

    （示例）提示权限不足：检查是否用了 sudo 或当前用户是否在磁盘组；提示设备不支持 SMART：部分虚拟盘与老设备无 SMART 数据，属正常现象。
