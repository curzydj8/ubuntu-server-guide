    CSS-02：CSS 单位与颜色、字体、背景、边框¶

    任务编号：CSS-02（网站建设与部署实战指南 · CSS 完整教程第 2 篇） 上一篇：CSS-01 CSS 基础语法与选择器；下一篇（待开始）：CSS-03 CSS 盒模型与定位。 本篇只讲单位、颜色、字体、背景、边框这五组属性，不讲盒模型与布局（那是 CSS-03）、不讲 Flex 和 Grid（那是 CSS-04、CSS-05）、不讲响应式断点设计（那是 CSS-06，clamp()、vw 的完整用法在那里再展开）。

    1. 本章目标¶

    读完并动手做完本篇，你能：

    1. 分清 px、%、em、rem、vw、vh 各以谁为基准，知道 em 为什么会“越套越大”；
    2. 用名字、十六进制、rgb()、hsl() 四种写法写出同一个颜色，并说出 rgba 的透明和 opacity 的透明有什么不同；
    3. 写出带 fallback 的字体栈，知道为什么字体列表最后总要跟一个通用字体族；
    4. 用 background 写出纯色、渐变、多层背景，知道 background-size: cover 和 contain 的区别；
    5. 用 border 写出边框、圆角，知道边框缺了 style 为什么画不出来，以及 outline 和 border 有什么不同。

    2. 适用人群¶

    • 已完成 CSS-01，知道选择器、优先级、继承，能写出简单规则的人；
    • 写过 font-size: 16px、color: red，但不知道 em 和 rem 差在哪、十六进制颜色是怎么算的人；
    • 想给卡片、按钮、标题加颜色、字体、背景、圆角，但每次都要现查写法的人。

    3. 适用系统和版本¶

    • 与 CSS-01 相同：Windows、macOS、Linux 均可，任意现代浏览器，任意纯文本编辑器。
    • CSS 版本：CSS3 及之后的标准；hsl()、rem、vw/vh、linear-gradient、border-radius 在现代浏览器里都不需要加前缀，老浏览器兼容问题本篇只在备注里提一句，不展开前缀表。

    4. 使用前提¶

    • 已完成 CSS-01，或至少知道“选择器 + 大括号 + 属性: 值;”的规则写法；
    • 知道 HTML 的语义化骨架（WEB-01），能看懂示例里的 header、main、section；
    • 知道怎么保存 UTF-8 编码的 .html 文件。

    5. 所需资源¶

    • 一台能打开浏览器的电脑，一个练习文件夹（沿用 CSS-01 的练习文件夹即可）；
    • 本篇第 10 节的完整代码；
    • 可选：浏览器的开发者工具（按 F12），用来做第 14 节的“看计算后的字号和颜色”检查，没有也不影响前三项验证。

    6. 技术原理¶

    单位：数字后面那个单位，决定了它以谁为基准¶

    CSS 里几乎所有带数字的属性都要带单位（0 例外，0 不用带单位，0px 和 0 是一样的），单位分两类：

    • 绝对单位：px 是最常用的，1px 在普通屏幕上就是 1 个物理像素点（高清屏上浏览器会按比例换算，你不用管换算细节，只记住 px 是“固定大小，不随别的元素变”）。
    • 相对单位：值是相对于某个基准算出来的，基准一变，值就跟着变。相对单位是响应式和可维护样式的基础，也是本篇的重点。

    相对单位的基准各不相同，记错基准是本篇最常见的错误来源：

    单位 基准 举例
    % 属性不同，基准不同：font-size 的 % 以父元素字号为基准；width 的 % 以包含块（父级内容盒）的宽度为基准；margin、padding 的 % 以包含块的宽度为基准（上下内边距也是按宽度算，这点很反直觉） 父元素字号 16px，子元素 font-size: 150% 就是 24px；父级宽 800px，子元素 width: 50% 就是 400px
    em 当前元素的父元素字号（用于 font-size 时）或当前元素自己的字号（用于其他属性时，比如 padding: 2em 是按自己字号算） 父元素 16px，子元素 font-size: 2em 就是 32px；再套一层 2em 就是 64px，这就是“越套越大”
    rem 根元素（html）的字号，浏览器默认 16px，全页统一基准，不随嵌套变 html 字号 16px，任何地方 font-size: 1.5rem 都是 24px，套几层都不变
    vw / vh 视口（浏览器窗口）的宽度 / 高度，1vw = 视口宽度的 1% 视口宽 1200px，width: 50vw 就是 600px；窗口一缩放，vw 的值就跟着变
    vmin / vmax 视口宽和高中较小 / 较大的那一边 做“正方形随窗口缩放”时用，本篇只提一句，CSS-06 再展开

    为什么现代网站推荐 rem 做字号、% 做宽度、vw/vh 做全屏区块？因为这三者各有各的基准，不互相干扰：改根字号，全站字号按比例变；改父级宽度，子级宽度按比例变；改窗口大小，全屏区块按比例变。em 不是不能用，而是它“按父级算”的特性在多层嵌套时容易失控，所以只在“明确想跟父级走”的小范围用，比如按钮里的图标跟按钮字号走。

    颜色：四种写法，写的是同一个东西¶

    颜色在计算机里就是红、绿、蓝三个通道的数值，四种写法只是表达方式不同：

    • 颜色名：red、blue、white、black 等，浏览器内置了 140 多个名字，好处是好记，坏处是可选的颜色太少，正式项目里很少只用名字；
    • 十六进制：#rrggbb，每两位十六进制数是一个通道，#ff0000 是纯红，#000000 是黑，#ffffff 是白；三位简写 #f00 等于 #ff0000，前提是每对数字都相同；八位写法 #rrggbbaa 最后两位是透明度，#ff000080 是半透明红；
    • rgb() / rgba()：rgb(255, 0, 0) 是纯红，rgba(255, 0, 0, 0.5) 是半透明红，最后一个数是透明度，0 是全透明，1 是不透明；现代写法也可以写成 rgb(255 0 0 / 50%)，两种写法浏览器都支持，本篇用逗号写法，兼容性最好；
    • hsl() / hsla()：按色相、饱和度、亮度描述颜色，hsl(0, 100%, 50%) 是纯红，hsl(210, 80%, 40%) 是深蓝；调颜色时改色相就能换色系，改亮度就能调深浅，比 rgb 直观，主题配色时常用。

    rgba 的透明和 opacity 的透明不是一回事：rgba(0, 0, 0, 0.5) 只让背景色半透明，文字还是不透明的；opacity: 0.5 是让整个元素（包括里面的文字、图片、子元素）都半透明。想做“半透明背景 + 不透明文字”，用 rgba 做背景，不要用 opacity。

    字体：字体栈、字号、行高¶

    字体相关的属性分两组：

    • 选字体：font-family 的值是一串字体名，用逗号分隔，浏览器从左到右试，第一个装了的就用，最后一个必须是通用字体族（serif 衬线、sans-serif 无衬线、monospace 等宽），保证前面都没装时还有兜底。中文页面常用写法是中文字体在前、英文字体在前都可以，关键是最后要有通用族，不要只写一个冷门字体名。
    • 调字形：font-size（字号）、font-weight（粗细，normal 正常、bold 加粗、数字 100～900，数字越大越粗）、font-style（normal 正常、italic 斜体）、line-height（行高，写数字比如 1.6 是按字号的倍数算，写 px 是固定值，推荐写数字，因为字号一变行高跟着变）、letter-spacing（字间距）、text-align（对齐）、text-decoration（下划线、删除线等）、text-transform（大小写转换）。

    简写 font 可以把多个字体属性写在一行，但顺序是固定的：font: [style] [variant] [weight] size[/line-height] family;，比如 font: italic bold 16px/1.6 "PingFang SC", sans-serif;，size 和 family 是必填的，顺序错了整条声明都会失效，所以新手建议先分开写，熟练了再用简写。

    背景：颜色、图片、渐变、位置、尺寸¶

    background 也是简写，分开写更清楚：

    • background-color：背景色，纯色背景只写它就够了；
    • background-image：背景图，url("images/photo.jpg") 是图片路径，linear-gradient(...)、radial-gradient(...) 是渐变，渐变在 CSS 里也算“图片”，可以和普通图片一样用；
    • background-repeat：图片平铺方式，no-repeat 不平铺、repeat 平铺、repeat-x 只横向平铺；
    • background-position：图片位置，center、top、left bottom、50% 50% 都是合法写法；
    • background-size：图片尺寸，cover 是“铺满整个区域，多余部分裁掉”，contain 是“完整显示整张图，区域可能留白”，做封面图用 cover，做完整展示用 contain；
    • background-attachment：scroll 跟着页面滚，fixed 固定不动（做视差效果时用，移动端支持不好，慎用）。

    多层背景就是 background-image 里用逗号写多个图，第一层在最上面，比如渐变遮罩 + 图片的组合，CSS-07 讲高级效果时再展开。

    边框：宽度、样式、颜色，缺一个都不行¶

    边框分开写是三条：border-width（粗细）、border-style（样式）、border-color（颜色），简写 border: 1px solid #999999; 是一次性写全三条。缺了 style，边框画不出来：border: 1px #999999; 只有宽度和颜色，没有样式，浏览器默认样式是 none，等于没写边框——这是新手最常见的“边框怎么不显示”原因。

    • border-style 的值：solid 实线、dashed 虚线、dotted 点线、double 双线、none 无边框；
    • 单边边框：border-top、border-right、border-bottom、border-left，只画一边时用；
    • border-radius：圆角，border-radius: 8px 是四个角都是 8px，border-radius: 50% 在正方形上是圆形，在长方形上是椭圆，做头像、圆形按钮时常用；
    • outline 和 border 的区别：outline 是轮廓线，画在边框外面，不占布局空间，不影响别的元素位置，主要用来做键盘焦点指示（按 Tab 时那个框就是 outline）；border 是边框，占布局空间。不要为了“好看”把 outline: none 全删掉，删了键盘用户就看不到焦点在哪了，WEB-03 讲过这个原则。

    7. 架构说明¶

    本篇完整示例的页面结构，仍然是 CSS-01 的骨架，只在 main 里加了四节，每节演示一组属性：

    header（标题：演示字体简写和颜色）
main
├── section#units（单位：rem 不随嵌套变，em 越套越大，对照演示）
├── section#colors（颜色：四种写法写出同一个红，对照演示）
├── section#fonts（字体：字体栈、字号、行高、字间距）
└── section#card（背景与边框：一张带渐变背景、圆角边框的卡片）
footer（页脚）

    四节之间没有依赖关系，可以单独拿出来用：只要单位，就复制单位那一节；只要卡片，就复制卡片那一节。每一节内部也是独立的，删掉一节不影响另外三节。

    12. 每个关键属性的解释¶

    单位¶

    单位 基准 适用场景 容易错的地方
    px 固定，不随别的元素变 边框粗细、小图标、固定尺寸 全站字号都用 px，用户调大浏览器字号时页面字号不变，无障碍上吃亏
    % 属性不同基准不同：字号按父级字号，宽度按父级宽度，内外边距按父级宽度 宽度、布局比例 以为内外边距的 % 是按高度算，其实是按宽度算，上下内边距写 % 时尤其容易错
    em 父级字号（用于字号时）或自己字号（用于其他属性时） 明确想跟父级走的小范围，比如按钮内图标跟按钮字号走 多层嵌套越套越大，1.5em 套两层就是 2.25 倍，不是 1.5 倍
    rem 根元素 html 的字号，全页统一 全站字号、间距，改根字号全站按比例变 忘了 html 默认是 16px，或者在某处改了 html 字号，全站 rem 都跟着变了还不知道为什么
    vw / vh 视口宽 / 高 全屏区块、横幅、大标题 手机浏览器地址栏收起展开时，vh 的值会跟着变，100vh 在手机上可能比可视区高，CSS-06 再讲这个坑
    vmin / vmax 视口宽高中较小 / 较大的一边 正方形随窗口缩放 用的少，知道有这个单位就行，不用现在背

    颜色¶

    写法 示例 说明
    颜色名 red、white、black 好记，可选太少，正式项目少用
    十六进制 #ff0000、#f00、#ff000080 每两位是一个通道，三位简写前提是每对数字相同，八位最后两位是透明度
    rgb() / rgba() rgb(255, 0, 0)、rgba(255, 0, 0, 0.5) 最后一个数是透明度，0 全透明，1 不透明；rgba 只让颜色透明，不让整个元素透明
    hsl() / hsla() hsl(0, 100%, 50%)、hsla(210, 80%, 40%, 0.8) 色相、饱和度、亮度，调色系改色相，调深浅改亮度，主题配色常用
    currentColor border-color: currentColor 取当前文字颜色做边框色，文字颜色一变边框跟着变，做主题时省事
    transparent background-color: transparent 全透明，和 rgba(0, 0, 0, 0) 等价

    字体¶

    属性 作用 容易错的地方
    font-family 字体栈，从左到右试，最后必须是通用字体族 只写一个冷门字体名，别人电脑没装就 fallback 到浏览器默认字体，效果全变
    font-size 字号 全站字号都用 px，无障碍上吃亏；推荐正文字号用 rem
    font-weight 粗细，normal、bold、100～900 数字粗细要字体本身支持，字体没有 900 那个档，浏览器会用最接近的档模拟，不是真的 900
    font-style normal、italic 斜体 中文字体很多没有真正的斜体，浏览器会用算法把字斜着显示，效果不如英文字体斜体自然
    line-height 行高，写数字是按字号倍数，写 px 是固定值 写 px 行高，字号一变行高不变，行距就挤了；推荐写数字，比如 1.6
    letter-spacing 字间距 中文段落字间距调太大，阅读会断断续续，标题可以调大，正文保持默认或微调
    text-align 对齐，left、center、right、justify 中文正文用 justify 两端对齐时，最后一行字间距会被拉大，效果不一定好，正文推荐左对齐
    text-decoration 下划线、删除线等 链接默认有下划线，删掉下划线要同时保证链接还能被认出来（比如加颜色），否则无障碍上吃亏
    font 简写 一行写多个字体属性，顺序固定 顺序错了整条失效，size 和 family 必填，新手建议先分开写

    背景¶

    属性 作用 容易错的地方
    background-color 背景色 只写颜色不写图片，就是纯色背景，最常用
    background-image 背景图，url() 或渐变 渐变也算图片，可以和普通图片一起写多层背景，第一层在最上面
    background-repeat 平铺方式，no-repeat 最常用 忘了写 no-repeat，小图会在区域里平铺成一片，效果全变
    background-position 图片位置，center、50% 50% 等 位置是按区域算的，不是按图片本身算的，写 center 是图片居中于区域
    background-size 图片尺寸，cover 铺满裁掉多余，contain 完整显示可能留白 封面图用 cover，完整展示用 contain，两个反过来用效果就错了
    background 简写 一行写多个背景属性 顺序不固定但容易漏写，漏了 no-repeat 或 size 效果就变了，新手建议先分开写

    边框¶

    属性 作用 容易错的地方
    border-width / border-style / border-color 边框粗细 / 样式 / 颜色 缺 style 就没边框，这是本篇最常见的“边框怎么不显示”原因
    border 简写 border: 2px solid #1a5276; 一次写全三条 顺序是宽度、样式、颜色，样式不能省
    border-top 等单边 只画一边 四边都写和单边混写时，后写的会盖掉先写的，按顺序检查
    border-radius 圆角，8px 四角同圆，50% 正方形变圆形 长方形上 50% 是椭圆不是圆形，做圆形头像要先保证元素是正方形
    outline 轮廓线，画在边框外面，不占布局空间 和 border 混淆：outline 不影响布局，border 影响布局；不要全站删 outline，键盘焦点就看不到了

    15. 常见错误¶

    错误 现象 改法
    em 多层嵌套越套越大 内层字号比预想的大很多 改用 rem，或者只在小范围用 em，不要全站用 em 做字号
    % 的基准记错 宽度、内外边距算出来的值和预想的不一样 字号 % 按父级字号，宽度 % 按父级宽度，内外边距 % 按父级宽度（上下也是按宽度）
    十六进制抄错 颜色和预想的不一样，比如红变紫 #ff0000 是红，#ff00ff 是紫，抄的时候一位一位对
    rgb 数值超出 0～255 浏览器按边界值处理，颜色和预想的不一样 三个数都控制在 0～255 之间
    字体栈没有通用族兜底 别人电脑没装那个字体，效果全变 最后加 serif、sans-serif 或 monospace
    font 简写顺序错 整条字体声明失效，字号字体全没变 按“style variant weight size/line-height family”顺序写，size 和 family 必填，顺序错了就分开写
    line-height 写死 px 字号一变，行距挤了或空了 行高写数字，比如 1.6，按字号倍数算
    边框漏了 style 边框画不出来 border 必须有样式，1px solid #999999 三个都要有
    背景图忘了 no-repeat 小图平铺成一片 背景图默认是平铺的，不想平铺就写 no-repeat
    cover 和 contain 用反 封面图留白了，或完整图被裁掉了 封面铺满用 cover，完整显示用 contain
    全站删 outline 键盘用户按 Tab 看不到焦点 不要删 outline，想改样式可以改颜色和粗细，但要保证焦点看得见
    opacity 当背景透明用 文字也跟着半透明了 半透明背景用 rgba 做背景色，不要用 opacity

    16. 故障排查¶

    • 字号和预想的不一样：先看单位是 px、em 还是 rem，再按第 12 节的基准算一遍；em 的多层嵌套要一层一层算，不要直接按根字号算。
    • 颜色和预想的不一样：先查十六进制和 rgb 的数值，再查是不是被更高优先级的规则盖住了（CSS-01 的优先级算法），再查是不是 opacity 把整个元素变透明了。
    • 字体没变：先查字体栈里的字体名拼写，再查是不是被 font 简写顺序错导致整条失效，再查浏览器是不是 fallback 到了默认字体（开发者工具里看计算样式的 font-family 是哪个生效了）。
    • 背景图不显示：按 WEB-02 的图片排查顺序查：文件名拼写、大小写、相对路径；再查 background-repeat、background-size 是不是把图缩没了或裁没了。
    • 边框不显示：先查 style，再查颜色是不是和背景色一样（比如白边框在白背景上看不见），再查是不是被 border: none 在后面盖住了。
    • 改了 CSS 刷新没变：确认保存了，再按 Ctrl+F5 强制刷新，排除浏览器缓存。

    17. 安全注意事项¶

    • CSS 本身不能直接偷数据、不能运行脚本，但从不可信来源引入的外部样式表仍然有风险，CSS-01 第 17 节讲过，正式网站只引用自己站内或可信 CDN 的样式表。
    • 颜色对比度是无障碍的一部分（WEB-03 讲过）：正文文字和背景的对比度至少 4.5:1，浅灰文字放在白背景上看着“高级”，实际上很多人看不清，不要为了好看牺牲可读性。
    • 不要把真实用户的隐私信息写进示例代码里，颜色值、字号这些占位数据就够了。

    18. 回滚和恢复¶

    本篇和 CSS-01、WEB 系列一样，没有服务器、没有数据库、没有配置改动，回滚就是：

    • 改错了：编辑器里 Ctrl+Z 撤销，或把第 10 节的完整代码重新复制覆盖一次；
    • 根字号改错了：把 html 的 font-size 改回 16px，rem 的段落就回来了；
    • 文件删错了：重新新建 units-colors.html，把第 10 节代码再贴一遍；
    • 没有任何线上内容会被影响，因为本篇文件只在你的练习文件夹里，还没有部署到 crozz.me。
