    JS-01：JavaScript 基础完整教程¶

    任务编号：JS-01（网站建设与部署实战指南 · JavaScript 完整教程第 1 篇） 上一篇：CSS-16 同一页面需求的多框架对照实战；下一篇：JS-02 DOM、事件、异步。 本篇只讲 JavaScript 语言本身的基础：变量、数据类型、运算符、条件与循环、函数、对象、数组。不讲 DOM 查找与操作、事件监听、异步、模块（那是 JS-02），不讲 TypeScript（那是 JS-03）。第 10 节示例里只用两三个固定写法把结果写到页面上，那只是“让结果可见”的手段，不展开讲 DOM，本篇不要求你学会 DOM。

    1. 本章目标¶

    读完并动手做完本篇，你能：

    1. 用 let 和 const 声明变量，并说清什么时候用哪一个、为什么现在不推荐用 var；
    2. 分清字符串、数字、布尔值、null、undefined、对象、数组这几类数据，并说出 typeof 能测出什么、测不出什么；
    3. 用算术、比较、逻辑运算符写出正确的表达式，知道 === 和 == 的区别；
    4. 用 if、switch、for、while 控制程序往哪走、重复做几次；
    5. 写函数声明和箭头函数，并说清参数、返回值、作用域是什么意思；
    6. 用对象表示一条记录、用数组表示一组记录，并用 map、filter、reduce 等常用方法算出结果；
    7. 把第 10 节的完整示例页在浏览器里打开，看到算出来的结果显示在页面上，而不是只停留在控制台。

    2. 适用人群¶

    • 已完成 WEB-01～WEB-03，能写出语义化 HTML 页面，也学过 CSS-01，知道页面由 HTML 结构和 CSS 样式组成，但还没写过 JavaScript 的人；
    • 以前复制过 JavaScript 代码、页面能动，但不知道变量、函数、数组到底是什么意思的人；
    • 想给自己的静态页面加一点“算一算、列一列”的能力，但还没准备学框架的人。

    3. 适用系统和版本¶

    • 操作系统：Windows、macOS、Linux 均可，本篇不涉及任何系统专属操作。
    • 浏览器：任意现代浏览器（Chrome、Edge、Firefox、Safari 的近几年版本均可），本篇示例只用最基础的语言特性，不依赖新浏览器才有的语法。
    • 编辑器：任意纯文本编辑器均可，记事本、VS Code、Sublime Text 都行，不需要装插件。
    • JavaScript 版本：本篇讲的是 ECMAScript 2015（ES6）及之后已经普及的写法，即 let、const、箭头函数、模板字符串、数组的 map、filter、reduce。这些写法在现代浏览器里都已默认支持，不需要转译、不需要构建工具。
    • Node.js：不是本篇页面的必需品，只在第 14 节用来做语法检查；任意近几年发布的 Node.js 均可，没有 Node.js 也可以跳过那一步，直接用浏览器验证。

    4. 使用前提¶

    • 已完成 WEB-01，知道 HTML 文档的基本骨架（html、head、body、标题、段落、列表）是什么意思，能自己新建一个 .html 文件并在浏览器里打开它。
    • 学过 CSS-01 会更好（能看懂示例里少量样式是干什么的），但不是必需的：本篇示例里的样式只有几行，只负责让输出结果排得整齐，不懂也能照抄。
    • 知道怎么在浏览器里按 F12 打开开发者工具、看控制台有没有红色报错即可，不需要会用断点调试。

    5. 所需资源¶

    资源 说明 是否必需
    现代浏览器 打开示例页、看页面上的输出结果、看控制台报错 必需
    纯文本编辑器 写 .html 文件 必需
    一个空文件夹 放本篇的练习文件，建议命名为 js-basics 必需
    Node.js（可选） 只用来跑 node --check 做语法检查 可选，没有也能学完本篇
    网络 本篇示例全部离线可跑，不需要联网、不需要引 CDN 不需要

    6. 技术原理¶

    JavaScript 是运行在浏览器里的编程语言。HTML 负责“页面上有什么”，CSS 负责“长什么样”，JavaScript 负责“算什么、变什么”。浏览器打开一个页面时，会按从上到下的顺序先读 HTML，读到 script 标签时就执行里面的 JavaScript 代码，执行完再继续往下读。本篇把 script 写在 body 的末尾，就是为了让它执行时，页面上的输出容器已经存在。

    本篇只涉及同步执行，也就是代码按书写顺序一行一行往下跑，上一行算完才跑下一行。事件循环、定时器、网络请求这些异步机制一律不在本篇讲，它们在 JS-02。

    还有两个一开始就要建立的概念：

    • 动态类型：同一个变量名，先后可以装不同类型的值，JavaScript 不会在声明时把类型定死。好处是写起来快，代价是类型错了要到运行时才暴露，所以本篇会反复提醒你用 typeof 和控制台去核对。
    • 值与引用：数字、字符串、布尔值是按值传递和比较的，改一个不影响另一个；对象和数组是按引用传递的，两个变量指向同一个对象时，改其中一个，另一个看到的也是改过的样子。第 15 节有这方面的典型错误。

    7. 架构说明¶

    本篇的练习只有一个文件、一个结构，不需要脚手架、不需要分包：

    部分 在文件里的位置 作用
    HTML 骨架 文件开头到 body 结束前 标题、说明文字、装输出结果的容器
    输出容器 body 里的 ul 和 p 脚本把算出来的结果一行一行写进这里
    样式 head 里的 style 只有几行，让页面不至于全是默认样式
    脚本 body 末尾的 script 本篇的全部 JavaScript 代码：数据、计算、输出

    数据流向只有一条线：写死在脚本里的数据（学生名单和分数）→ 函数和数组方法算出总分、平均分、及格名单 → 输出语句把结果写到页面容器里。没有网络请求，没有用户输入，没有事件监听，所以结果每次打开都一样，这正是初学时最容易验证的状态。

    关于 DOM 要说清边界：第 10 节示例里出现的 document.getElementById 和 textContent 只是“把结果显示到页面上”的固定写法，你照抄就能用。本篇不讲它们背后的查找规则、节点关系、事件绑定，那些是 JS-02 的内容；现在不需要你理解为什么是这个写法，只需要知道“结果要显示在页面上，就用这一套写法”。

    8. 操作前检查¶

    动手之前，先逐项打勾，缺哪项补哪项：

    • [ ] 能新建一个文件夹，并在里面新建一个以 .html 结尾的文件；
    • [ ] 知道怎么用浏览器打开本地 .html 文件（双击文件，或把文件拖进浏览器窗口）；
    • [ ] 知道怎么按 F12 打开开发者工具、找到控制台（Console）面板；
    • [ ] 编辑器保存文件时用的是 UTF-8 编码（现代编辑器默认就是，不用特意改；记事本保存时注意编码栏不要选成 ANSI，否则中文会乱码）；
    • [ ] 示例文件里的 <meta charset="UTF-8"> 一行没有被删掉，它是中文正常显示的保证。

    9. 逐步操作¶

    1. 新建文件夹 js-basics，在里面新建文件 index.html。
    2. 先写 HTML 骨架：doctype、中英文本编码 UTF-8、标题、一个一级标题、一段说明文字、一个装结果的 ul（给它一个 id，例如 output）和一个装汇总的 p（例如 summary）。
    3. 在 body 的末尾写 script 标签，脚本先放最简单的数据：用 const 声明一个学生数组，每个学生是一个对象，有姓名和分数两个属性。
    4. 在脚本里用 let 声明几个会变化的量（例如总分、及格人数），用 for 循环或 reduce 把总分算出来，再算平均分。
    5. 写一个判等级的函数：分数大于等于 90 是优秀，大于等于 60 是及格，否则是不及格；再用 map 或循环把每个学生的等级算出来。
    6. 用 filter 筛出及格的学生，用 map 取出他们的姓名，拼成汇总语句。
    7. 用输出语句把每一条结果写进 ul，把汇总写进 p，保存文件。
    8. 双击 index.html 在浏览器里打开，核对页面上的结果是不是第 13 节列出的样子；如果不是，按第 16 节的表逐项排查。改动数据（例如改一个分数）后保存、刷新页面，看结果跟着变，这一步做完才算真正跑通过。

    10. 完整代码¶

    下面是完整示例页，没有省略号，整段复制到 js-basics/index.html 就能打开。注意：全文只有这一个带围栏的 HTML 代码块，其他地方的代码一律只写在行内或表格里，免得把错误示例和正确示例混在一起。

    <!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>JavaScript 基础练习：学生成绩统计</title>
<style>
body { font-family: sans-serif; line-height: 1.8; margin: 2em; }
li { margin: 0.3em 0; }
</style>
</head>
<body>
<h1>学生成绩统计</h1>
<p>下面的结果是由页面里的 JavaScript 算出来的，不是手写在 HTML 里的。</p>
<ul id="output"></ul>
<p id="summary"></p>
<script>
const students = [
  { name: "小林", score: 92 },
  { name: "小陈", score: 78 },
  { name: "小何", score: 58 }
];
function gradeOf(score) {
  if (score >= 90) {
    return "优秀";
  } else if (score >= 60) {
    return "及格";
  } else {
    return "不及格";
  }
}
const total = students.reduce(function (sum, student) {
  return sum + student.score;
}, 0);
const average = total / students.length;
const passed = students.filter(function (student) {
  return student.score >= 60;
});
const passedNames = passed.map(function (student) {
  return student.name;
});
let statusText = "仍有学生不及格";
if (passed.length === students.length) {
  statusText = "全部学生及格";
}
const output = document.getElementById("output");
students.forEach(function (student) {
  const item = document.createElement("li");
  item.textContent = student.name + "：" + student.score + " 分，" + gradeOf(student.score);
  output.appendChild(item);
});
const summary = document.getElementById("summary");
summary.textContent = "共 " + students.length + " 名学生，总分 " + total + "，平均分 " + average + "；及格 " + passed.length + " 人：" + passedNames.join("、") + "。" + statusText + "。";
const showInConsole = "总分 " + total + "，平均分 " + average;
console.log(showInConsole);
</script>
</body>
</html>

    文件 存放路径 说明
    index.html js-basics/index.html（你自建的练习文件夹内） 本篇的全部内容：HTML 骨架、少量样式、全部脚本都在这一个文件里

    12. 每个关键配置项的解释¶

    这里的“配置项”就是第 10 节里每个关键写法是干什么的，逐项说明：

    写法 作用 容易错的地方
    <meta charset="UTF-8"> 告诉浏览器按 UTF-8 解码，中文才不乱码 删掉或写错编码名，中文变乱码
    script 写在 body 末尾 执行脚本时，ul 和 p 已经存在，脚本才能找到它们 写在 head 里又不加延迟写法，脚本找不到容器就报错
    const students = [...] 声明一个不会被重新赋值的数组变量 const 不是“里面的内容不能改”，数组照样能 push，不能改的是变量本身指向谁
    let 声明会被重新赋值的变量 本篇示例里 statusText 先给一个默认值、满足条件时再改一次，所以必须用 let；只赋值一次的量用 const
    var 老写法，本篇不用 var 没有块级作用域、声明会被提升，容易在循环和条件里埋错，所以新代码一律用 let 和 const
    === 严格相等：类型和值都相同才算相等 用 == 会先做类型转换，例如 0 == false 是 true，容易埋错；本篇一律用 ===，比较大小用 >=、<
    if / else if / else 按条件走不同分支 只写 if 不写 else 时，不满足条件的分支什么都不做，这是正常的，不是漏写
    function gradeOf(score) 函数声明：给一段计算起个名字，传分数进去、返回等级 忘记 return 时，函数返回的是 undefined，不是 0，也不是空字符串
    箭头函数，例如 (x) => x * 2 更短的函数写法，常配合 map、filter 使用 箭头函数用大括号包住函数体时，必须自己写 return，不写就没有返回值
    students.map(...) 对数组每个元素做一次变换，返回一个新数组，原数组不变 把 map 当成循环用、又不收它的返回值，是浪费；只想循环、不需要新数组时用 forEach
    students.filter(...) 按条件筛出符合的元素，返回一个新数组，原数组不变 回调里返回的不是布尔判断，而是别的值，容易筛错
    students.reduce(...) 把数组“折叠”成一个值，例如总分，第二个参数是初始值 忘记写初始值 0 时，第一次累加会拿第一个元素当初始值，空数组还会直接报错
    students.forEach(...) 对每个元素执行一次操作，不返回新数组 在 forEach 里 return 只会结束本次回调，不会结束整个循环，更不会返回值
    document.getElementById("output") 按 id 找到页面上的容器，本篇只把它当固定写法用 id 写错一个字母就找不到，拿到的是 null，再往下写就会报错；DOM 的系统讲解在 JS-02
    textContent 把纯文本写进元素，不解析成 HTML 需要显示用户输入的内容时，千万不要换成 innerHTML，原因见第 17 节
    模板拼接，例如 "共 " + n + " 名" 把变量拼进一句话里 数字和字符串用 + 相连时，数字会被转成字符串，例如 "5" + 3 是 "53"，不是 8

    13. 执行结果示例¶

    在浏览器里打开 js-basics/index.html，页面上应该出现下面这些内容（顺序和文字都应该一致）：

    • 标题：学生成绩统计
    • 说明：下面的结果是由页面里的 JavaScript 算出来的，不是手写在 HTML 里的。
    • 列表第 1 行：小林：92 分，优秀
    • 列表第 2 行：小陈：78 分，及格
    • 列表第 3 行：小何：58 分，不及格
    • 汇总行：共 3 名学生，总分 228，平均分 76；及格 2 人：小林、小陈。仍有学生不及格。

    算数核对：总分 92 + 78 + 58 = 228，平均分 228 / 3 = 76，及格线 60 分，92 和 78 及格、58 不及格，所以及格 2 人。如果你的页面显示的不是这组数字，先不要改数据，按第 16 节排查，确认是代码抄错了还是数据被改动了。

    按顺序做完下面 5 步，全部通过才算本篇过关：

    1. 双击 index.html，浏览器打开后能看到第 13 节列出的 3 条列表和 1 条汇总，文字一字不差。

    15. 常见错误¶

    错误 现象 原因
    用 var 声明循环变量 循环结束后变量还在外面“漏”出来，后面的代码误用它 var 没有块级作用域；改用 let
    用 == 比较 0 == false、"" == false 居然是 true，判断走偏 == 会先做类型转换；比较一律用 ===
    在 if 里写成单个 = 条件永远成立，分支永远走同一条 = 是赋值，=== 才是比较；if (score = 90) 是把 90 赋给 score，不是比较
    箭头函数大括号里忘写 return map 出来的数组全是 undefined 大括号写法不会自动返回；要么写 return，要么去掉大括号用单表达式写法
    const 数组被“改了”就以为报错 以为 const 数组不能 push，其实能 const 锁住的是变量指向，数组内容照样能改；不想让人改内容要另外处理，本篇不展开
    两个变量指向同一个对象，改一个、另一个也变了 以为复制了一份，其实是同一份 对象和数组是引用类型，赋值只是多了一个指向同一份数据的名字
    字符串和数字用 + 相加 "5" + 3 得到 "53"，不是 8 + 遇到字符串就做拼接；要做加法先确认两边都是数字
    循环多跑或少跑一次 数组最后一个元素没处理，或多出一个 undefined 循环条件写成 i <= 数组长度 而不是 i < 数组长度，下标从 0 开始、最大是长度减 1
    函数忘写 return 拿到的是 undefined，再往下算就出 NaN 函数里算完不 return，结果就丢了
    用 innerHTML 显示拼接出来的文本 本来只是想显示文字，却可能被解析成标签 innerHTML 会解析 HTML；显示纯文本一律用 textContent
    reduce 忘写初始值 空数组直接报错，非空数组结果也可能差一个元素 reduce 的第二个参数就是初始值，累加求和时写 0

    16. 故障排查¶

    现象 先查什么 办法
    页面打开是空白的，只有标题 控制台有没有红色报错；script 标签有没有闭合；id 有没有写错 按报错指出的行号去找；id 必须和脚本里写的一模一样，大小写也不能差
    页面上只有说明文字，没有列表和汇总 脚本是不是写在了 body 末尾；文件是不是保存了 没保存就刷新，浏览器看到的还是旧文件；确认编辑器左下角没有“未保存”的提示
    改了分数，刷新后结果不变 是不是改错了文件（例如改的是备份）；浏览器是不是看了缓存 确认改的是正在打开的那个 index.html；强制刷新一次（Windows 按 Ctrl + F5，macOS 按 Command + Shift + R）
    控制台出现 Uncaught SyntaxError 报错后面的行号附近：括号、大括号、引号有没有成对 从报错行往上找最近一个没闭合的括号或引号，补上；一次只改一处，改完刷新再看
    控制台出现 Cannot read properties of null 脚本里 getElementById 拿到的东西是不是 null 说明 id 写错了，或者脚本写在了容器出现之前；核对 id，并确认脚本在 body 末尾
    结果出现 NaN 参与计算的是不是数字 在控制台用 typeof 查那个变量；字符串分数要先转成数字再算，不要直接拿字符串做加法
    结果出现 undefined 函数有没有 return；对象属性名有没有写错 属性名错一个字母，取到的就是 undefined；核对对象定义里的属性名
    中文显示成乱码 <meta charset="UTF-8"> 在不在；文件保存编码是不是 UTF-8 两项都确认，缺哪项补哪项，保存后刷新
    控制台报错指向某一行，但那行看起来没错 往上找 很多语法错误是前面少了括号或引号，报错行只是浏览器“发现不对”的地方，不是错误本身的位置

    17. 安全注意事项¶

    • 显示文本用 textContent，不要用 innerHTML 拼用户能改动的内容。innerHTML 会把字符串解析成 HTML，别人能往里面塞标签乃至脚本，这是最常见的初级漏洞；本篇示例从头到尾都用 textContent，养成这个习惯。
    • 不要把密码、密钥、Token 写进前端 JavaScript。浏览器里的代码任何人都能打开看到，写进去就等于公开；需要密钥的调用要走后端，本篇不涉及后端调用，所以本篇示例里不应该出现任何密钥。
    • 不要直接复制来路不明的代码就往自己页面里粘，先看懂它在做什么、会不会往外发数据；看不懂的先不要用。
    • 不要用 eval 执行字符串形式的“代码”。本篇的计算全部用正常的运算符和函数就能完成，不需要 eval，它的风险远大于便利。
    • 本篇示例的数据是写死在文件里的演示数据，不要把真实的他人姓名、分数、联系方式放进公开的练习页。
