## 维护约定

- **跟随 LTS 节奏**：内容以 Ubuntu 22.04 / 24.04 LTS 为基线；下一个 LTS 发布后一个季度内完成全站命令复核与版本标注迁移，EOL 版本内容标注「已停止维护」而非直接删除。
- **准确性优先**：命令与版本信息以 Ubuntu 官方文档、各项目官方文档为准；发现错误请用每页右上角的「编辑此页」直接提 PR，或到仓库开 Issue。
- **安全红线**：全站示例只用文档段 IP（192.0.2.0/24、198.51.100.0/24）与占位符凭据；脚本类内容一律提示「先下载审阅再执行」。

## 参与方式

发现命令错误、版本过时或想补充章节：用每页的「编辑此页」直接提 PR，或到仓库 [curzydj8/ubuntu-server-guide](https://github.com/curzydj8/ubuntu-server-guide) 开 Issue。
