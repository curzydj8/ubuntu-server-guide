# 更新日志

本站的版本记录与维护约定。

### 2026-10-21 · 第一期扩展：对标官方文档与 CIS 基线（v6.0）

- **内容补强 8 项**：09 部分新增《邮件服务器：Postfix + Dovecot 与送达四件套》（含云厂商 25 端口限制与中继备选路线）；04 部分新增《DNS 进阶与 DNSSEC》，03 部分《挂载与存储共享》增补 Samba 深化（权限映射、凭据保护、配额、回收站、审计）与 NFS Kerberos 选项，04 部分《时间同步与系统日志》增补时间同步深化（选型、漂移与对 TLS/复制/Kerberos 的连锁影响）；02 部分新增《企业身份认证：LDAP、Kerberos 与 SSSD》《CIS 安全基线审计》《自动安全更新：unattended-upgrades》；01 部分新增《云初始化与无人值守安装：cloud-init 与 Autoinstall》。
- **新增「参考索引」组**：术语表、命令索引（汇总第 15 部分 79 个速查条目）、端口与协议目录、配置文件索引、内容贡献规范，随正文长期维护。
- [版本兼容与验证状态](compatibility.md)逐章状态表已追加本期全部新章与索引组行；新增内容在 22.04 / 24.04 为「文档核对」，26.04 一律保持「待核验」。

### 2026-10-21 · 正式上线

本站于 2026-10-21 正式上线：第一轮线上审查与第二轮专业审计整改均已通过，[版本兼容与验证状态](compatibility.md)页同步上线并补齐逐章验证状态表；Ubuntu 26.04 因实测环境暂不可用，全站如实标注「待核验」，待环境恢复后逐章核验升级。

### 2026-10-21 · 增补第 14、15 部分：SSH 专题与 Linux 命令速查手册

- 新增 **14 SSH 专题：连接、密钥与隧道**（6 章）：SSH 原理与服务端安装、连接与客户端配置、密钥/Agent 与轮换、文件传输与远程执行、隧道与跳板机、故障排查与安全加固要点，与第 02 部分服务端加固互链分工。
- 新增 **15 Linux 命令速查手册**（6 章）：按文件权限、软件包服务、网络诊断、磁盘进程、文本归档、定时容器系统分组的结构化速查条目（用途/语法/参数/示例/输出/错误/风险），危险命令单独警示。
- [互动工具](tools/index.md)新增 **SSH 命令生成器**：按命令类型（登录、上传、下载、三种端口转发、调试、跳板机）动态生成命令，含输入校验、复制提示与私钥安全提醒。
- [版本兼容与验证状态](compatibility.md)逐章状态表已追加 14、15 全部章节行；26.04 一律保持「待核验」。

### 2026-10-21 · 第二轮专业审计整改（工作流 A：版本兼容性体系）

### 2026-10-21 · 第二轮专业审计整改（工作流 B–F：工具安全、宝塔版本管理、补强专题、搜索实测）

- **互动工具安全整改**：Netplan 生成器默认输出改为 `/etc/netplan/99-custom.yaml`，新增动手前检查清单（查现有文件、判断 cloud-init 托管、备份、generate 校验、try 回滚）与五种模式（普通/云服务器/DHCP/静态 IPv4/双栈）；UFW 生成器新增 SSH 端口输入（永远先放行、带锁死警告）、六步编号输出、数据库与管理后台端口的最小权限动态警告。
- **宝塔章节版本管理**：安装命令与宝塔国内版/aaPanel 国际版官方安装页逐条对齐（核验日期 2026-10-21)，注明渠道参数差异与「官方未提供校验和」事实；新增安装失败日志收集与官方卸载恢复步骤；`bt` 菜单命令标注为版本相关、先看帮助再执行；Ubuntu 26.04 官方支持标注「待确认」。
- **08 部分补强**：新增 8.5《灾难恢复与系统迁移》（整机迁移、系统盘/数据盘分离恢复、SSH 密钥丢失恢复、升级失败恢复、Docker 卷恢复、RTO/RPO 与恢复演练清单）；8.2《网络故障排查》主体重构为 7 个分层案例（每案：现象→检查→判读→根因→修复→修复后验证）。
- **12/13 部分补强**：GPU 章新增四种使用方式兼容性矩阵（明确 VMware Workstation 图形加速不等同 CUDA 直通）、五层排错与「安装成功 ≠ 链路正常」验收标准；AI CLI 章安全边界扩写为完整一节（最小权限账号与 sudoers 白名单、五步命令审批、高危命令清单、审计留痕、异常恢复）。
- **站内搜索实测**：对线上搜索索引完成六项核查（中文关键词、连字符/下划线参数、代码块内词汇、结果锚点存在性、无结果零假阳性、最新章节可检索），结果随第二轮审计整改记录留存。

## 维护约定

- **跟随 LTS 节奏**：内容以 Ubuntu 22.04 / 24.04 LTS 为基线；下一个 LTS 发布后一个季度内完成全站命令复核与版本标注迁移，EOL 版本内容标注「已停止维护」而非直接删除。
- **准确性优先**：命令与版本信息以 Ubuntu 官方文档、各项目官方文档为准；发现错误请用每页右上角的「编辑此页」直接提 PR，或到仓库开 Issue。
- **安全红线**：全站示例只用文档段 IP（192.0.2.0/24、198.51.100.0/24）与占位符凭据；脚本类内容一律提示「先下载审阅再执行」。
