# RISC-V 出货量、市场份额与产业格局

> 本篇是 [RISC-V 生态](04-riscv-ecosystem.md) 的三级专题，只讲出货量、市场份额与产业格局这一个三级主题。生态总览（标准线、上游软件线、硬件产品线的结构）见总览文章，本篇不重复；指令集层面的技术对比见本站 01 域的指令集对比文章，本篇不复制。

## 1. 研究问题

“RISC-V 卖得怎么样？”是一个听起来简单、实则很容易被数字误导的问题。难处不在有没有数字，而在数字的口径各不相同：累计核数、当年出货核数、SoC 出货量、IP 授权收入、整机设备收入，讲的是五件不同的事；“市场份额”的分母是全部处理器、全部微控制器，还是只算 RISC-V 已经进入的细分市场，得出的百分比可以差一个数量级。本篇要解决的问题正是这个：读者看到一个出货量或份额数字时，怎么判断它是什么口径、能不能信、能不能和另一个数字比较。

本篇的立场在总览文章里已经定下，这里只落实到本篇：只采信可核查的公开口径；厂商预测与分析机构预测一律视为预测，不转载为事实；查不到或口径分歧的，写“以官方发布为准（待核实）”，不写会被时间打脸的绝对数字。

## 2. 基础理论

- **核（core）与 SoC**：一颗 SoC 里可以集成多个处理器核，也可以集成一个主核加若干个做控制、电源管理、I/O 的小核。统计“核数”时，一个小核和一个应用处理器核各算一个；统计“SoC 数”时，一颗芯片只算一颗。两者不可直接换算。
- **累计出货与当年出货**：累计数是历史上所有出货之和，当年数是某一年的新增量。“累计超百亿”与“当年出货几十亿”是不同量纲的说法，放在一起比较没有意义。
- **市场份额的分母**：份额 = 分子 ÷ 分母。分子是 RISC-V 的出货或收入，分母可能是全部处理器、某类微控制器、某类 CPU IP 授权市场或某类设备市场。只看百分比不看分母，等于没看。
- **IP 授权收入与设备收入**：IP 厂商收的是授权费与版税，设备厂商卖的是整机或整颗芯片。两者口径不同、量级不同，分析机构的“市场规模”数字常常混用这两个口径，读数时必须先问“这是哪一层收入”。
- **可见核与不可见核**：大量 RISC-V 核以微控制器的形式藏在 GPU、存储控制器、无线芯片、电源管理芯片内部，用户买到的产品说明书上往往不写。只看“跑操作系统的应用处理器”会严重低估 RISC-V 的实际存在；只看累计核数又会高估它在桌面与服务器市场的地位。两种误读都要避免。

## 3. 技术路线

出货量与份额数字按来源分三条线，处理方式各不相同：

- **标准组织与厂商的公开披露线**：RISC-V International 发布的里程碑总结、厂商在公开场合披露的自家出货里程碑（如某厂商称其含 RISC-V 微控制器的设备出货达到某一量级）。这类数字的可核查性最高，但仍是“自家口径”，且往往只披露累计数而不披露统计方法。
- **分析机构的研究报告线**：SHD Group 等机构发布的 SoC 出货量、收入与预测。这类报告通常是付费全文，公开渠道只能看到二手转述的摘要数字；不同机构对“RISC-V SoC”“RISC-V 市场”的定义不同，数字之间不可直接比较。本篇不转载二手摘要数字为事实，只说明口径分歧的存在。
- **媒体与自媒体的转述线**：把上述两条线的数字再加工，常见做法是去掉限定词（把“某机构预测某年”写成“某年达到”）、去掉分母（把“某细分市场占比”写成“全球占比”）、把累计数写成当年数。本篇对这类转述一律不采信，读者看到时应回查原始发布。

## 4. 产业格局

产业格局按“谁在出货、货出在什么地方、钱在哪个环节”分四层讲，不讲具体型号的选购（选购归 01 域）：

- **嵌入式与微控制器层——出货的主力**：公开资料一致的定性判断是，RISC-V 的出货量集中在嵌入式与微控制器领域，包括藏在各类设备内部的控制核。这一层是累计核数最大的来源，也是“RISC-V 已经规模化”这一判断的依据；但它不等于应用处理器市场的地位。
- **应用处理器与开发板层——生态建设的前线**：面向开发者与消费者的单板机、开发板与应用处理器 SoC 是生态可见度最高的层，也是 profile（如 RVA23）收敛兼容性的主战场。这一层的出货量级与嵌入式层不在一个量级，公开的、可横向比较的出货统计尚未建立，以官方发布为准（待核实）。
- **数据中心、汽车与 AI 加速层——正在进入、尚未定型**：厂商公开资料显示，RISC-V 正在进入服务器级处理器、汽车电子与 AI 加速器方向，代表性厂商与产品方向见总览文章第 5 节。本篇不写这一层的份额数字：各厂商的量产时间、客户与出货规模披露程度不一，尚无统一口径的公开统计，以官方发布为准（待核实）。
- **IP 与工具链环节——格局的另一半**：SiFive、Andes（晶心科技）、阿里巴巴达摩院、StarFive、Espressif 等厂商提供含 RISC-V 核的 IP 或 SoC（见总览文章第 5 节）；开源实现与商业实现并存。IP 环节的收入与 SoC 环节的收入是两层账，不能混算为“RISC-V 市场规模”。

## 5. 代表性实现与开源项目

本节不列产品清单（那是总览文章的内容），只列与出货统计直接相关的、可核查的公开披露主体：

- **RISC-V International**：标准组织，发布年度进展与里程碑总结，是累计核数等 headline 数字最常见的原始来源；其统计方法与口径细节以其官方发布为准。
- **SHD Group**：发布 RISC-V SoC 研究报告的分析机构，其数字常被媒体转述；本篇未读到其报告全文，转述数字不采信，详见第 7 节。
- **披露自家里程碑的厂商**：如高通在 2023 年 RISC-V 峰会场合披露的“含 RISC-V 微控制器的设备出货”里程碑（经 RISC-V International 2023 年里程碑总结转述），属于厂商自家口径，见第 7 节；英伟达将其 GPU 内部微控制器转向 RISC-V 的做法在公开报道中多次出现，但其具体年度核数以厂商官方发布为准（待核实），本篇不转载报道中的约数。

## 6. 关键论文与标准

本篇没有可作为出货统计依据的论文或标准：出货量与市场份额是产业统计问题，不是标准文本问题。相关的标准只有一条间接联系：profile（如 RVA23）决定了“什么样的芯片算同一类应用处理器”，从而决定了未来按类别统计出货时分母的划法。RVA23 本身的批准时间与内容见第 7 节与总览文章，不在本篇重复展开；RVA23 之后的标准演进对照归本域 33 篇。

## 7. 当前实验结果

本节不写性能数字（出货统计没有测试条件可言），只写经核查的事实与明确标为预测的说法，分开列出，绝不混写：

**经核查的公开口径（可引用）：**

- RISC-V International 在 2023 年 12 月 13 日发布的《2023 年十大里程碑》总结中称，RISC-V 已在“市场上超过 130 亿个核”中得到采用；同篇总结称其会员当时已超过 4,100 家、分布于 70 个国家，并称 2023 年批准了 16 项规范，包括 RVA20、RVI20、RVA22 的 profile 规范 1.0 版。注意：这是累计核数口径，不是当年出货量，也不是应用处理器份额；其统计方法原文未在本篇核查范围内展开，引用时应保留“据 RISC-V International 总结”这一限定。
- 同篇总结转述：高通在 2023 年披露其含 RISC-V 微控制器的设备出货达到 10 亿台量级。这是厂商自家披露的累计设备数口径，不是全行业份额，引用时应保留厂商与口径限定。
- RISC-V International《2025 年度报告》称，RVA23 profile 于 2024 年底批准，是面向运行 Linux 等操作系统的应用处理器的共同基线。RVA23 的批准是生态收敛的事件节点，不是出货数字；它对出货统计的意义在于：此后“应用处理器”这一类别有了更清晰的统计边界，但按 RVA23 口径的出货统计本身尚未见公开统一发布，以官方发布为准（待核实）。

**各口径分歧（必须明说，不采信为事实）：**

- 分析机构对 RISC-V SoC 当年出货量、设备收入与未来年份预测的数字，在公开转述中彼此量级不同：有的按 SoC 出货量计，有的按设备收入计，有的按 IP 市场计；同一家机构的不同年份报告之间口径也可能调整。本篇未读到 SHD Group 等机构的报告全文，二手转述中的具体数字（如某年出货几十亿、某年收入几千亿美元、某年占比三成以上）一律不转载为事实，以机构官方发布为准（待核实）。
- 流传的“RISC-V 全球处理器市场渗透率约 25%”一类说法，分母不清：公开讨论中已有人指出，尚不清楚该数字指的是全部微处理器还是仅指 RISC-V 已有布局的细分市场。在分母澄清之前，任何“某年占比”的说法都只能视为预测或口径不明的转述，不得作为事实引用，以官方发布为准（待核实）。
- 关于某一国家或地区占全球 RISC-V 出货量一半一类的说法，本篇只在单一二手来源中见到，未见原始统计发布，不采信，以官方发布为准（待核实）。
- 厂商关于“某年出货将达多少”“某年 SoC 数将超 200 亿”一类的说法属于路线图目标与预测，不是已发生的事实，本篇不转载为事实。

## 8. 技术瓶颈

这里的“瓶颈”不是芯片性能瓶颈，而是“出货统计本身为什么难做准”的结构性原因：

- **统计边界不清**：藏在设备内部的微控制器核往往不单独披露，厂商财报也不单列 RISC-V 核数；第三方只能靠抽样与建模估算，估算方法不同，结果就不同。
- **类别划分不统一**：嵌入式微控制器、应用处理器、加速器核在不同机构的分类里归属不同；RVA23 之前连“应用处理器”的兼容性基线都不统一，按类别统计的基础更弱。
- **付费墙**：最详细的机构报告是付费的，公开渠道只有摘要与转述；转述过程丢失限定词，是数字失真最常见的环节。
- **预测与事实的混写**：分析机构的商业模式包含预测，媒体转述时常把预测年份的数字写成现在时；读者若不核对年份与“预测”二字，就会把路线图当成现状。
- **地缘与政策变量**：不同地区对 RISC-V 的政策支持力度不同，区域出货结构会随政策变化；单一时点的区域份额数字不宜外推为长期格局。

## 9. 成熟度判断

- **成熟度：工程发展中。** 判断依据一句话：RISC-V 在嵌入式与微控制器领域的规模化出货已有可核查的公开口径（累计核数超 130 亿，见第 7 节），但应用处理器、服务器与汽车等高价值类别的统一口径出货与份额统计尚未建立， headline 份额数字分母不清，因此整体产业格局仍处工程发展中，而非“成熟应用”所要求的、可横向比较的成熟市场。

## 10. 未来研究问题

- **已有研究在做**：RVA23 基线推广后，按 profile 类别统计应用处理器出货的方法是否会建立；检验标准是标准组织或机构是否发布按 RVA23 口径划分的、可复核的统计。
- **已有研究在做**：分析机构之间统计口径的收敛——SoC 数、核数、IP 收入、设备收入四类口径是否会分开披露而不是混成一个“市场规模”。
- **本文推测**：出货统计的下一个可信节点不是“累计核数再翻一倍”，而是“某机构或标准组织发布一份方法公开、可复核的按类别年度出货统计”；在那之前，读者应把所有份额数字当作口径待查的说法处理。
- **本文推测**：随着应用处理器层出货的增长，未来“RISC-V 份额”的争论焦点会从“累计核数”转向“应用处理器与服务器类别的份额”，而后者的分母争议会比现在更大；提前讲清分母，比提前给数字更重要。
