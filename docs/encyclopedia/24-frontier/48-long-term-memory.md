# 长期记忆与持续学习

本篇是 [AI Agent 前沿总览](06-frontier-ai-agents.md) 的分支文章，只讲长期记忆与持续学习的研究侧问题。总览已把记忆层列为多智能体系统的组成部分，并指出记忆污染是多智能体特有的攻击面之一；本篇展开记忆本身：Agent 如何跨会话记住、更新与遗忘，以及为什么“记住”比“存下来”难得多。单次任务内的记忆与回溯见[推理、规划与搜索](47-reasoning-planning-search.md)，本篇讲跨会话、跨任务的长期记忆。

## 1. 研究问题

长期记忆要解决的问题是：一个 Agent 在多次交互、多个任务之后，能否保留有用的经验与知识，并在新任务中正确地调用它、更新它、丢弃过时的它？持续学习（continual learning）是同一问题的训练侧表述：模型能否在学习新任务时不遗忘旧任务，并把新旧知识整合起来？

现有方法解决不了这个问题的三个原因。第一，**存取不等于记忆**：把对话历史、文档片段存进向量数据库很容易，但“在正确的时候取出正确的一条、并以正确的方式用它”很难；取回错误、过时或被污染的记忆，比没有记忆更危险。第二，**更新与遗忘的冲突**：新知识要写进去，旧知识不能全丢，但哪些旧知识已过时、哪些仍有效，系统自己很难判定；一味追加会导致记忆膨胀与自相矛盾，一味覆盖会导致灾难性遗忘。第三，**记忆的归属与权限不清**：一条记忆来自哪个用户、哪次任务、是否还有效、谁有权删除它，在多用户、多智能体场景下尤其复杂；记忆一旦被污染，污染会通过后续取回扩散到更多任务中。

## 2. 基础理论

- **灾难性遗忘（catastrophic forgetting）**：神经网络在新任务上训练时，旧任务性能急剧下降的现象；经典解释是新任务的梯度更新覆盖了旧任务所需的参数方向。缓解思路包括正则化（如 EWC，Kirkpatrick 等人，2017）、回放旧数据、参数隔离等，但每种方法都有适用范围与代价。
- **检索增强生成（RAG）**：Lewis 等人（2020）提出，把外部知识库的检索结果作为生成条件的补充；它是今天长期记忆最常见的工程实现，但 RAG 的“记忆”是外部文档的检索，不是模型自身的知识更新，二者不可混淆。
- **记忆的心理学区分**：情景记忆（发生过什么）、语义记忆（知道什么事实）、程序记忆（会怎么做）是不同的记忆类型；Agent 记忆研究借用这一区分，但机器实现上三者的边界远不如心理学中清晰。
- **知识编辑（knowledge editing）**：研究如何在不重训整个模型的情况下，定向修改模型内部的某个事实；它与长期记忆相关，但编辑的副作用（改一处、坏一片）仍是开放问题。

## 3. 技术路线

- **外部记忆库路线**：把经验、文档、对话摘要存入向量数据库或知识图谱，需要时检索注入上下文。优点是实现简单、可审计、可删除；缺点是检索质量决定一切，且上下文窗口有限时，取回内容会挤占推理空间。
- **参数内化路线**：通过持续微调、LoRA 等方式把新知识写进模型参数。优点是调用时无需检索、响应自然；缺点是遗忘风险高、更新不可逆、难以定位某条知识存放在哪、难以按用户或权限删除。
- **摘要与提炼路线**：把长对话、多轮经验压缩成结构化摘要、规则或经验条目，再存入记忆库。优点是记忆体积小、可读性好；缺点是摘要过程会丢信息，且摘要者的偏见会固化进记忆。
- **分层记忆路线**：区分工作记忆（当前任务）、情景记忆（近期交互）、长期语义记忆（稳定知识），按不同策略读写与遗忘。优点是结构清晰、符合直觉；缺点是分层边界与晋升规则（什么值得从短期升入长期）本身就是开放问题。
- **多智能体共享记忆路线**：多个智能体读写同一记忆库，经验可共享；优点是协作效率高；缺点是污染扩散快——一个智能体写入的错误或恶意内容会被其他智能体取回并放大，见总览的安全论述与[AI 可解释性、可靠性与安全性](52-ai-explainability.md)。

## 4. 系统架构

一个研究型的长期记忆系统通常包含：

- **写入与编码器**：决定什么值得记、以什么形式记（原文、摘要、结构化条目、向量），以及附带哪些元数据（来源、时间、置信度、权限）。
- **存储层**：向量库、文档库、知识图谱或参数本身；不同存储的删除、更新与审计能力差异极大，选型时应先看“能否删、能否改、能否审计”，再看检索精度。
- **检索与排序器**：按相关性、时效性、来源可信度排序候选记忆；排序标准不公开时，记忆系统的行为不可解释。
- **融合与冲突解决器**：多条记忆冲突时怎么办（信新的、信旧的、信权威来源的、还是向用户确认）；没有冲突解决规则的系统会在记忆自相矛盾时随机表现。
- **遗忘与清理器**：按时效、价值、权限定期清理；没有清理机制的记忆库只会膨胀，检索质量随时间下降。
- **审计与删除接口**：谁读过哪条记忆、哪条记忆影响了哪次决策、用户如何要求删除自己的记忆；这是合规与安全的要求，不是可选项。

尚无代表性商用系统可以按“已解决长期记忆”来介绍：现有产品的记忆功能多为受限场景的外部检索与摘要，跨任务的知识整合与安全删除仍是研究问题。

## 5. 代表性实现与开源项目

- **向量数据库与检索框架**：如 FAISS、Milvus、Chroma 等，提供记忆存储与检索的基础设施；它们是工具，不是记忆系统本身，检索质量取决于编码、切分与排序策略。
- **记忆框架类开源项目**：学术界与开源社区有多种“Agent 记忆”框架（如带分层记忆、摘要记忆的实现），可作为研究起点；各框架的记忆语义（记什么、忘什么、何时更新）差异很大，选型时应先读其记忆模型说明，而非只看演示。
- **持续学习基准与方法库**：如 Avalanche 等持续学习研究框架，提供遗忘度量与基线方法；其基准多为图像分类等受控任务，结论向语言 Agent 的迁移需谨慎。
- **知识编辑研究代码**：ROME、MEMIT 等方法的公开实现，用于研究定向修改模型事实的可行性与副作用；它们是研究工具，不是生产级的知识更新方案。

## 6. 关键论文与标准

- Kirkpatrick 等人《Overcoming Catastrophic Forgetting in Neural Networks》（PNAS 2017，arXiv:1612.00796）：EWC 正则化方法。
- Lewis 等人《Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks》（NeurIPS 2020，arXiv:2005.11401）：RAG 范式。
- Meng 等人《Locating and Editing Factual Associations in GPT》（ROME，NeurIPS 2022，arXiv:2202.05262）与《Mass-Editing Memory in a Transformer》（MEMIT，ICLR 2023，arXiv:2210.07229）。
- 暂无公开标准：长期记忆的语义、遗忘策略、删除与审计标准均无公认标准；各产品的“记忆”功能口径不一，不可直接比较。

## 7. 当前实验结果

本节不写统一的记忆性能排名，只写定性结论：

- 持续学习研究在受控任务上反复确认：不加任何缓解措施的顺序微调，旧任务性能下降显著；加正则化、回放或参数隔离后遗忘减轻，但新任务学习速度与旧任务保留之间存在 trade-off，具体数值因任务序列与方法而异。
- RAG 类外部记忆在知识问答任务上效果明确，但效果高度依赖检索质量：取回错误文档时，模型可能比没有检索时更自信地答错；“检索到了”不等于“检索对了”。
- 知识编辑研究表明，定向修改单个事实在受控条件下可行，但编辑的泛化（同一事实的不同表述是否都改对）与特异性（无关事实是否未受影响）难以同时保证；批量编辑时副作用更明显。
- 记忆污染的公开讨论已超出理论：通过对话、文档或工具输出注入的恶意内容，可能被写入记忆并在后续任务中被取回利用；具体攻击细节与防御效果以发布方的官方披露为准，本篇不复述未经核实的案例。

所有示例均为文献与公开讨论复述，不是本站实测；本地没有 Agent 实验环境，任何记忆系统复现均属示例未实测。

## 8. 技术瓶颈

- **取回瓶颈**：相关性排序、时效判断与来源可信度评估都没有通用解；取回错误是记忆系统最常见的失效模式。
- **更新与遗忘瓶颈**：新旧知识冲突时缺乏可靠的裁决规则；参数内化路线的遗忘与副作用问题未解决。
- **规模瓶颈**：记忆量增长后，检索延迟、存储成本与冲突概率同步上升；“记一切”不是可扩展的策略。
- **安全瓶颈**：记忆污染、跨用户记忆泄露、删除不彻底（向量库删了、模型参数里还留着）是三类不同性质的问题，需要不同的防御。
- **评估瓶颈**：没有能同时度量记忆准确性、时效性、遗忘率与污染抵抗力的评估体系；单次任务基准测不出长期记忆质量。

## 9. 成熟度判断

- **成熟度：实验研究中。** 判断依据一句话：外部检索与摘要记忆已有可用工程实现，但跨任务知识整合、可靠更新与遗忘、安全删除三大问题未解决，长期记忆尚不能作为 Agent 可信的知识基础。

## 10. 未来研究问题

- **已有研究在做**：带来源与置信度的记忆表示、冲突时的向用户确认机制、记忆污染的检测与隔离。
- **已有研究在做**：参数内化与外部记忆的混合策略——什么知识值得写进参数、什么只适合存在外部库。
- **本文推测**：长期记忆可能先以“可审计、可删除的外部记忆”形态进入生产，而非以“模型自己记住一切”的形态；检验标准是产品能否公开回答“这条记忆从哪来、谁能删、删后是否还影响决策”。
