# 脉冲神经网络与类脑学习规则

本篇是总览 [神经形态计算](02-neuromorphic-computing.md) 的分支文章。总览讲“神经形态计算是什么、有哪些代表性芯片”；本篇讲算法侧：脉冲神经网络（SNN）怎么表示信息、怎么训练、以及类脑学习规则（以 STDP 为代表）到底能做什么、不能做什么。芯片侧的架构与规格见 [神经形态芯片原理](40-neuromorphic-chip-principles.md)，本篇不重复。

## 1. 研究问题

常规神经网络（ANN）训练之所以成功，很大程度上是因为反向传播：一个连续、可微的损失函数，沿着计算图把梯度一路传回每一层，权重按梯度更新。这个链条在脉冲网络里断了两处：

- **脉冲不可微**：神经元的输出是 0 或 1 的离散事件——膜电位不到阈值输出 0，一过阈值输出 1，中间没有平滑过渡。对阶跃函数求导，处处是 0、阈值处是无穷大，梯度传不下去。
- **时间是显式维度**：脉冲网络的计算发生在时间上展开：同一个神经元在不同时刻的状态互相影响，学习必须同时处理“空间（哪一层、哪一神经元）”与“时间（哪一时刻发放）”两个维度的依赖。把时间压平成一帧、或只看发放频率，都会丢掉脉冲编码里的时间信息。

于是 SNN 的核心研究问题是：在“输出离散、时间显式、硬件要求局部（片上学习不能依赖全局反向传播）”的三重约束下，有没有一种学习方法，能在通用任务上接近常规网络的精度，同时保住脉冲计算的稀疏与事件驱动优势？今天的答案是“有若干条路线，各有代价，没有一条已通用”。

## 2. 基础理论

- **脉冲编码：信息藏在哪？** 同一串脉冲可以有四种读法：频率编码（单位时间发放次数代表数值大小）、时间编码（第一次发放的时刻、或脉冲间间隔代表数值）、相位编码（相对某个参考节律的发放相位）、群体编码（多个神经元的联合发放模式）。编码方式的选择决定硬件成本：频率编码直观但需要长时间窗口统计（延迟大）；时间编码信息密度高但对时间抖动与噪声敏感；群体编码稳健但要更多神经元。没有一种编码在所有任务上都最优，编码选择本身就是模型设计的一部分。
- **LIF 神经元与膜电位动态**：见 40 篇第 2 节——膜电位积分、漏电、阈值发放、复位。算法侧要补一句：LIF 的“漏电时间常数”不是装饰，它决定了神经元的时间窗口——时间常数短，神经元只对近期的脉冲敏感（适合快速变化信号）；时间常数长，神经元能整合更久的历史（适合慢信号）。时间常数的选择与任务的时间尺度必须匹配，这在常规网络里没有对应物。
- **不应期与适应**：发放后的短暂不应期（神经元暂时不能再次发放）与发放频率适应（持续输入下发放率逐渐下降），是生物神经元的两种基本动态；算法上它们起到“限速”与“归一化”的作用，防止网络被少数高频神经元主导。简化模型常常省略它们，代价是网络动态更容易失稳。
- **突触可塑性（synaptic plasticity）**：突触权重随活动而变化的统称。分两类：短期可塑性（毫秒到秒量级，随活动暂时增强或减弱，随后恢复）与长期可塑性（分钟以上，权重持久改变，是“学习”的载体）。片上学习讨论的几乎都是长期可塑性。
- **STDP（脉冲时间依赖可塑性）**：最常引用的局部学习规则——突触前神经元在突触后神经元之前发放，连接加强（LTP）；顺序反过来，连接减弱（LTD）；加强/减弱的幅度随两者时间差的增大而指数衰减。关键在“局部”二字：权重更新只依赖它两端神经元的发放时刻，不需要全局误差信号，因此天然适合片上实现；关键也在“无目标”二字：STDP 本身不知道任务目标是什么，它只按时序因果调权重，能学出什么结构，取决于输入统计与网络结构的设计。
- **替代梯度（surrogate gradient）**：反向传播时，前向仍用真实的离散脉冲（0/1），反向把阶跃函数的导数替换成一个平滑函数（如 sigmoid 导数、矩形窗、反正切导数）的近似值，让梯度能传下去。它是“有用的近似”，不是生物机制：生物大脑里没有反向传播这条全局通路。替代梯度的代价是梯度本身是近似的，网络越深、时间步越长，近似误差累积越严重（深层梯度消失是公开讨论的问题之一）。
- **ANN–SNN 转换（ANN-to-SNN conversion）**：先在常规框架里训练好 ANN，再把权重映射到脉冲网络，用发放频率（或发放时刻）去近似 ANN 的连续激活值。转换的精度损失来自量化：连续值被离散脉冲近似，时间窗口越短、发放率越低，近似误差越大。转换法的长处是能直接复用 ANN 的训练成果与大规模预训练模型；短处是转换后的网络常常需要很长的时间窗口才能达到原精度，延迟与能效优势被时间窗口吃掉一部分。

## 3. 技术路线

按“学习信号从哪来”分四条路线：

- **局部可塑性路线（STDP 及其变体）**：权重更新只用局部时序信息，代表规则有经典 STDP、带奖赏调制的 R-STDP（全局奖赏信号乘上局部 STDP 迹，解决“无目标”问题的一部分）、三因子规则（突触前活动 × 突触后活动 × 第三因子如奖赏或新奇性，三者同时满足才更新）。这条路线最符合“片上学习”的硬件约束，也最难在有监督任务上达到高精度——局部规则没有全局目标，学出的表征质量依赖网络结构与输入统计的精心设计。
- **替代梯度直接训练路线**：把 SNN 当作沿时间展开的循环网络，用替代梯度做端到端反向传播（BPTT 的脉冲版）。这是今天在分类基准上精度最高的 SNN 训练路线，也是与常规深度学习工具链最接近的路线。代价是它在训练时并不“事件驱动”：反向传播需要保存全时间步的膜电位轨迹、做全局梯度计算，训练成本与 ANN 相当甚至更高；它的收益只在推理部署时兑现（稀疏脉冲推理），训练侧没有能效优势可言。
- **ANN–SNN 转换路线**：离线训练 ANN，转换部署为 SNN。长处是精度起点高（继承 ANN 的训练成果）；短处有三：转换需要校准（阈值、权重归一化、时间窗口）且校准对任务敏感；转换后的网络在时间维度上是“ANN 的慢动作重放”，没有真正利用脉冲的时间编码能力；对 ANN 里难以用频率近似的运算（如注意力中的 softmax、逐元素乘法），转换法要另想办法。
- **混合与储备池路线**：储备池计算（reservoir computing）只训练读出层，中间的脉冲储备池固定随机连接、靠其丰富的动态去展开输入的时间结构——训练极便宜，适合时间序列与小样本任务，但表达能力受储备池规模与随机性的制约；混合路线则把上述方法组合（例如 STDP 预训练 + 替代梯度微调，或转换初始化 + 片上 STDP 适应），用一种方法的长处补另一种的短处，代价是系统复杂度与超参数空间都翻倍。

四条路线没有胜负，只有“任务—硬件—精度”三者权衡后的选型：要片上在线适应，选局部规则；要分类精度，选替代梯度或转换；要小样本时间序列，储备池值得一试；要两者兼得，今天还没有现成答案。

## 4. 系统架构

一个 SNN 学习系统的组成（与 40 篇的芯片架构对照阅读：这里是算法与软件栈的视角）：

1. **编码层**：把常规输入（图像像素、音频采样、传感器读数）转成脉冲序列。编码方式（频率、时间、直接电流注入）是超参数，不是事后选择——同一网络换编码，精度与延迟都可能大变。事件相机输出的天然脉冲流是例外：它不需要编码层，输入本身就是事件（见 43 篇）。
2. **脉冲网络本体**：按层组织，层内神经元模型（LIF 或其变体）、层间连接（前馈、循环、侧向抑制）与时间步长（离散仿真步长，决定时间分辨率与计算量）共同定义网络。时间步长越小，时间精度越高，仿真步数与计算量越大——这是 SNN 特有的“精度—延迟—算力”三维权衡。
3. **学习模块**：按路线分三类实现——局部规则在每个突触处本地更新（适合片上微码）；替代梯度在离线框架里做 BPTT（需要保存全轨迹）；转换法在 ANN 框架里训练、在转换工具里校准。三类模块的接口互不相同，这是 SNN 工具链碎片化的根源之一。
4. **仿真与部署框架**：离线仿真（在 GPU/CPU 上按时间步推进网络）与片上部署（把网络映射到神经形态核、路由与学习引擎）是两套执行语义；仿真里成立的精度，部署后可能因权重精度、路由延迟、异步时序而变化。仿真—部署一致性是 SNN 工程化最容易被低估的一环。
5. **评估层**：精度、延迟（达到目标精度需要多少时间步）、发放率（平均每个神经元每步发放几次，决定稀疏收益）、能效（是否含主机与编码开销，见 40 篇第 8 节）四项必须同时报告；只报精度不报延迟与发放率的 SNN 结果，无法判断它是否真的兑现了脉冲优势。

## 5. 代表性实现与开源项目

只列真实存在的框架与工具；本节不列精度排名，因为不同框架、不同编码、不同时间步下的精度数字不具可比性（见第 7 节）：

- **Brian2**：用 Python 描述神经元微分方程与网络的仿真器，神经科学仿真最常用的入口之一；模型想怎么写就怎么写，适合探索学习规则与网络动态，不直接面向神经形态芯片部署。
- **NEST**：大规模脉冲网络仿真器，面向大规模脑仿真与 SpiNNaker 一类系统的模型描述；与 PyNN 接口配合，是 SpiNNaker 与 BrainScaleS 的常用模型入口。
- **PyNN**：与仿真器无关的模型描述接口——同一份网络描述可以跑在 NEST、SpiNNaker、BrainScaleS 等不同后端；它的价值在“模型一次编写、多处运行”，局限是各后端的神经元模型与精度支持并不完全一致。
- **Lava（Intel）**：随 Loihi 2 发布的开源框架，用于开发神经启发的事件驱动应用，是 Loihi 研究最常用的入口；它把“进程（process）—端口—消息”的事件驱动编程模型带到了神经形态开发里。
- **snnTorch 与 SpikingJelly**：基于 PyTorch 的 SNN 训练框架，用替代梯度做端到端训练，是今天替代梯度路线最常用的两个入口；二者的区别主要在 API 风格与支持的神经元模型、编码方式上，训练方法论（替代梯度 + BPTT）是共通的。
- **尚无统一框架**：按“同一模型、同一训练方法、能在多家神经形态芯片上部署且精度一致”的定义，今天不存在统一的 SNN 框架；框架碎片化与芯片碎片化互相强化（见第 8 节）。

## 6. 关键论文与标准

- Song, Miller 与 Abbott《Competitive Hebbian learning through spike-timing-dependent synaptic plasticity》，Nature Neuroscience 3（2000）——STDP 竞争性学习的经典论文，STDP 规则的实验与模型基础。
- Diehl 与 Cook《Unsupervised learning of digit recognition using spike-timing-dependent plasticity》，Frontiers in Computational Neuroscience 9（2015）——STDP 无监督学习在手写数字识别上的代表性工作，局部规则能做什么的参照点。
- Neftci, Mostafa 与 Zenke《Surrogate gradient learning in spiking neural networks》，IEEE Signal Processing Magazine 36(6)（2019）——替代梯度方法的综述，替代梯度“前向真实脉冲、反向平滑近似”的标准表述来源。
- Zenke 与 Ganguli《SuperSpike: Supervised learning in multilayer spiking neural networks》，Neural Computation 30（2018）——多层 SNN 有监督学习的代表性方法，替代梯度路线的重要节点。
- Sengupta 等《Going deeper in spiking neural networks: VGG and residual architectures》，Frontiers in Neuroscience 13（2019）——ANN–SNN 转换路线把深层网络（VGG、残差结构）转换到脉冲域的代表性工作。
- 暂无公开标准：SNN 没有统一的编码标准、精度折算标准或跨平台基准；同一任务在不同编码、不同时间步、不同发放率下的结果不可直接比较（见第 7 节）。

## 7. 当前实验结果

本节的立场比其他前沿文章更克制，原因在方法论：SNN 的精度数字高度依赖编码方式、时间步数、发放率与评估协议，脱离这四项的精度排名没有意义。因此本节只写方向性结论，不转载任何一方的精度榜：

- **替代梯度路线在中小规模分类基准上已接近常规网络**：在手写数字、事件相机数据集一类的中小任务上，替代梯度训练的 SNN 精度已进入“与同规模 ANN 可比”的区间；但“可比”的前提是时间步与发放率的代价——时间窗口拉长、发放率抬高时，稀疏优势会被侵蚀。精度数字本身不说明能效，精度 + 时间步 + 发放率三项齐全才说明问题。
- **STDP 无监督路线在小任务上有效、在通用任务上未达标**：Diehl 与 Cook 一类的工作证明 STDP 能在小规模无监督任务上学出有用表征；但把它扩展到深层、大规模、有监督的通用任务，至今没有稳定达到同规模 ANN 精度的公开方法。STDP 的价值今天更多在“片上在线适应”（输入分布缓慢漂移时本地微调）而非“从零训练大模型”。
- **ANN–SNN 转换在深层网络上可行、但有延迟税**：转换法能把 VGG、残差结构一类的深层 ANN 搬到脉冲域；代价是达到原精度需要的时间窗口随网络深度增长，延迟税是转换法的结构性成本，不是某个实现的 bug。
- **不写进本节的数字**：任何脱离编码、时间步、发放率、评估协议的 SNN 精度排名，以及“比 ANN 能效高 N 倍”的说法——前者不可比，后者缺统一测试条件（见 40 篇第 7 节）。读者在别处看到这类数字时，应先问这四项是否齐全。

## 8. 技术瓶颈

- **梯度近似误差随深度与时间累积**：替代梯度的平滑近似在浅层、短时间窗口时尚可接受；网络加深、时间步拉长后，近似误差累积，深层梯度消失或失真，训练稳定性下降。这是替代梯度路线扩展到大模型时首先撞上的墙。
- **局部规则的目标缺失**：STDP 不知道任务目标，学出的表征质量依赖输入统计与网络结构设计；把“无目标的局部规则”与“有目标的任务”接起来（奖赏调制、三因子规则、全局调制信号），至今没有通用解法。
- **时间维度的超参数爆炸**：时间步长、膜时间常数、阈值、不应期、编码方式、时间窗口——SNN 比 ANN 多了一整套时间维度的超参数，且它们互相耦合；调参空间大、且最优值随任务时间尺度而变，自动化调参方法尚未成熟。
- **仿真—部署不一致**：离线仿真（浮点权重、理想时序）与片上部署（低精度权重、异步路由延迟、器件偏差）之间的精度落差，是 SNN 从论文走向产品的必经之痛；没有“仿真时就考虑部署约束”的协同设计流程，论文精度到硬件精度总要打折。
- **基准与评估协议缺失**：没有统一的编码、时间步、发放率、能效归属的评估协议，跨论文、跨平台的结果不可比；研究者各报各的精度，领域整体进展难以度量。

## 9. 成熟度判断

- **成熟度：实验研究中。** 判断依据一句话：替代梯度、STDP、ANN–SNN 转换三条路线各有中小任务上的验证，但没有一条在通用任务上稳定达到同规模常规网络的精度，且仿真—部署一致性与统一评估协议均未解决。

## 10. 未来研究问题

- **已有研究在做**：可微脉冲学习的新近似——能否找到比现有替代梯度更保真、随深度衰减更慢的梯度估计？检验标准是在深层网络上精度随深度的衰减曲线是否变平缓。
- **已有研究在做**：片上持续学习（continual learning）的稳定性——在线 STDP 适应时如何不遗忘旧知识、不发散？检验标准是在输入分布漂移的长时程任务上，精度是否稳定而不崩溃。
- **已有研究在做**：ANN–SNN 转换的延迟税控制——能否在不拉长时间窗口的前提下缩小转换精度损失？检验标准是“达到原精度 99% 所需的时间步数”是否随方法改进而下降。
- **本文推测**：SNN 的第一个“杀手级”训练范式可能不是“从零训练大模型”，而是“转换初始化 + 片上局部适应”的组合——离线转换解决精度起点，片上 STDP 解决部署后的分布漂移；检验标准是是否有公开工作在真实部署场景（而非仿真）中证明该组合优于纯转换或纯离线方案。
