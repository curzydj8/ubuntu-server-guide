# 光子计算

> 本篇是 [新型计算架构：光子与存算一体](08-new-computing-arch.md) 总览下光子方向的三级展开。总览已讲光子计算的范式定位与共性瓶颈（转换开销、存储缺失），本篇讲光子计算本身的器件、路线与实验，不重复总览。光子神经网络、电子-光子混合架构归本篇；神经形态芯片的具体产品归 [神经形态计算](02-neuromorphic-computing.md)，只链接、不重复。

## 1. 研究问题

电子计算有两个物理代价随规模放大：导线上的充放电与串扰，以及数据搬运的带宽上限。光子计算要回答的问题是：**能不能让光来承担计算中最重的那部分——大规模线性运算（主要是矩阵乘法），从而绕开电子互连的带宽与能耗瓶颈？**

光的吸引力来自三点：光速传播、波导间串扰低、波分复用（WDM）让一条波导可同时承载多路不同波长的信号，天然带有并行性。光的短板同样来自物理：光不擅长“把值存住并反复改写”，光学非线性弱且难控制，光信号最终仍要回到电子世界做存储、控制与非线性运算。于是光子计算的研究问题从一开始就是混合问题：光负责什么、电负责什么，两者之间的转换代价由谁买单。

## 2. 基础理论

- **干涉做乘法**：两束相干光干涉的结果取决于它们的振幅与相位差；调节相位即可调节权重，这是相干光子矩阵乘法的物理基础。
- **马赫—曾德尔干涉仪（MZI）网格**：由分束器与移相器组成的网格可以实现任意酉矩阵变换；Shen 等 2017 年的工作用它演示了光子神经网络。来源：Shen et al., 《Deep learning with coherent nanophotonic circuits》, Nature Photonics, 2017 年。
- **波分复用广播—加权（broadcast-and-weight）**：多路波长信号在同一波导中广播，微环谐振器按波长选择性地加权，再由光电探测器求和；这是非相干路线的基本结构，源自 Tait、Prucnal 等人在普林斯顿的研究。
- **光电探测即求和**：光电探测器的输出电流正比于入射光功率之和，天然完成“加法”这一步；但这一步同时把相位信息丢掉，是相干与非相干路线分叉的根源。
- **衍射与自由空间光学**：透镜与衍射元件可以在光传播过程中完成傅里叶变换等运算，几乎不耗能；代价是体积大、难集成、可重构性差。
- **光子存储的物理困难**：光子不带电荷、难被“抓住”；光子存储必须借助物质媒介（相变材料、光机械、原子系综等）把光信号转成物质状态再转回来，每一步都有损耗与速度代价。

## 3. 技术路线

主流路线按“相干还是非相干、集成还是自由空间”划分：

- **相干集成光子路线（MZI 网格）**：用硅光平台上的 MZI 网格做矩阵乘法，精度由相位控制精度决定。优点是数学上干净、可实现任意线性变换；缺点是网格规模随矩阵尺寸平方增长、相位漂移需要持续校准、光损耗随级联深度累积。
- **非相干 WDM 路线（微环谐振器广播—加权）**：用波长维度做并行，用微环做加权，用探测器做求和。优点是并行度高、对相位不敏感、结构相对紧凑；缺点是微环对温度敏感（热漂移会改谐振波长）、权重精度受限于谐振控制精度、波长通道数受光源与串扰限制。
- **光子张量核路线**：把上述结构做成可复用的张量计算单元，配合电子控制做神经网络推理。代表性工作见第 5 节；本路线与“光子神经网络”基本同义，只是更强调可编程张量核而非固定网络。
- **自由空间衍射路线**：用衍射光学元件做大规模并行光学计算，适合图像处理与卷积类任务；优点是并行规模极大，缺点是难集成、难重构、系统体积大，离芯片级产品最远。
- **电子—光子混合路线**：光做线性部分（矩阵乘法），电子做非线性激活、存储、控制与数据调度。这是目前唯一在系统层面跑通真实网络的组织方式，也是本篇认为最现实的路线——但它同时意味着：光子部分的收益必须先扣除光电转换（DAC/ADC、电光调制、光电探测）的全部代价，才是系统级收益。
- **光子存算路线**：把相变材料（PCM）等非易失光学元件放进光子结构，让权重以光学状态存住并参与计算，瞄准“光子缺存储”问题。2025 年前后有光子锁存单元的研究演示（见总览），但密度、保持时间与改写耐久性仍是研究问题，本篇不把演示写成产品。

## 4. 系统架构

一个典型的电子—光子混合推理系统由以下部分组成：

- **光源**：片上或片外激光器，连续波或微梳（frequency microcomb）提供多波长载波；光源的功耗、波长稳定性与成本是系统级指标的一部分，常被器件级报道忽略。
- **光子计算核心**：MZI 网格或微环加权阵列，执行矩阵乘法；核心本身几乎不耗能（被动光学），但调制、校准与温控要耗能。
- **电光调制与光电探测**：输入数据经调制器上光，输出经探测器回电；这两步的速度与精度决定系统吞吐与有效精度。
- **转换接口**：DAC（数字到模拟，驱动调制器）与 ADC（探测电流转数字）；转换接口常是系统瓶颈——计算核心再快，也要等转换。总览 [新型计算架构：光子与存算一体](08-new-computing-arch.md) 已把这一点列为共性瓶颈。
- **电子控制与存储**：电子存储器存权重与中间结果，电子控制器做非线性激活、数据调度、校准与系统控制；权重更新（训练）几乎总是在电子侧完成。
- **软件栈**：把神经网络映射到光子硬件的编译与映射工具；没有它，光子核只能跑演示用的固定网络。

## 5. 代表性实现与开源项目

只列真实存在的研究工作，不写厂商宣传倍数：

- **Feldmann 等，集成光子张量核**：用集成光子器件做并行卷积处理的研究工作。来源：Feldmann et al., 《Parallel convolutional processing using an integrated photonic tensor core》, Nature, 2021 年。
- **Shen 等，相干纳米光子神经网络**：用 MZI 网格做深度学习推理的早期集成演示。来源：Shen et al., Nature Photonics, 2017 年。
- **Wang 等，集成大规模光子加速器**：2025 年《Nature》上的集成光子加速器工作，演示了低延迟的光子推理系统（具体延迟与能效数字以论文原文的测试条件为准，本篇不转载脱离条件的数字）。
- **Meng 等，高集成光子张量核**：用单个微环谐振器结合时间、波长与微波频域多维复用做张量卷积，见第 7 节带测试条件的数字。
- **硅光代工平台**：GlobalFoundries 硅光平台、imec 硅光平台等是上述研究工作的制造基础；平台本身是代工服务，不是光子计算机产品。
- **尚无代表性商用系统**：按“通用可编程、按商用标准交付、能跑用户自有模型”的定义，今天不存在商用的光子计算机；现有产品多为光互连（把光用于传输而非计算）或特定推理场景的研究原型。光互连的另一面见 [新型存储与互连：HBM 与 CXL](09-new-storage-interconnect.md) 与 [高性能网络与并行文件系统](14-hpc-network-storage.md)。

## 7. 当前实验结果

只写带来源与测试条件的数字；其余一律不写：

- **Meng 等 2025 年光子张量核**（Light: Science & Applications 14, 27）：用单个微环谐振器做多维复用张量卷积，报道的计算密度为 34.04 TOPS/mm²；同一工作的演示芯片在手写数字识别（MNIST）卷积网络测试集上达到 96.41% 准确率，接近理论预测的 96.79%，芯片计算速度报道为 245.33 GOPS。测试条件说明：这是单器件演示系统的报道值，精度、阵列规模与是否含完整系统转换开销以论文原文为准；密度数字（每平方毫米）与速度数字（GOPS）不能直接换算成系统级推理吞吐。
- **定性结论（有文献支撑、无脱离条件数字）**：光子计算在“用光做线性运算”上已有可复现的器件演示；光子存储、非线性环节与大规模集成仍是研究问题；系统级收益必须在含转换开销的条件下评估，器件级数字不等于系统级收益。

## 8. 技术瓶颈

- **光子存储缺失**：光擅长传输与变换，不擅长把值存住并反复改写；光子存储单元的密度、保持时间与改写耐久性均未达到实用水平。
- **非线性环节**：神经网络需要非线性激活；光学非线性弱、阈值高、难集成，实际系统几乎总把非线性交回电子侧，于是系统仍是混合的。
- **精度与校准**：相干路线的相位漂移、非相干路线的微环热漂移，都需要持续校准；校准本身耗能、占时间，并随规模放大。
- **转换瓶颈**：DAC/ADC 与光电转换的能量与延迟常吃掉光子核心的收益；核心越快，转换的相对代价越大。
- **损耗与规模化**：光损耗随级联深度与分路数累积，限制了单核矩阵规模；大规模集成、良率与硅光代工兼容性仍在验证中。
- **软件栈与可编程性**：把任意网络映射到光子硬件、并在漂移与噪声下保证精度的编译工具链不成熟；用户模型一换，映射可能要重做。
- **评估口径混乱**：有效精度、是否含光源与转换功耗、是否含电子控制开销，各家口径不一；跨原型比较需要先统一口径（方法见 [计算架构仿真与基准测试](79-arch-simulation-benchmarks.md)）。

## 9. 成熟度判断

- **成熟度：实验研究中。** 判断依据一句话：光子张量核与光子神经网络均有器件级与小规模系统级演示，但存储、非线性、转换与软件栈问题均未解决，尚无通用可编程的商用光子计算系统；光互连（传输）比光计算（运算）成熟得多，两者不可混淆。

## 10. 未来研究问题

- **已有研究在做**：光子存储单元（相变材料光子锁存、光机械存储等）的密度、保持时间与耐久性。
- **已有研究在做**：光电混合架构的转换优化——降低 DAC/ADC 与调制探测的能量占比，或把更多非线性留在光域。
- **已有研究在做**：抗漂移的权重校准与噪声容忍训练方法，让光子推理精度在真实器件上稳定。
- **本文推测**：光子计算最可能先以“特定推理加速器”（固定或少量模型、低功耗推理）的形态落地，而不是以通用光子计算机的形态落地；检验标准是是否出现可跑用户自有模型、可量产交付的加速器产品。
- **本文推测**：光子与存算的结合（光子存算）可能比单一路线走得更远，因为它同时瞄准传输与存储两个瓶颈；检验标准是光子存算原型是否在系统级（含量化转换开销）而非器件级证明收益。
