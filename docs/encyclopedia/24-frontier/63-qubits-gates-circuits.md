# 量子比特、量子门与量子线路

> 本篇是 [量子计算基础](01-quantum-computing.md) 的三级展开：总览讲“量子计算是什么、离容错还有多远”，本篇只讲最底层的操作单元——量子比特是什么、量子门做什么、量子线路怎么组织。硬件路线对比见 [66 篇](66-quantum-hardware-routes.md)，纠错编码见 [65 篇](65-quantum-error-correction.md)。

## 1. 研究问题

经典计算的操作单元是比特和逻辑门：比特是 0 或 1，逻辑门是 AND、OR、NOT 的组合。量子计算要回答一个更底层的问题：**如果操作单元本身服从量子力学，计算的基本操作应该长什么样？** 这个问题不能靠“把经典门换个名字”回答，因为量子态的演化规则（幺正演化）与经典逻辑门的规则（不可逆的布尔函数）根本不同：量子门必须是可逆的，测量是唯一不可逆的步骤，而“复制一个未知量子态”被不可克隆定理禁止。

本篇的研究问题因此有三层：第一，如何用数学对象精确描述一个量子比特及其演化；第二，哪些门集合起来足以实现任意量子计算（通用性问题）；第三，线路的规模（门数、深度、纠缠结构）如何决定它在真实含噪硬件上能不能跑出来。第三层是本篇与总览的交界：总览指出“能跑多深的电路比有多少比特更重要”，本篇把这句话落实为可检查的量——深度、双比特门数、以及连通性带来的额外开销。

## 2. 基础理论

- **量子比特态矢**：单量子比特态写为 α|0⟩ + β|1⟩，α、β 为复数且 |α|² + |β|² = 1；测量得 0 的概率为 |α|²，得 1 的概率为 |β|²，测量后态坍缩到测得结果。来源：Nielsen 与 Chuang《Quantum Computation and Quantum Information》。
- **布洛赫球**：忽略整体相位后，单比特纯态一一对应于单位球面上的点；球的北极是 |0⟩，南极是 |1⟩，赤道上的点是等权叠加态（相位不同则经度不同）。布洛赫球是“看”单比特门最直观的工具：单比特门就是球的旋转。
- **幺正演化**：除测量外，量子态的演化由幺正矩阵 U 描述，满足 U†U = I；幺正变换保持内积与总概率，因而可逆。量子门就是作用在少量比特上的幺正变换。
- **张量积与纠缠**：n 个量子比特的联合态生活在 2ⁿ 维空间中；不能写成单比特态乘积的联合态称为纠缠态。纠缠不是“两个比特各自的状态”，而是联合态本身的属性。
- **不可克隆定理（Wootters 与 Zurek，1982）**：不存在一个通用过程能把任意未知量子态 |ψ⟩ 复制成 |ψ⟩⊗|ψ⟩。推论：量子纠错不能靠“备份三份再投票”实现，必须用编码（见 65 篇）；量子线路也不能随意“扇出”一个量子比特的值。
- **测量公设**：测量是一个非幺正、不可逆、带随机性的过程；测量基的选择决定了读出的是哪一方面的信息，测错基会丢掉相位信息。线路设计里“最后测什么、中间要不要测”是算法正确性的一部分，不是事后读数。

## 3. 量子比特的表示与物理对应

数学上的量子比特只有一个定义，但物理实现各不相同；本篇只讲表示层面，物理载体对比见 66 篇：

- **计算基与叠加基**：{|0⟩, |1⟩} 是计算基；{|+⟩, |−⟩}（H 门作用于计算基得到）是叠加基。同一量子态在不同基下有不同的振幅写法，算法常在基之间切换：例如 Shor 算法的量子傅里叶变换，本质是在计算基与傅里叶基之间换基。
- **纯态与混合态**：纯态可用一个态矢描述；与环境纠缠后、或对系综取平均后得到的状态要用密度矩阵描述。真实硬件上的量子比特几乎总是混合态——噪声就是“纯态变混合态”的过程。密度矩阵的语言在本篇不展开推导，但读者应知道：保真度、相干时间这些工程指标，衡量的正是“态离理想纯态有多远”。
- **相位是真实资源**：相对相位（α 与 β 之间的辐角差）不影响单次测量的 0/1 概率分布，却决定了后续干涉的结果。很多初学者误以为“概率相同就是同一个态”；反例是 |+⟩ 与 |−⟩：两者测计算基都是 50/50，但经过 H 门后前者回到 |0⟩、后者回到 |1⟩。算法设计（见 64 篇）的全部技巧，几乎都在于安排相位。

## 4. 量子门：从单比特到多比特

### 4.1 单比特门：布洛赫球上的旋转

任何单比特幺正操作都可以写成绕布洛赫球某个轴的旋转（至多差一个整体相位）。常用门：

- **X、Y、Z（泡利门）**：分别绕 x、y、z 轴转 180°；X 门相当于经典 NOT 门，Z 门只改相位不改 0/1 概率——Z 门的存在提醒读者：量子线路里有“只改相位、不动概率”的操作，而经典线路里没有对应物。
- **H 门（Hadamard）**：把 |0⟩ 变成 (|0⟩ + |1⟩)/√2，把 |1⟩ 变成 (|0⟩ − |1⟩)/√2；在布洛赫球上是绕 (x + z)/√2 轴转 180°。它是制造叠加与换基最常用的门，也是 Grover 扩散算子与量子傅里叶变换的构件。
- **S 门与 T 门**：S 门是绕 z 轴转 90°，T 门是绕 z 轴转 45°；S 门属于 Clifford 群，T 门不属于。这一区分在容错计算里至关重要：Clifford 门在多数纠错码里容易做容错实现，T 门通常需要魔术态蒸馏等额外代价（见 65 篇）。
- **参数化旋转门 Rx(θ)、Ry(θ)、Rz(θ)**：绕轴转任意角度 θ；变分算法（见 64 篇与 70 篇）里的可调参数就挂在这些门上。参数化门是“量子线路可训练”的载体，也是量子机器学习（见 67 篇）里参数化量子线路的构件。

### 4.2 双比特门与纠缠的产生

- **CNOT 门**：控制位为 |1⟩ 时翻转目标位，否则不动；它是制造纠缠的最小工具：H 门作用于控制位后再做 CNOT，可得到 Bell 态 (|00⟩ + |11⟩)/√2。多数硬件上 CNOT（或其等价的 CZ 门）是保真度最低、最难做好的门，线路的真实成本往往由双比特门数决定，而不是总门数。
- **CZ 门与受控旋转**：CZ 门只在 |11⟩ 上加一个负号；它与 CNOT 只差两个 H 门，在超导硬件上常是原生门。受控-U 门（控制位为 1 时对目标位做 U）是许多算法的构件，例如 Shor 算法里的受控模幂运算。
- **SWAP 门与连通性代价**：真实芯片的量子比特并非全连接：两个不相邻的比特要做双比特门，必须先用一串 SWAP 门把它们“搬”到一起。SWAP 本身由三个 CNOT 组成，因此连通性差的芯片上，一个逻辑上很浅的线路可能被编译成很深的物理线路。读硬件指标时，“双比特门保真度”必须连同“连通图”一起看，只看前者会低估真实开销。

### 4.3 通用门集

一组门称为通用的，如果用它们可以任意逼近任何幺正操作。常见结论：

- **{H, T, CNOT} 是通用门集**：H 与 T 生成单比特旋转的稠密集，CNOT 提供纠缠能力；两者合起来可逼近任意多比特幺正操作。
- **Clifford 群 + T 门**：H、S、CNOT 生成 Clifford 群；Clifford 线路可以被经典计算机高效模拟（Gottesman–Knill 定理），因此 Clifford 群本身不带来量子优势——优势来自 T 门等非 Clifford 资源。这一结论把“量子优势从哪来”精确化为“非 Clifford 资源有多少”。
- **逼近代价**：Solovay–Kitaev 定理说，用有限门集逼近目标幺正操作所需的门数随精度要求只以多对数方式增长；也就是说，通用门集的选择不改变算法的渐近复杂度类，只改变常数与编译开销。工程上常数很重要（它决定线路深度），理论上它不改变“多项式还是指数”的定性结论。

## 5. 量子线路的结构与成本度量

量子线路是门的时序排布图：横轴是时间（从左到右），每条横线是一个量子比特，方块是门，竖线是双比特门。评价一条线路不能只看“用了几个门”，要看一组量：

- **宽度**：线路用到的量子比特数。宽度决定经典模拟的内存（态矢模拟需存 2ⁿ 个振幅），也决定芯片规模需求。
- **深度**：最长的一串有依赖关系的门。深度决定噪声累积：每多一层门，错误概率就叠加一层；相干时间内能跑的深度，是硬件的真实能力上限。
- **双比特门数与双比特深度**：双比特门错误率通常比单比特门高一个量级，因此双比特门数比总门数更能预测线路的成功概率。
- **测量与反馈**：含中间测量与基于测量结果的条件操作（动态线路）的线路，超出了“幺正演化 + 末端测量”的简单模型；纠错（65 篇）与部分变分算法依赖这种反馈能力，硬件是否支持低延迟反馈是选型时要问的问题。
- **线路示例（示例未实测）**：以三比特 GHZ 态制备为例——对比特 0 做 H 门，再依次做 CNOT(0→1)、CNOT(0→2)，得到 (|000⟩ + |111⟩)/√2。以下为 Qiskit 风格的示意代码，仅说明线路写法，本地无量子硬件与量子实验环境，**示例未实测**，版本号以官方发布为准（待核实）：

```python
# 示例未实测：仅示意 GHZ 态制备线路的写法，不代表已在硬件上运行通过
from qiskit import QuantumCircuit
qc = QuantumCircuit(3, 3)
qc.h(0)
qc.cx(0, 1)
qc.cx(0, 2)
qc.measure([0, 1, 2], [0, 1, 2])
```

读这段代码时应注意：它描述的是逻辑线路；编译到真实芯片时，编译器还要做门分解、比特映射、SWAP 插入与时序调度，物理线路会比逻辑线路深得多（见 69 篇编译器一节）。

## 6. 系统架构：线路如何变成一次运行

一条线路从“纸面”到“结果”要经过四层（详见 69 篇软件栈与 70 篇混合计算）：

1. **线路层**：用户用 SDK 写逻辑线路，含参数化门与测量。
2. **编译层**：把逻辑线路翻译成硬件原生门集、映射到物理比特、插入 SWAP、做门合并与深度优化。
3. **控制层**：把编译后的门序列翻译成微波脉冲（超导）、激光脉冲序列（离子阱）或光学元件设置（光子），按纳秒级时序发出。
4. **读出层**：测量物理比特，返回比特串样本；一次运行只给一个样本，要估计概率分布必须重复运行成千上万次（shots），再做统计。

这个分层解释了一个常见困惑：为什么同一条线路在不同硬件上结果不同——编译策略、原生门、噪声模型、读出保真度在每一层都不同，线路本身只是第一层。

## 7. 当前实验结果

本节只写来源与测试条件齐全的项；缺一件的数字不写：

- **Google Willow 表面码存储实验**：105 量子比特超导芯片上的表面码存储实验（见总览第 7 节与 65 篇），码距 3、5、7 三档，逻辑错误率随码距增大而下降，抑制因子约 2.14，距离 7 的逻辑错误率约为每周期 0.143%。来源：Google Quantum AI 及合作者《Quantum error correction below the surface code threshold》，Nature 638, 920–926（2025，https://doi.org/10.1038/s41586-024-08449-y）。注意：这是存储实验，不是逻辑门实验；它证明的是“编码后的存储可以越编越好”，不是“任意线路都能跑”。
- **不写进本节的数字**：各厂商宣传的单比特/双比特门保真度纪录——不同平台、不同测量方法（随机基准测试、过程层析、交叉熵基准）的数值不可直接比较，且随芯片批次变化；本篇不转载这类纪录，读者应以各硬件方的基准方法说明为准（待核实）。

## 8. 技术瓶颈

- **双比特门保真度是瓶颈中的瓶颈**：线路成功率近似等于各门保真度的乘积（忽略关联误差的粗略估计）；双比特门保真度 99% 时，100 个双比特门的线路成功率已降至约 37%，1000 个时约 0.004%。这就是“深度”与“保真度”必须一起谈的原因。
- **串扰与频率拥挤**：超导芯片上比特数增加时，相邻比特的控制信号会互相干扰，频率排布也更难避开碰撞；规模化后保真度变差是常见现象，不是某个厂商的个别问题。
- **读出误差**：测量本身会出错，且读出误差与门误差性质不同（读出只影响最后一步，但会污染全部统计结果）。读出保真度低时，即使线路本身完美，结果分布也会被抹平。
- **编译开销不透明**：同一逻辑线路在不同编译器、不同芯片上的物理深度可差数倍；论文与新闻里“跑了多少比特的线路”若不注明编译后深度与双比特门数，可比性有限。

## 9. 成熟度判断

- **成熟度：实验研究中。** 判断依据一句话：单比特与双比特门的数学理论与通用门集理论早已成熟，但把这些门在规模化硬件上做到足够低错误率、且能稳定跑深线路，仍是各路线正在攻关的实验问题；今天的门保真度与连通性尚不足以支撑无纠错的深线路通用计算。

## 10. 未来研究问题

- **已有研究在做**：更高保真度的原生双比特门（超导的可调耦合器、离子阱的高速纠缠门、中性原子的里德伯门）；低串扰的芯片布图与频率规划算法；考虑噪声的线路编译（把“保真度最高”而非“门数最少”作为优化目标）。
- **已有研究在做**：动态线路与低延迟反馈的标准化：中间测量 + 实时条件操作是纠错的前提，但各硬件的支持程度与延迟差异很大，尚无统一的性能基准。
- **本文推测**：未来线路设计的主战场可能从“手写线路”转向“噪声感知的自动综合”——编译器根据当天的校准数据（各比特、各门的实时保真度）重新映射线路；这一推测的检验标准是：编译器是否成为硬件方公开竞争的指标，而不只是 SDK 的附带功能。
