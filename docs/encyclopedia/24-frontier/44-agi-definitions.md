# AGI 定义、争议与研究路径

本篇是 [AI Agent 前沿总览](06-frontier-ai-agents.md) 的分支文章，只讲 AGI 这一概念本身的研究侧问题：它到底指什么、为什么各方定义不一致、以及不同的定义会导向怎样不同的研究路径。总览中关于多智能体协作、自主研究与世界模型的展开，见本分支的对应文章，本篇只链接、不重复。总览已指出“能跑一个演示不等于能交付一个系统”，本篇把同样的审慎态度用在“通用”二字上：一个系统在很多任务上表现好，与它具备人类意义上的通用智能，是两个不同的主张。

## 1. 研究问题

AGI（Artificial General Intelligence，通用人工智能）研究要回答的核心问题是：是否存在一种智能系统，能够在足够广泛的任务范围上，像人类一样学习新任务、迁移已有知识、并在没有为每个任务单独训练的情况下完成任务？这个问题的难度不在于造一个“什么都会一点”的系统——今天的大模型在文本、代码、图像等任务上已经覆盖很广——而在于“通用”没有公认的度量：广到什么程度算通用？在什么条件下完成才算？由谁来判定任务的难度与新颖性？

现有技术解决不了这个问题的三个原因。第一，**任务边界是人定的**：基准由研究者选，系统在基准上的表现只能证明它在这些基准上好，不能证明它在基准之外的世界里也好。第二，**学习与记忆的界限不清**：系统答对一道题，可能是推理出来的，也可能是训练数据里见过类似内容，现有方法很难在一般情况下区分二者。第三，**“人类水平”本身不是一个点**：人类在不同任务上的能力差异极大，以“达到人类水平”作标准时，必须先说明是哪类人、在哪类任务上、在什么工具与时间条件下，否则比较没有意义。

因此本篇的立场是先拆定义、再谈路径：不同的 AGI 定义，对应不同的证据标准，也对应不同的研究议程。把定义混为一谈，是 AGI 讨论中最常见的混乱来源。

## 2. 基础理论

- **通用智能的早期形式化尝试**：如 Legg 与 Hutter 提出的通用智能度量思路，把智能理解为在多种环境中达成目标的能力，并按环境复杂度加权。它的价值在于提醒读者：没有环境分布的说明，“通用”无从谈起；它的局限在于该度量在实践中无法直接计算，只能作概念参照。
- **智力理论的分歧**：心理学中的一般智力因素（g 因素）讨论的是人类能力之间的相关结构，不能直接搬运为机器智能的定义；机器智能研究更关心任务迁移、样本效率与自主学习，而非与人类智商分数的对应关系。
- **计算学习理论**：样本复杂度、泛化界、分布外泛化等概念为“学会新任务”提供了可讨论的语言，但现有理论结果多针对受限模型类，离 AGI 的开放任务空间还很远。
- **具身与交互视角**：一部分研究者认为，脱离身体与真实环境交互的智能不可能是完整的通用智能；另一部分认为，语言与符号推理本身已足以构成通用能力的基础。这一分歧直接影响研究路径的选择，见第 3 节。

## 3. 技术路线

按对“通用”的不同理解，研究路径大致分为三条，彼此并非互斥，但证据标准不同：

- **规模化路线**：认为通用能力主要随模型规模、数据规模与算力规模涌现，研究重点是扩展规律、训练效率与对齐方法。这一路线的证据是模型在越来越多任务上的表现提升；它的未解问题是，表现提升是否等于通用能力提升，还是只等于“覆盖的任务分布变宽”。规模化路线的支持者常把“尚未解决”读作“规模还不够”，批评者则认为这是把结论预设进了前提，需要独立的、事先注册的迁移测试来裁决。
- **架构与认知路线**：认为仅靠规模不够，还需要新的架构要素——如显式记忆、规划、世界模型、因果推理或符号与神经的结合。这一路线的证据标准更高：新架构必须在同等规模与数据条件下，在事先未见的任务类型上表现出系统性的迁移优势，而不只是在已有基准上多拿几分。本分支的[世界模型与环境建模](46-world-models.md)、[推理、规划与搜索](47-reasoning-planning-search.md)与[长期记忆与持续学习](48-long-term-memory.md)属于这一路线的具体研究问题。
- **交互与社会路线**：认为通用智能体现在与人类和环境的持续交互中——学习使用工具、接受纠正、参与协作、在多智能体环境中行动。这一路线的证据来自长程任务与真实部署中的表现，而非单轮问答基准；它的困难在于评估成本高、可复现性差。本分支的[自主 Agent 与多 Agent 协作](49-multi-agent-collaboration.md)与[自主研究原型与可复现证据](53-autonomous-research.md)讨论的正是这一路线的评估困境。

三条路线有一个共同的盲点：它们都容易把“研究者希望系统具备的能力”写进任务设计，再用系统在这些任务上的表现反证能力。避免这种循环，需要在任务设计时就把“新颖性”说清楚——任务是否在训练分布之外、判定标准是否事先公开、失败案例是否同样公开。

## 4. 系统架构

尚无代表性商用系统可以按“AGI 系统”的定义来介绍：今天可用的系统都是在特定任务分布上表现良好的专用或宽域系统，称其为 AGI 系统会超出证据。本节因此只描述研究讨论中常见的参照架构，而非已落地的 AGI 架构：

- **感知与语言层**：处理文本、图像、语音等输入，见[基础模型与多模态模型](45-foundation-multimodal.md)。
- **推理与规划层**：在行动前做推演与拆解，见[推理、规划与搜索](47-reasoning-planning-search.md)。
- **记忆层**：跨任务保留经验与知识，见[长期记忆与持续学习](48-long-term-memory.md)。
- **行动与工具层**：通过工具影响环境，实操细节见本站 18 域[Agent 与工作流自动化](../18-local-ai/03-agent-workflow.md)，本篇不复制。
- **评估与监督层**：对系统行为做监控、审计与人工接管，这是目前最薄弱的一层，也是 AGI 讨论中最容易被跳过的一层。

任何把其中一两层做得好的系统，都还不等于“通用系统”；架构图的完整不等于能力的通用。

## 5. 代表性实现与开源项目

本节不列“AGI 项目排行榜”，因为按任何一种严肃定义，今天都不存在可公开验证的 AGI 实现。只列与 AGI 讨论相关的、可查证的研究载体：

- **大语言模型与多模态模型系列**：作为规模化路线的参照实现，它们的公开技术报告是讨论通用能力边界的主要证据来源；但各厂商的报告口径不一，分数不可直接比较，本篇不采信任何一方的宣传性排名。
- **ARC 等抽象推理基准**：以“事先未见的规则推理任务”作为通用性的探针，其设计意图是减少对训练数据记忆的依赖；但基准本身也会被针对性优化，基准分数上升不等于通用能力上升，这是所有 AGI 基准共有的局限。
- **开源 Agent 框架**：如 AutoGen、CrewAI、LangGraph 等，提供多智能体编排基础设施；它们是研究工具，不是 AGI 证据，见总览[AI Agent 前沿总览](06-frontier-ai-agents.md)。
- **暂无公开标准**：AGI 的能力分级、测试方法与安全评估均无公认标准，见第 6 节。

## 6. 关键论文与标准

- Legg 与 Hutter 关于通用智能度量的早期论述（概念参照，非可直接计算的标准）。
- Yao 等人《ReAct: Synergizing Reasoning and Acting in Language Models》（ICLR 2023，arXiv:2210.03629）：推理与行动交错的研究范式，是 Agent 路线的重要参照，但它证明的是特定任务上的方法有效性，不是通用智能。
- Ha 与 Schmidhuber《Recurrent World Models Facilitate Policy Evolution》（NeurIPS 2018）：世界模型路线的早期实证，环境限于受控游戏环境，结论不宜外推到开放世界。
- Hammond 等人《Multi-Agent Risks from Advanced AI》（2025）：多智能体风险的系统论述，见总览引用；它讨论的是“即使个体能力很强，群体仍可能不安全”，与 AGI 的“能力”讨论互补。
- 暂无公开标准：AGI 没有 ISO、IEEE 或其他公认机构发布的统一能力标准；任何自称“AGI 分级标准”的厂商文件或媒体榜单，都应视为一家之言，以官方发布为准（待核实）。

## 7. 当前实验结果

本节只写方法论层面的定性结论，不写模型排行榜数字，理由与总览一致：编排层敏感性使分数不可直接比较。

- 宽域模型在大量基准上的表现确实在提升，但提升的解释有争议：是通用推理能力提升，还是训练分布覆盖了更多基准类任务，现有公开证据无法干净地区分。
- 在事先未见的抽象推理任务上，系统表现仍远不稳定；同一任务换一种表述、换一个编排层，结果可能大幅波动，这说明“能力”尚未稳定到可以脱离测试条件的程度。
- 长程、多步、需要工具与纠错的任务，是目前最能暴露通用性短板的一类任务；短问答基准上的高分不能预测这类任务的表现。
- 安全与对齐实验表明，能力越强的系统，其失效模式也越难事先枚举；这意味着 AGI 的评估问题不只是“测能力”，还要“测失效”，而后者目前没有成熟方法。

## 8. 技术瓶颈

- **定义瓶颈**：没有可操作、可复现的通用性定义，所有“接近 AGI”的说法都缺乏可证伪的检验标准。
- **评估瓶颈**：基准污染、编排层敏感性、任务分布的人为选择，使评估结果的解释空间过大。
- **迁移瓶颈**：在分布内任务上表现好，不等于在分布外任务上能学习；样本效率与人类学习效率的差距仍是数量级问题（具体倍数因任务而异，不写统一数字）。
- **记忆与持续学习瓶颈**：见[长期记忆与持续学习](48-long-term-memory.md)，灾难性遗忘与记忆污染尚未解决。
- **安全与责任瓶颈**：见[AI 可解释性、可靠性与安全性](52-ai-explainability.md)，能力主张越强，责任划分与审计要求越高，而这两者目前都不成熟。
- **证据瓶颈**：关键训练数据、评估细节与失败案例多不公开，第三方难以独立复现厂商的能力主张。

## 9. 成熟度判断

- **成熟度：理论探索中。** 判断依据一句话：AGI 连可操作、可复现的定义与评估标准都尚未建立共识，谈论“实现进度百分比”或“到达年份”都超出了现有证据；本篇讨论的只是定义之争与研究路径之争，不是某个系统的交付进度。

## 10. 未来研究问题

- **已有研究在做**：如何设计抗污染、抗编排层敏感性的通用性探针任务；如何度量分布外迁移而非分布内记忆。
- **已有研究在做**：规模化路线与架构路线的对照实验设计——在同等数据与算力下，新架构是否带来系统性的迁移增益。
- **本文推测**：AGI 讨论最可能先收敛的不是一个“AGI 到达日”，而是一套分层的、任务类型明确的能力描述语言（例如区分“宽域问答”“长程工具任务”“开放环境学习”），检验标准是不同研究团队能否用同一套语言复现彼此的评估结论。
- **本文推测**：如果未来出现被广泛接受的 AGI 评估标准，它更可能先来自安全与审计需求（必须说清系统不能做什么），而非来自能力宣传需求；检验标准是该标准是否包含公开的失败案例库。
