# 自主研究原型与可复现证据

本篇是 [AI Agent 前沿总览](06-frontier-ai-agents.md) 的分支文章，只讲自主研究原型与可复现证据的研究侧问题。总览已把“自主研究循环”定义为严格含义——假设与实验的循环本身由智能体驱动，而非“自动查资料写综述”；本篇展开这个定义：自主研究原型到底做了什么、证据标准应是什么、以及为什么“演示”与“发现”之间隔着一道可复现性的鸿沟。文献调研与综述写作的工具实操见本站 18 域[Agent 与工作流自动化](../18-local-ai/03-agent-workflow.md)，本篇只链接、不复制。

## 1. 研究问题

自主研究要解决的问题是：智能体能否独立完成科学研究的一个完整闭环——提出有价值的假设、设计可检验的实验、执行实验并分析结果、根据结果修正假设、最终产出经得起同行评议的新知识？这个问题的难度不在于“让智能体写一篇看起来像论文的文档”，而在于“让智能体产出的结论经得起独立复现”。一篇格式规范、引用齐全、图表精美的文档，如果实验不可复现、假设不可证伪、数据来源不明，就不是研究成果，而是研究格式的仿制品。

现有方法解决不了这个问题的三个原因。第一，**假设质量难以度量**：一个假设“有价值”与否，需要领域知识、文献背景与问题意识来判断；智能体生成的假设可能只是已有文献的重新组合，而非真正的新见解，现有方法难以自动区分二者。第二，**实验执行的可靠性不足**：代码错误、数据泄露（测试集混入训练）、超参数调优中的选择性报告、统计方法误用等问题，在人类研究中已常见，在智能体自主执行时更难被发现——因为没有人类在中间步骤做常识检查。第三，**可复现性的基础设施缺失**：自主研究原型多不公开完整的代码、数据、环境、随机种子与失败记录；没有这些，第三方无法复现，也就无法判断“发现”是真实的还是某次幸运采样或某个 bug 的产物。

## 2. 基础理论

- **科学方法与可证伪性**：Popper 的可证伪性标准要求假设必须能被实验否定；一个永远正确的假设（因为表述模糊、无法检验）不是好假设。自主研究系统必须生成可检验的假设，否则闭环只是自我肯定的循环。
- **可复现性分层**：计算可复现（同一代码、同一数据、同一环境得同一结果）、统计可复现（换随机种子、换数据划分结论仍成立）、概念可复现（换方法、换数据集结论方向仍成立）是三个不同层次；自主研究原型目前多数只在第一层有零星证据，后两层基本空白。
- **实验设计理论**：对照组、随机化、盲法、样本量、统计功效等概念，是判断实验结论可信度的基本工具；智能体设计的实验如果缺少对照或统计功效不足，结论就不可信，无论执行得多流畅。
- **同行评议的认识论功能**：同行评议不只是“格式检查”，而是领域专家对假设新颖性、方法正确性、结论合理性的独立判断；绕过同行评议、直接以“智能体已发表论文”作宣传，是对研究证据标准的误读。

## 3. 技术路线

- **文献驱动的假设生成路线**：智能体读大量文献、找空白、提假设。优点是覆盖面广；缺点是容易生成“文献中已有但表述不同”的伪新假设，且对文献的误读会传导为假设错误。
- **实验驱动的闭环路线**：智能体在特定领域（如材料、药物、代码优化）中做“假设—实验—分析—再假设”的循环，实验由代码或仿真执行。优点是闭环真实、可检验；缺点是领域受限——实验可自动化的领域才适合，开放领域的实验设计仍需人类。
- **人机协作路线**：人类定方向、定关键假设、做关键判断，智能体做文献初筛、实验执行、数据分析与初稿撰写。优点是结合了人类的判断力与智能体的执行力；缺点是“协作增益”需要对照实验证明——有智能体帮助的研究是否比没有帮助的更快、更好，目前公开的可复现证据仍少。
- **多智能体研究团队路线**：多个智能体分别担任文献员、实验员、评审员，互相审阅。优点是评审环节理论上能拦截错误；缺点与[自主 Agent 与多 Agent 协作](49-multi-agent-collaboration.md)一致——评审员可能盲从生产者，且协作收益需要消融实验证明。
- **基准化研究任务路线**：把研究任务标准化为基准（如给定数据集、给定问题、要求产出可验证的结论），用基准分数度量自主研究能力。优点是可比较；缺点是基准化会简化真实研究——真实研究的问题定义本身就是研究的一部分，基准给定的问题定义越完整，离真实研究越远。

## 4. 系统架构

一个研究型的自主研究原型通常包含：

- **文献与知识层**：文献检索、引用管理、知识库；文献的时效性、权威性与获取许可需要单独处理，不能默认检索到的都是可靠来源。
- **假设生成层**：基于文献与已有实验结果生成候选假设，并附带可检验性说明（如何证伪它）；没有可检验性说明的假设不应进入实验环节。
- **实验执行层**：代码执行、仿真、数据分析；执行环境（依赖版本、随机种子、硬件）必须完整记录，否则结果不可复现。
- **结果分析层**：统计分析、图表生成、与已有文献的对比；选择性报告（只报阳性结果、不报阴性结果）是自主研究中最容易发生的偏差之一，需要强制报告失败与阴性结果的机制。
- **评审与复现层**：独立评审（人类或独立智能体）、复现检查（换环境、换种子重跑）、失败记录公开；没有这一层，原型产出的是“演示”，不是“证据”。
- **人类接管层**：关键判断（假设是否值得做、实验是否合规、结论是否可发表）的人工确认入口；自主程度越高，接管设计越重要，见[AI 可解释性、可靠性与安全性](52-ai-explainability.md)。

尚无代表性商用系统可以按“自主做出有价值新发现”来介绍：学术界与工业界均有原型系统，但“自主做出有价值的新发现”的主张大多停留在特定领域的演示层面，通用结论以同行评议结果为准（待核实）。

## 5. 代表性实现与开源项目

只列研究载体类别，不写“发现排行榜”：

- **学术界自主研究原型**：多个研究团队发布了“智能体做文献调研、生成假设、跑实验”的原型系统，各自针对特定领域；其论文应作为证据来源阅读，重点看方法、对照、复现细节与失败记录，而非只看摘要中的成功案例。
- **代码与实验自动化框架**：如面向机器学习实验自动化的框架（自动调参、自动实验记录），是自主研究执行层的工程基础；它们解决的是“实验跑起来”，不是“假设对不对”。
- **科学文献检索与分析工具**：文献数据库、引用图谱、语义检索工具是假设生成层的基础设施；工具的覆盖范围与更新时效以其官方发布为准。
- **可复现性基础设施**：容器化环境、实验记录工具、数据版本管理工具是复现层的基础；没有这些工具链的原型，其结果难以被第三方复现。

## 6. 关键论文与标准

- 科学方法与可复现性的方法论著作（Popper 可证伪性、实验设计与统计功效的经典论述）是本篇的理论参照，具体版本以学术出版为准。
- 自主研究原型的论文应逐篇阅读其方法与复现细节，本篇不列“代表性成功案例”清单，因为成功案例的选取本身就有发表偏倚——失败的原型很少发表，清单会系统性高估自主研究的成熟度。
- 暂无公开标准：自主研究的证据标准（什么算“自主发现”、什么算“可复现”）、实验记录的完整性标准、失败报告的标准均无公认标准；任何“智能体已独立发表论文”的宣传，都应核对论文是否经过同行评议、实验是否可独立复现（待核实）。

## 7. 当前实验结果

本节只写方法论层面的定性结论，不写“自主发现数量”排名：

- 自主研究原型在“按给定流程做文献与实验”上已有演示：在实验可自动化、评价标准明确的领域，智能体可以完成从假设到实验报告的流程；但这证明的是流程自动化能力，不是研究创造力。
- 在“独立提出有价值的新假设并验证”上，尚无公认的通用证据：公开的“自主发现”案例多限于特定领域、特定任务设置，且独立复现的报道很少；把演示中的成功案例当作通用能力证据，是证据标准的误用。
- 人机协作的增益证据仍不完整：有智能体帮助是否使研究更快、更好，需要对照实验（同一任务、有帮助 vs 无帮助）来证明；目前公开的对照证据少，且任务类型受限，通用结论以同行评议结果为准（待核实）。
- 可复现性问题在自主研究中被放大：人类研究的可复现危机（代码不公开、数据不公开、选择性报告）已是公开讨论的问题；智能体自主执行时，这些问题可能更隐蔽——因为执行过程没有人类目击者，失败记录更容易被系统性地忽略。

本节所有结论均为公开讨论复述，不是本站实测；本地没有 Agent 实验环境，任何自主研究复现均属示例未实测。

## 8. 技术瓶颈

- **假设质量瓶颈**：新颖性、有价值性、可检验性的自动判断方法缺失；假设生成容易陷入文献重组。
- **实验可靠性瓶颈**：代码错误、数据泄露、统计误用、选择性报告等问题在自主执行中更难发现。
- **可复现性瓶颈**：完整的代码、数据、环境、随机种子与失败记录公开机制缺失；发表偏倚使成功案例被高估。
- **评估瓶颈**：没有能同时度量假设新颖性、实验正确性、结论可复现性的评估体系；基准化会简化真实研究。
- **责任瓶颈**：自主研究产出的错误结论（如错误的实验结论被用于后续研究）由谁负责、如何撤回，尚无成熟规则。
- **领域局限瓶颈**：实验可自动化的领域与不可自动化的领域之间，自主研究的可行性差异极大；通用自主研究仍是假设，不是已证实的系统。

## 9. 成熟度判断

- **成熟度：实验研究中。** 判断依据一句话：自主研究原型在特定领域有流程自动化的演示，但假设质量判断、实验可靠性、可复现性三大问题未解决，尚不能按“自主做出有价值新发现”来交付或宣传。

## 10. 未来研究问题

- **已有研究在做**：自主研究实验记录的完整性标准、失败与阴性结果的强制报告机制、假设可检验性的自动检查。
- **已有研究在做**：人机协作研究工作流的对照实验——有智能体帮助 vs 无帮助的任务完成质量与效率比较。
- **本文推测**：未来五年最可能落地的不是“全自主研究智能体”，而是“人类定方向、智能体做执行与初筛、人类做关键判断”的人机协作研究工作流；检验标准是是否有经同行评议的、在真实科研流程中复现的人机协作增益案例。
- **本文推测**：自主研究的证据标准可能先从“可复现性基础设施”收敛（完整记录、失败公开、独立重跑），而非从“发现数量”收敛；检验标准是原型系统是否公开完整的复现包与失败记录。
