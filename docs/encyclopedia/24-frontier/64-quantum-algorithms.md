# 量子算法与复杂度

> 本篇是 [量子计算基础](01-quantum-computing.md) 的三级展开：总览用 Shor 与 Grover 划定了“特定结构的问题快得多”这一边界，本篇把边界展开为算法分类、复杂度结论与适用条件。线路写法见 [63 篇](63-qubits-gates-circuits.md)，纠错开销见 [65 篇](65-quantum-error-correction.md)。

## 1. 研究问题

量子算法研究要回答的问题不是“量子计算机能算什么”，而是三个更精确的问题：第一，**哪些问题存在可证明的量子加速**，加速是指数还是多项式；第二，加速的来源是什么——是问题本身的结构（如周期性），还是通用的搜索加速；第三，在含噪硬件上能跑的启发式算法，有没有可证明的优势，还是只有实验上的个案表现。

这三个问题必须分开回答，因为它们的证据强度完全不同：Shor 算法的指数加速是数学定理；Grover 算法的二次加速是数学定理，但工程价值要打折扣；变分算法的“优势”目前只是启发式实验结果，没有定理支撑。把三者混成一句“量子算法比经典快”，是本领域最常见的误读。

## 2. 基础理论

- **量子查询复杂度与 oracle 模型**：许多加速结论是在 oracle 模型里证明的——算法可以调用一个黑箱函数（oracle），代价按调用次数算。Grover 的 √N 加速是 oracle 调用次数的加速；oracle 本身的实现成本不计入该模型，落地时必须另算。
- **量子傅里叶变换（QFT）**：把计算基变换到傅里叶基的幺正操作；n 比特 QFT 的线路门数约为 O(n²)，而经典快速傅里叶变换处理 2ⁿ 个点需要 O(n2ⁿ) 运算。QFT 是 Shor 算法与相位估计的核心子程序，加速来自“对叠加态整体做变换”，而不是“并行算了 2ⁿ 个值再挑一个”。
- **相位估计**：给定一个幺正操作的本征态，估计其本征相位；精度与线路深度成反比。相位估计是连接 QFT 与实际应用（化学能谱、线性方程组求解）的桥梁，也是对相干时间要求最高的算法构件之一。
- **振幅放大**：Grover 算法的一般化——把“好解”的振幅逐步放大；它是二次加速的通用机制，适用于任何能构造“标记好解的 oracle”的搜索问题。
- **复杂度类 BQP**：量子计算机在多项式时间内以高概率解决的问题类。已知 BQP 包含 P，也包含一些不在 P 中的问题（如因数分解，假定经典上它不在 P 中）；但 BQP 与 NP 的关系仍是开放问题——**没有证据表明量子计算机能高效解决 NP 完全问题**，这是本篇要守住的一条边界。
- **哈密顿量模拟**：模拟一个量子系统的演化 e^{-iHt}；这是 Feynman 在 1982 年提出量子计算的原始动机，也是目前证据最强的“实用加速”候选方向之一。

## 3. 技术路线：按加速来源分类

### 3.1 基于隐藏结构的指数加速：Shor 算法族

- **Shor 算法（Peter Shor，1994）**：把因数分解转化为求周期问题，再用 QFT 求周期；时间复杂度关于输入位数是多项式的。同一框架覆盖离散对数问题，因此 RSA 与椭圆曲线密码同时受影响。定语必须写全：这需要容错机器与大量逻辑资源，今天的含噪机器跑不了实际规模的 RSA-2048；密码学应对（抗量子标准）归本站 13 域，本篇不复制。
- **隐藏子群问题**：Shor 算法是阿贝尔隐藏子群问题的特例；非阿贝尔情形（如图同构相关的某些问题）至今没有高效量子算法。这一对比说明：指数加速不是“量子力学给的免费午餐”，而是特定代数结构的产物。
- **密码学含义的边界**：Shor 算法威胁的是公钥体系，不是全部密码学——对称密码（如 AES）与哈希函数在 Grover 攻击下只需把密钥长度翻倍即可大致恢复同等安全强度（二次加速的对称含义），这与“公钥体系需整体迁移”是不同量级的应对。

### 3.2 通用二次加速：Grover 算法族

- **Grover 算法（Lov Grover，1996）**：在 N 个无结构项中找一个标记项，oracle 调用次数约为 √N，相对经典的约 N/2 是二次加速。二次加速在理论上有意义、在工程上要打折扣：oracle 实现成本、纠错开销、以及“经典算法也能用结构优化”的余地，都可能吃掉这部分优势。
- **振幅估计与计数**：Grover 框架的延伸，可用于估计满足条件的项数、做蒙特卡洛加速（量子振幅估计把经典蒙特卡洛的 1/ε² 采样复杂度降到约 1/ε）。这类算法是量子金融与风险建模文献里最常引用的方向，但同样需要容错硬件与高效 oracle，落地证据尚在早期。
- **误读澄清**：Grover 算法不加速“数据库查询”本身——真实数据库的 oracle 是经典数据结构，构造量子 oracle 的成本可能超过加速收益；它加速的是“能用量子线路高效标记解”的抽象搜索问题。

### 3.3 量子模拟：证据最强的实用方向

- **哈密顿量模拟**：用量子线路模拟另一个量子系统的演化；经典模拟的成本随系统规模指数增长，而量子模拟的成本随规模多项式增长（对局域哈密顿量）。这是 Feynman 的原始论证，也是今天量子化学、材料模拟文献的主线。
- **变分量子本征求解器（VQE）**：为含噪时代设计的混合算法——参数化线路制备试探态、经典优化器调参数、目标是逼近分子基态能量。VQE 是今天云上硬件最常见的化学负载，但“有没有可证明优势”仍是开放问题；小分子演示（如氢分子、氢化锂）的数值结果不能外推为“量子化学已落地”。
- **量子相位估计路线**：精度高、可证明，但需要深线路与容错硬件；它是 VQE 的“远期替代品”，不是竞争对手——两者的关系是“近期启发式”与“远期可证明”的分工。
- **动力学模拟与热态制备**：除基态能量外，含时演化、谱函数、有限温度性质也是模拟目标；这些方向的算法成熟度低于基态能量估计，本篇只点名，不展开。

### 3.4 启发式优化算法：QAOA 与退火

- **QAOA（量子近似优化算法，Farhi 等，2014）**：把组合优化问题编码为参数化线路，交替施加问题哈密顿量与混合哈密顿量，经典优化参数；层数 p 越大，近似质量理论上越好，但线路也越深。QAOA 在小规模问题上有实验结果，但“在什么规模上超过经典启发式”没有定论；经典优化算法（如模拟退火、禁忌搜索、专用求解器）也在进步，对照基线一直在变。
- **量子退火**：用缓慢变化的哈密顿量把系统从易制备的初态带到问题基态；D-Wave 等公司的退火机是专用设备，不是通用门模型计算机。退火机的“优势”声明历来争议最大，读这类结果时先看“问题定义 + 经典对照 + 是否含退火时间外的全部开销”三项。
- **变分算法的共同困境**：贫瘠高原（barren plateau）——参数化线路的梯度随比特数指数消失，优化在大规模时变得困难；这是变分路线从演示走向实用的主要理论障碍之一，已有缓解思路（局域代价函数、问题启发的线路结构），但无通用解法。

### 3.5 量子线性代数：HHL 与其边界

- **HHL 算法（Harrow、Hassidim、Lloyd，2009）**：在特定条件下（稀疏、良态矩阵，高效制备右端项与读出方式受限）以关于矩阵维数的对数时间求解线性方程组。HHL 常被误读为“量子计算机能指数加速解线性方程组”；真实边界是：输入输出的代价（数据加载与结果读出）往往吃掉加速，且“解”以量子态形式存在，读出全部解分量仍需指数成本。HHL 的价值在“以量子态为输入输出的子程序”场景，不在“替代经典线性求解器”。

## 4. 系统架构：算法如何落到混合工作流

可证明的量子算法（Shor、QFT、相位估计）与启发式算法（VQE、QAOA）落到系统里的形态完全不同：

- **容错算法工作流**：经典预处理 → 量子线路（含大量纠错编码的逻辑门，见 65 篇）→ 经典解码与后处理。线路深度与逻辑门数是主要成本，纠错开销乘数可达数个数量级。
- **变分混合工作流**：经典优化器提参数 → 量子芯片跑浅层参数化线路、采样估计期望值 → 经典优化器更新参数 → 循环。量子芯片在这里是“期望值估计器”，不是独立计算机；循环次数、采样噪声、优化器选择共同决定成败（详见 70 篇）。
- **oracle 成本的归属**：在混合工作流里，oracle（或问题哈密顿量）的构造是经典预处理的一部分；如果 oracle 构造本身是指数成本，算法的加速声明就不成立。评估任何量子算法声明时，第一步永远是问 oracle 从哪来。

## 5. 代表性实现与开源项目

- **Qiskit Algorithms 与 Cirq 示例库**：Qiskit、Cirq 等 SDK 自带 Shor、Grover、VQE、QAOA 的教学实现（见 69 篇）；这些实现是“能在模拟器上跑的小规模演示”，不是“已解决实际问题”的证据——小规模演示的价值在教学与验证，不在性能声明。
- **量子化学软件栈**：Qiskit Nature（历史项目，现已并入 Qiskit 生态的扩展）、PennyLane 的化学模块等提供分子哈密顿量构造与 VQE 流程；工具存在不等于优势存在，分子规模与精度仍是瓶颈。
- **尚无代表性商用系统**：按“在真实规模问题上稳定超越经典最优方法”的定义，今天不存在商用量子算法系统；已发表的“优势”案例均为特定基准或小规模演示。

## 7. 当前实验结果

本节只写来源与测试条件齐全的项：

- **小规模算法演示**：Shor 算法分解 15（3×5）等小整数的演示早在 2000 年代初即已完成；这类演示验证的是“线路逻辑正确”，不是“能分解大整数”——分解规模从 15 到 RSA-2048 之间差的不是“再努力一点”，而是容错资源的数量级。
- **VQE 小分子演示**：氢分子、氢化锂等小分子的基态能量估计已在多种硬件上演示；演示的分子规模与化学精度（1.6 毫哈特里量级的化学精度门槛）仍未同时达到实用标准，具体数值因硬件与误差缓解方法而异，本篇不转载单次实验的精度数字。
- **不写进本节的数字**：任何“量子算法比经典快多少倍”的宣传倍数——这类倍数的经典对照基线、问题规模、误差处理在学界存在争议，达不到来源与测试条件齐全的标准，本篇不采信。

## 8. 技术瓶颈

- **纠错开销吞没加速**：二次加速最容易被纠错开销吃掉——如果纠错让每个逻辑门慢 100 倍、贵 1000 倍，Grover 的 √N 优势在中小规模上可能是负收益；指数加速（Shor）对开销的容忍度更高，这也是 Shor 族与 Grover 族工程前景不同的根本原因。
- **数据加载瓶颈**：量子随机存取存储器（QRAM）——把经典数据高效加载为量子叠加态的设想设备——至今没有可规模化的实现；没有 QRAM，许多“大数据量子算法”的加速声明在输入端就不成立。
- **贫瘠高原**：变分线路在大规模时梯度消失，优化困难；这是理论障碍，不是“调参技巧”能绕过的。
- **对照基线漂移**：经典算法与模拟方法持续进步（张量网络模拟、经典优化启发式），昨天的“量子优势”基准可能被今天的经典方法追平；优势声明必须注明日期与对照方法，过期声明不应继续引用。

## 9. 成熟度判断

- **成熟度：理论探索中。** 判断依据一句话：Shor、Grover 等核心算法的数学证明早已完成，但“在真实规模问题上实现可证明优势”仍是未解决的开放问题；今天能跑的变分启发式算法缺乏可证明优势，远期可证明算法缺乏容错硬件，两头都不落地。

## 10. 未来研究问题

- **已有研究在做**：低开销的容错算法编译（把逻辑门数与 T 门数压下来）；问题启发的变分线路结构（避开贫瘠高原）；量子模拟在强关联材料、催化反应等具体科学问题上的精度与规模推进。
- **已有研究在做**：量子优势的判定标准——对给定问题，什么算“比经典好”，由哪组基准、哪种经典对照说了算；这是方法论问题，不是某个算法的问题。
- **本文推测**：未来五年最可能出现“优势”的地方不是通用算法，而是量子模拟的某个具体科学问题（例如特定材料的谱性质），且形式是“混合工作流中的子问题加速”，不是“整机替代经典超算”；检验标准是：是否有经同行评议、在真实科学问题上复现的案例出现。
