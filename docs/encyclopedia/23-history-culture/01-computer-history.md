# 计算机发展史：从机械计算到个人计算机

## 1. 一句话定义

计算机发展史是计算工具从人力辅助算具、机械计算器、电子计算机一路演进到个人计算机的过程史，核心线索是：计算如何一步步变得更快、更通用、更便宜、更贴近普通人。

## 2. 为什么需要它

学技术只看“现在怎么用”，容易把今天的样子当成理所当然。看历史才能明白：为什么计算机用二进制而不是十进制，为什么程序和数据要存在同一个存储器里，为什么个人计算机长成今天这样。很多今天的架构选择，都是历史上某次转折的直接后果；读懂转折，就读懂了技术为什么长成这样。

## 3. 核心含义：时间线与转折

### 3.1 机械时代：计算第一次脱离人手

- **1642 年，帕斯卡加法器**：法国数学家帕斯卡为帮父亲算税，做出用齿轮进位的加法器。转折在于：计算第一次由机器完成，不再依赖人的心算与手算——哪怕它只能加减。
- **1670 年代初，莱布尼茨阶梯计算器**：德国数学家莱布尼茨做出能四则运算的机械计算器（有资料记为 1672 年，也有记为 1673 年）。转折在于：机器从“只能加减”走向“通用算术”，计算工具开始有了通用性的苗头。
- **19 世纪初（1804 年前后），雅卡尔提花机**：法国织工雅卡尔用打孔卡片控制织布机的花纹。转折不在于织布，而在于**程序与机器分离**：换一张卡片，机器就换一种行为——“指令”第一次成为可以独立于机器存在的对象。
- **1822 年起，巴贝奇差分机；1830 年代，分析机**：英国数学家巴贝奇先设计只能算数表的差分机，又提出更通用的分析机：设想了存储器、运算器、输入输出和打孔卡片程序，几乎就是现代计算机的逻辑结构。两台机器在他生前都没建成，转折在于**思想超前于制造能力**：通用可编程计算机的概念，比能造出它的工艺早了一个多世纪。
- **1843 年，阿达·洛芙莱斯的译注**：洛芙莱斯在翻译一篇介绍分析机的论文时写下长篇注释，其中包含一则计算伯努利数的算法，常被视为第一个计算机程序。转折在于：**软件第一次作为独立于硬件的思想出现**——程序可以被讨论、被写下来、被评价，而不必等机器造出来。
- **1890 年，霍勒里斯制表机**：美国人口普查用打孔卡片制表机处理数据，把原来要花数年的人工统计缩短到数月。转折在于：计算第一次进入大规模数据处理，计算机从科学家的工具变成组织的工具。

### 3.2 电子时代：速度与通用性的两次飞跃

- **1946 年，ENIAC 公开亮相**：美国宾夕法尼亚大学的 ENIAC 用近两万只电子管实现电子计算，每秒约 5000 次运算，比机电式机器快上千倍。它常被说成“第一台通用电子计算机”——准确的说法是第一台大规模通用电子数字计算机；更早的电子机器（如 1937 年起研制的 ABC、1943 年的 Colossus）都是专用或实验性质。转折在于：**电子速度证明了通用计算可以实用**，但 ENIAC 靠接线改程序，换一次任务要重新接线，通用性还不完整。
- **1945 年，冯·诺依曼《EDVAC 报告草案》；1948 年，曼彻斯特“婴儿机”**：冯·诺依曼总结出“存储程序”思想——程序和数据一样存在存储器里，机器按顺序取指令执行；曼彻斯特小组 1948 年造出第一台真正按存储程序运行的机器。转折在于：**换程序不再需要改硬件**，计算机从此成为“改软件就能改用途”的通用机器，这是今天所有计算机（包括手机）的祖先结构。
- **1947 年，晶体管；1958 年，集成电路**：贝尔实验室发明晶体管，替代体积大、易坏、耗电多的电子管；1958 年基尔比与诺伊斯各自做出集成电路，把多个元件做到一块芯片上。转折在于：**计算机从“房间大小的设备”走向“可以缩小、可以量产”的产品**，没有这一步，就没有后来的小型机，更没有个人计算机。
- **1951 年，UNIVAC I；1964 年，IBM System/360**：UNIVAC I 是第一台商用计算机，计算机开始卖给企业与政府；System/360 则是一整个兼容机型系列，同一套软件能在不同档次的机器上跑。转折在于：**计算机从“每台都是孤品”变成“有生态的产品线”**，软件兼容性第一次成为商业战略。

### 3.3 个人时代：计算机走出机房

- **1971 年，Intel 4004 微处理器**：第一块商用微处理器把 CPU 做到一块芯片上。转折在于：**计算机的核心部件变成可以批量买到的商品**，造一台计算机不再需要一家大公司。
- **1975 年，Altair 8800**：美国 MITS 公司推出基于 Intel 8080 的套件机，通过杂志邮购销售，爱好者自己组装。它本身很难用，却点燃了个人计算机爱好者社群。转折在于：**计算机的买家第一次从机构变成个人**。
- **1976 年 Apple I、1977 年 Apple II**：乔布斯与沃兹尼亚克先做出手工组装的 Apple I，又推出开箱即用的 Apple II，带键盘、彩色图形和扩展槽，卖给普通用户。转折在于：**个人计算机从“爱好者的套件”变成“开箱即用的商品”**。
- **1981 年，IBM PC**：IBM 推出采用开放总线与第三方操作系统（MS-DOS）的个人计算机，各家厂商可以兼容生产。转折在于：**标准与兼容压倒了单一品牌**，PC 兼容机生态从此主导市场，个人计算机的价格一路下降。
- **1984 年，苹果 Macintosh**：把图形界面与鼠标带给大众用户。转折在于：**计算机的操作从“记住命令”变成“看得见、点得到”**，普通人不需要先学计算机语言就能用计算机。

### 3.4 一条主线

机械时代解决“算得出来”，电子时代解决“算得快、改得动”，个人时代解决“人人用得起、用得上”。每一次转折都不是单纯的技术升级，而是**使用者的范围扩大了一圈**：从数学家，到机构，到爱好者，到所有人。

## 4. 分类：按时代分期

- 机械计算时期（17 世纪–19 世纪）：齿轮与打孔卡片，算得慢、用途专。
- 电子计算机时期（1940 年代–1960 年代）：电子管到集成电路，通用性与速度确立。
- 小型化与个人化时期（1970 年代–1980 年代）：微处理器、个人计算机、图形界面。
- 联网时期（1990 年代起）：计算机连成网络，单机史汇入互联网史，见本域下一篇。

## 5. 典型应用：这些转折在今天的延续

- 存储程序思想：今天的 CPU、手机、服务器仍按“取指令、执行、存结果”循环工作，见 [CPU 组成与指令集](../01-computer-basics/02-cpu-instruction-set.md)。
- 打孔卡片的“程序与机器分离”：今天的软件分发、应用商店、云端部署，都是这一思想的放大版。
- 兼容机生态：今天“同一套软件跑在不同档次设备上”的做法，直接来自 System/360 与 IBM PC 的兼容策略。
- 图形界面与鼠标：今天的触屏、窗口、图标，都是 1984 年那次“看得见、点得到”的延续。

## 6. 限制与常见误解

- **“ENIAC 是第一台计算机”是简化的说法**：ENIAC 是第一台大规模通用电子数字计算机，但更早有专用电子机器（ABC、Colossus），更早还有机械计算机；“第一”取决于怎么定义“计算机”。
- **“图灵造了第一台计算机”是误解**：图灵 1936 年提出的是图灵机——一种思想模型，定义了“可计算”的边界；它影响了计算机理论，但不是一台造出来的机器。
- **“个人计算机一出现就人人会用”是误解**：Altair 8800 需要自己组装、自己写程序；直到 Apple II、IBM PC、Macintosh 一步步降低门槛，个人计算机才真正大众化。
- **历史分期只是教学工具**：真实历史没有干净的分界线，机械、电子、个人三个阶段长期重叠；分期是为了讲清主线，不是给历史划界。

## 7. 小结

计算机从齿轮加法器走到个人计算机，靠三次转折：机械计算让机器替人算，存储程序让机器通用可改，微处理器与兼容生态让机器属于个人。下一篇讲这些单机如何连成网络。
