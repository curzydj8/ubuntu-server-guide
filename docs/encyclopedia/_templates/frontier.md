# 前沿研究模板（使用说明）

> 本文件是模板，不是正式文章，不进导航。写新专题时复制本文件结构，删掉本说明块。
> **硬规则**：性能数字必须有来源与测试条件；预测必须写成预测；成熟度必须按专题标注，不得含糊。
> **不适用的节直接删除，不要硬填**。

# （研究方向）

## 1. 研究问题

（这个方向要解决什么问题？为什么现有技术解决不了？）

## 2. 基础理论

（依赖哪些已有理论？每个理论一句话 + 来源。）

## 3. 技术路线

（主流路线有哪几条？各走什么思路？不要只列名词，每条路线一句话讲清做法。）

## 4. 系统架构

（代表性系统的组成部分与关系；没有成熟系统的写“尚无代表性商用系统”。）

## 5. 代表性实现与开源项目

（项目名 + 一句话定位 + 链接；只列真实存在的项目，不要列传闻中的项目。）

## 6. 关键论文与标准

（论文标题 + 作者/年份 + 链接；标准写编号与名称；没有则写“暂无公开标准”。）

## 7. 当前实验结果

（数字 + 来源 + 测试条件三件套，缺一件就不要写这个数字。）

## 8. 技术瓶颈

（卡在哪几处？是理论、工艺、成本还是生态问题？）

## 9. 成熟度判断

（本专题成熟度：成熟应用 / 工程发展中 / 实验研究中 / 理论探索中，并用一句话说明判断依据。）

## 10. 未来研究问题

（开放问题列表；每个问题标注是“已有研究在做”还是“本文推测”，推测必须明说。）
