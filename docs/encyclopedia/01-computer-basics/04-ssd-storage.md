# SSD 存储原理

## 1. 本章目标

读完本篇，能说清 SSD 里没有磁盘和磁头、数据到底存在哪、为什么用久了会变慢、以及 TRIM、磨损均衡这些词各自在解决什么问题。

## 2. 背景与问题

上一篇讲到存储层次的底端是外存：断电后数据还在，但速度最慢。机械硬盘（HDD）慢的原因是物理的——磁头要寻道、盘片要旋转，再快的电路也绕不过机械运动。SSD 的思路是把“存数据”这件事从机械运动换成半导体：用闪存芯片存电荷，没有寻道、没有旋转，随机访问不再有机械惩罚。但闪存有自己的脾气：不能原地改写、写之前必须先擦除、擦写次数有限。SSD 的全部内部机制，都是在伺候这三条脾气。

## 3. 总体架构

一块典型 SSD 的内部（文字结构图）：

```
  主机 ──接口──▶┌─────────────┐
  （SATA /     │  主控芯片    │
   NVMe）      │  （FTL 固件、 │
                │   ECC、加密）│
                └──────┬──────┘
                       │ 多通道并行
        ┌──────────────┼──────────────┐
        ▼              ▼              ▼
┌─────────────┐ ┌─────────────┐ ┌─────────────┐
│  闪存芯片    │ │  闪存芯片    │ │  缓存 DRAM   │
│  （NAND     │ │  （NAND     │ │  （映射表、  │
│   颗粒）    │ │   颗粒）    │ │   写缓冲）  │
└─────────────┘ └─────────────┘ └─────────────┘
```

- **闪存颗粒（NAND）**：真正存数据的芯片，由大量存储单元组成；读按页、擦除按块（见第 4 节）。
- **主控芯片**：SSD 的大脑，跑 FTL 固件，负责地址翻译、磨损均衡、垃圾回收、纠错。
- **缓存 DRAM**：存地址映射表和写缓冲，让主控查表不用每次都读闪存；掉电时 DRAM 里的东西会丢（见第 7 节）。

## 4. 工作机制

### 4.1 闪存单元：电荷就是数据

NAND 单元通过浮栅或电荷捕获层里困住的电荷量来表示数据。一个单元存几位，由此分档：

| 类型 | 每单元位数 | 特点 |
|---|---|---|
| SLC | 1 | 最快、最耐擦写、最贵，容量最小 |
| MLC | 2 | 折中 |
| TLC | 3 | 当前消费级主流，容量与成本平衡 |
| QLC | 4 | 容量最大、成本最低，擦写寿命最短、写入速度最易掉速 |

规律：每单元存的位数越多，区分不同电荷状态的裕量越小，擦写寿命按 SLC > MLC > TLC > QLC 的数量级递减。具体擦写次数以厂商 datasheet 为准，不同代际、不同颗粒差异很大，不要背绝对数字。

### 4.2 读按页、擦除按块：不能原地改写

闪存的两个不对称操作：

- **读、写以“页”（通常 4KB–16KB）为单位**；**擦除以“块”（由几百页组成）为单位**，而且擦除前必须先把块里还有效的数据搬走。
- 因此“改写”一个页的实际过程是：把新数据写到一个空页，把旧页标记为无效，更新映射表——旧数据不是被当场擦掉，而是等垃圾回收时连同整块一起处理。这就是 SSD 内部写操作比看起来多的根源。

### 4.3 FTL：闪存翻译层

主机看到的是一块连续的逻辑地址空间（LBA），闪存实际是离散的页和块。**FTL（Flash Translation Layer）**是主控里的固件层，维护“逻辑地址 → 物理页”的映射表。所有上层读写都要经过它翻译；磨损均衡、垃圾回收、坏块管理都在这一层实现。FTL 是 SSD 区别于“裸闪存”的关键：没有它，操作系统要直接面对闪存的擦写规则。

### 4.4 磨损均衡：把擦写次数摊平

闪存每个块的擦写次数有限，如果总写同一个块，它会先坏。磨损均衡分两种：

- **动态磨损均衡**：新数据优先写到擦写次数少的空块。
- **静态磨损均衡**：连长期不动的冷数据也会定期被搬家，让所有块的擦写次数趋于平均——代价是额外的内部写入。

### 4.5 垃圾回收与写入放大

无效页攒多了，主控要在后台做**垃圾回收**：挑一个无效页多的块，把其中还有效的页搬到别处，然后整块擦除，腾出空白块。由此产生**写入放大（Write Amplification，WA）**：实际写入闪存的数据量 ÷ 主机发来的写入量。WA 大于 1 是常态；顺序大块写入的 WA 接近 1，随机小写入的 WA 可能远大于 1——这就是“随机写伤盘”的定量说法。

### 4.6 TRIM：让 SSD 知道哪些页已经没用了

文件系统删文件时，传统上只改自己的元数据，不通知磁盘。没有通知，SSD 会把已删除文件的页继续当有效数据，在垃圾回收时白白搬运。**TRIM（SATA）/ Deallocate（NVMe）**就是这条通知通道：操作系统告诉 SSD“这些逻辑地址已经没用了”，SSD 把对应页标为无效，垃圾回收就不用再搬它们。TRIM 不提高峰值速度，它减少的是无效劳动；长期不用 TRIM 的盘，写性能下降会更明显。

### 4.7 预留空间（Over-Provisioning）

SSD 实际闪存容量大于标称容量，多出来的部分叫预留空间，用来做垃圾回收周转、换坏块、放映射表。预留空间越大，垃圾回收越从容，满盘时的性能下降越缓；代价是用户可用容量变小。消费级产品常见做法是出厂预留一部分，用户也可以自己少分区、多留空闲，效果类似。

## 5. 关键设计取舍

- **容量换寿命**：每单元位数越多容量越便宜，但寿命与持续写入性能越差——TLC/QLC 成为消费级主流，是成本取舍，不是技术“退步”。
- **性能换写入量**：静态磨损均衡、垃圾回收、ECC 纠错都在用额外的内部写入和算力换寿命与可靠性；SSD 的标称速度是在新盘、空盘、顺序读写下测的，日常表现要看满盘与随机写。
- **缓存换掉电风险**：DRAM 缓存提速明显，但突然断电时缓存中未落盘的写可能丢失；企业级产品用掉电保护（电容 + 固件）对冲，消费级产品通常没有或只有部分保护。

## 6. 分类与变体

- **按接口与协议**：SATA（走 AHCI，SATA III 上限约 600MB/s）与 NVMe（走 PCIe，队列深度与并行度远高于 AHCI，规范定义最多 64K 队列 × 64K 命令，而 AHCI 只有一个 32 命令队列）。接口是瓶颈时，颗粒再快也跑不上去。
- **按形态**：2.5 英寸 SATA、M.2（SATA 或 NVMe，注意 M.2 只是形态，协议要看具体产品）、U.2（企业级）。买盘先看协议再看形态，不要只看插口形状。
- **按用途**：消费级（成本优先，TBW 标称较低）与企业级/数据中心级（掉电保护、更高 TBW、更稳的持续性能），差别主要在固件策略与用料，不只在颗粒。

## 7. 应用与限制

- 应用：系统盘、数据库、虚拟机、一切对随机读写敏感的场景；是机械硬盘在性能敏感位置的直接替代。
- 限制：
  - 寿命是擦写预算，不是时间：看厂商的 TBW（总写入字节数）或 DWPD（每天全盘写入次数），结合自己的写入量估算，不要只看“能用几年”。
  - 满盘与长期无 TRIM 会让写性能下降，留 10%–20% 空闲是最简单的缓解办法。
  - 突然断电可能丢缓存中的写：重要数据靠备份与文件系统日志保护，不要把“SSD 可靠”等同于“数据不会丢”。
  - 数据恢复比机械硬盘难：TRIM 后的页、FTL 映射丢失后，恢复成功率低；删除前确认备份。
- 常见误解：
  - “SSD 不怕震所以不会坏”：错。不怕机械冲击不等于没有寿命与固件问题，擦写预算和主控固件同样会出故障。
  - “TRIM 是碎片整理”：错。TRIM 是删除通知，不是整理；SSD 没有寻道，不需要也不应该做传统碎片整理。
  - “标称速度就是日常速度”：错。标称多为空盘顺序读写；日常看随机读写与满盘持续写入表现。

## 8. 可核验示例：用 lsblk 看本机的磁盘与 discard 支持

> 环境：Ubuntu 24.04，普通用户权限，只读命令，无风险。以下输出为本文写作时在代理 VM 上实际运行的结果；**虚拟机的磁盘是虚拟设备**，其 rotational、discard 标志反映的是虚拟化层的呈现，不等于物理硬盘参数，命令本身通用。

```bash
lsblk -d -o NAME,SIZE,ROTA,TRAN
lsblk -D -o NAME,DISC-GRAN,DISC-MAX
```

实际输出：

```
NAME  SIZE ROTA TRAN
vda   6.9G    1 virtio
vdb   7.5G    1 virtio
vdc   1.2G    1 virtio
vdd   150G    0 virtio
NAME   DISC-GRAN DISC-MAX
vda           0B       0B
vdb         512B       2T
vdc           0B       0B
vdd           4K      32M
```

怎么读：`ROTA` 是“是否旋转”标志，1 表示传统机械盘特征、0 表示非旋转（SSD 类）；但虚拟磁盘上这个标志由虚拟化层决定，不能据此判断物理介质——vda/vdb/vdc 在虚拟机里报 1，不代表它们真是机械盘。`DISC-GRAN`/`DISC-MAX` 是 discard（TRIM）粒度与上限：vdb（512B 粒度）与 vdd（4K 粒度）报告了 discard 能力，vda/vdc 报 0 表示该设备不报告 discard 能力。物理机上还可以用 `fstrim`（本机已安装，未实测执行）对已挂载文件系统下发 TRIM；是否生效要看文件系统挂载选项与设备支持，执行前先确认备份。
