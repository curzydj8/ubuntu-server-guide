# 线性回归与逻辑回归：一条直线，两种任务

## 1. 一句话定义

线性回归用输入特征的加权和预测一个连续数值；逻辑回归对同一个加权和再套一个 sigmoid 函数，输出样本属于某一类的概率——名字里有“回归”，干的却是分类的活。

## 2. 为什么需要它

很多预测问题本质上是“给几个输入，猜一个输出”，而最简单的猜法就是加权求和：房价大概随面积、地段、房龄线性变化；一个人会不会逾期，大概随收入、负债、历史逾期次数变化。线性回归与逻辑回归就是把这个直觉做成可训练、可检验的模型。

它们值得先学，有四个理由：

- **可解释**：每个特征都有一个权重，正负表示方向、大小表示影响，模型“为什么这么判”能直接说出来。这是神经网络与集成方法做不到的。
- **快且省**：训练与预测的计算量都很小，小数据上也能工作，是上线前必须打败的基线。
- **诊断价值**：基线模型表现差，能帮你定位问题在特征还是在模型：线性基线都学不会，说明特征里缺信息；线性基线已经很好，复杂模型未必值得上。
- **处处是构件**：逻辑回归的 sigmoid 与交叉熵损失、线性模型的正则化思想，在[深度学习与神经网络](02-deep-learning-neural-networks.md)里会以同样的形式再次出现。

反过来，输入与输出之间明显不是直线关系时（例如剂量与疗效先升后降），它们就不够用，那是决策树与神经网络的领地，见[决策树与集成方法](05-decision-tree-ensemble.md)。

## 3. 核心含义

### 3.1 线性回归：加权和 + 最小二乘

线性回归假设输出是输入的加权和再加一个截距：

```text
ŷ = w₁x₁ + w₂x₂ + … + wₙxₙ + b
```

其中 `x₁…xₙ` 是特征，`w₁…wₙ` 是权重，`b` 是截距（输入全为 0 时的预测值）。训练的目标是找到一组权重，让预测值与真实值尽可能接近。最常用的“接近”标准是**最小二乘**：让所有样本的误差平方和最小：

```text
最小化  Σ (yᵢ − ŷᵢ)²
```

平方有两个作用：一是正负误差不互相抵消，二是大误差被罚得更重。求解有两条路：特征不多时可用闭式解 `w = (XᵀX)⁻¹Xᵀy` 一步算出；特征多或数据量大时用梯度下降一小步一小步迭代（梯度下降的思想见[深度学习与神经网络](02-deep-learning-neural-networks.md)第 4.4 节）。

下面这段代码用 numpy 的最小二乘闭式解手算了一次线性回归，演示数据是 6 条“面积（百平方米）→ 房价（万元）”的编造样本，真实运行输出附后：

```python
import numpy as np
# 演示数据（编造，仅用于演示最小二乘的计算过程）
x = np.array([0.5, 0.8, 1.0, 1.2, 1.5, 2.0])
y = np.array([120, 180, 210, 250, 310, 400])
X = np.column_stack([np.ones_like(x), x])
w, *_ = np.linalg.lstsq(X, y, None)
pred = X @ w
print(f"w0(截距)={w[0]:.2f} w1(斜率)={w[1]:.2f}")
print("pred:", np.round(pred, 1).tolist())
print(f"mse={np.mean((y-pred)**2):.1f}")
print(f"predict x=1.8 -> {w[0]+w[1]*1.8:.1f}")
```

```text
w0(截距)=27.08 w1(斜率)=186.79
pred: [120.5, 176.5, 213.9, 251.2, 307.3, 400.7]
mse=6.1
predict x=1.8 -> 363.3
```

读法：面积每多 1 个单位（100 平方米），房价平均多约 186.8 万元；面积 180 平方米的房子，模型预测约 363.3 万元。注意这只是 6 条编造样本上的算术演示，不是真实房价模型——样本量这么小，任何结论都不作数。

线性回归成立时依赖几个经典假设，违反时结论要打折：关系本身近似线性、误差的方差大致稳定（同方差）、样本之间相互独立、特征之间没有严重的共线性（两个特征几乎是同一个量的两种说法）。这些假设主要影响“权重能不能信”，对“预测准不准”的影响相对小——预测与推断是两回事，见第 6 节。

### 3.2 逻辑回归：加权和 + sigmoid，输出概率

逻辑回归先算与线性回归一样的加权和 `z = w·x + b`，再把 `z` 送进 sigmoid 函数，把它压到 0 到 1 之间，当作“属于正类的概率”：

```text
σ(z) = 1 / (1 + e^(−z))，  p(y=1|x) = σ(w·x + b)
```

sigmoid 的形状是 S 形：`z = 0` 时概率正好是 0.5，`z` 越大概率越接近 1，越小越接近 0。本机实测的三个点：`σ(−2) ≈ 0.119`，`σ(0) = 0.5`，`σ(2) ≈ 0.881`（numpy 计算）。换一个角度看，逻辑回归假设的是“对数几率是线性的”：`ln(p/(1−p)) = w·x + b`，即几率（odds）的对数随特征线性变化。

训练时逻辑回归没有闭式解，只能迭代优化，用的损失是**交叉熵**（预测给正确类别的概率越低，损失越大；定位见[深度学习与神经网络](02-deep-learning-neural-networks.md)第 4.3 节）。预测时再加一条规则：概率超过阈值（默认 0.5）判为正类，否则判为负类。阈值不是模型的一部分，是业务选择：漏报代价高时可以调低阈值、宁可误报，见[模型训练与评估](03-model-training-evaluation.md)第 4.4 节的指标取舍。

### 3.3 两者的关系与区别

|  | 线性回归 | 逻辑回归 |
|---|---|---|
| 任务 | 回归：输出连续数值 | 分类：输出类别概率，再经阈值判类别 |
| 输出范围 | 全体实数 | 0 到 1 之间 |
| 核心公式 | `ŷ = w·x + b` | `p = σ(w·x + b)` |
| 训练损失 | 均方误差（最小二乘） | 交叉熵 |
| 求解 | 有闭式解，也可用梯度下降 | 无闭式解，迭代优化 |
| 决策边界 | 不适用 | 线性的（概率为 0.5 的点连成直线或超平面） |

一句话：两者共享“线性加权和”这个骨架，区别在骨架外面套了什么——直接输出就是回归，套 sigmoid 再阈值化就是分类。

## 4. 分类与关键方法

### 4.1 线性回归的变体

- **一元与多元回归**：一个特征叫一元，多个特征叫多元；多元时每个权重是在“其他特征不变”的条件下该特征的影响。
- **多项式回归**：给模型加入 `x²`、`x³` 等项。它拟合的是曲线，但对参数来说仍是线性的——“线性”指的是对参数线性，不是对特征线性。
- **岭回归（Ridge，L2 正则化）**：在最小二乘目标里加一项，罚权重的平方和，让权重整体变小、分布均匀。特征间共线性严重时，岭回归能让权重稳定下来。
- **Lasso（L1 正则化）**：罚权重的绝对值之和，倾向把不重要特征的权重直接压到 0，兼有特征选择的作用。
- **弹性网（Elastic Net）**：L1 与 L2 混合，兼顾两者的优点。正则化的定位见[模型训练与评估](03-model-training-evaluation.md)第 4.5 节。

### 4.2 逻辑回归的变体

- **二分类逻辑回归**：最常见的形式，输出“是 / 否”的概率。
- **多分类逻辑回归（Softmax 回归）**：把 sigmoid 换成 Softmax，同时输出属于每个类别的概率，概率之和为 1。
- **有序逻辑回归**：目标类别有顺序（如差 / 中 / 好）时使用；细节待后续深入篇。
- **带正则化的逻辑回归**：与线性回归一样可加 L1/L2 惩罚，防止在小样本上过拟合。

### 4.3 使用前必须做的特征处理

- **标准化 / 归一化**：正则化与梯度下降对特征尺度敏感，量纲差几个数量级的特征要先拉到同一尺度；不加正则化、用闭式解时这一步对结果无影响。
- **类别特征编码**：性别、城市这类类别特征要转成数值（独热编码等）才能进入加权和。
- **缺失值与异常值处理**：最小二乘对异常值敏感，一个离群点就能把直线拉偏；建模前先看数据分布，不要直接把原始数据喂给模型。

## 5. 典型应用

- **房价与销量预测**：线性回归的经典场景，输入面积、地段、房龄等，输出价格或销量；业务上更看重可解释的权重，而不只是预测分数。
- **信用评分与风控初筛**：逻辑回归输出逾期概率，权重直接对应每项特征对风险的贡献，监管与业务复核都要求这种可解释性；阈值按漏报与误报的代价定。
- **疾病风险评估**：逻辑回归输出患病概率，输入年龄、指标、病史等；这里概率的校准（预测 30% 是否真有约三成发病）比单纯分对错更重要。
- **营销响应预测**：逻辑回归预测用户会不会点开、会不会购买，用于排序投放优先级；配合[模型训练与评估](03-model-training-evaluation.md)的精确率与召回率取舍。

## 6. 限制与常见误解

- **只能表达线性关系**：输入与输出之间是曲线、是“先升后降”、是特征之间的交互作用，线性模型都抓不住。残差图呈现明显形态（而不是随机散布），就是线性假设失效的信号。
- **对异常值敏感**：最小二乘用误差平方，大误差被平方放大，一个离群点就能显著改变权重。稳健回归是后续深入篇的范围。
- **多重共线性让权重失真**：两个特征高度相关时，权重会在两者之间“打架”，单个权重的数值不再可信——预测可能还行，解释已经失真。岭回归与特征筛选是常用缓解手段。
- **逻辑回归的决策边界是线性的**：两类样本需要曲线才能分开时，逻辑回归再怎么调参也分不开；这是模型能力边界，不是调参问题。
- **“逻辑回归是回归”是误解**：名字是历史遗留，它输出概率、做的是分类；按任务分，它属于分类方法。
- **输出的概率不等于“模型有多确定”**：逻辑回归的概率是“在模型假设下的类别概率”，不是置信度；样本不平衡、分布漂移时概率会系统性失真，使用前要校准、要验证。
- **预测准不等于因果**：权重显著、预测准确，只能说明统计关联，不能说明“改这个特征就能改结果”。干预与决策需要因果分析，不是回归能给的。
- **外推要小心**：训练数据范围之外的预测，是把直线无限延长的结果；超出范围后线性关系是否还成立，模型自己不知道。

## 7. 小结

线性回归与逻辑回归共享“输入的加权和”这个骨架：直接输出是回归，套 sigmoid 输出概率再阈值化是分类；前者用最小二乘训练，后者用交叉熵迭代优化；两者都简单、可解释、是必须打败的基线，边界同样清楚——只能表达线性关系，对异常值与共线性敏感，曲线关系要交给决策树与神经网络。
