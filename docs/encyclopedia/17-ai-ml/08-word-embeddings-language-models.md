# 词向量与语言模型：从词的表示到预训练

## 1. 一句话定义

词向量是把词表示成稠密数字向量的方法，语言模型是给一段文本打分、预测下一个词的概率模型；两者合起来，让计算机能用数值运算处理语言的含义。

## 2. 为什么需要它

计算机只认数字，语言却是离散符号：“猫”“狗”“汽车”在计算机眼里本来只是三个互不相干的编号。直接用编号（one-hot）表示词有两个毛病：第一，词表有多大、向量就有多长，几万维的稀疏向量又大又难算；第二，任意两个词的向量都正交，“猫”和“狗”的距离与“猫”和“汽车”的距离完全一样——语义信息全丢了。

词向量要解决的就是这个问题：让意思相近的词在向量空间里靠得近，让“国王 − 男人 + 女人 ≈ 女王”这样的语义关系能用向量运算表达出来。语言模型则更进一步：它不只表示单个词，还要建模词与词之间的组合规律——给定前文，下一个词最可能是什么。没有这两个基础，文本分类、机器翻译、对话系统都无从下手。

## 3. 核心含义

### 3.1 分布式假设：词义藏在上下文里

词向量背后的思想叫**分布式假设**：出现在相似上下文里的词，意思也相似。“猫爱吃鱼”和“狗爱吃骨头”结构相同，“猫”和“狗”在句中的位置与邻居类似，于是它们的向量也该相近。这句话反过来也成立：一个词的意思，不由词典定义决定，而由它在真实文本里常和哪些词一起出现决定。

词向量的两个关键性质由此而来：

- **稠密**：每个词对应一个几十到几百维的实数向量，维度远小于词表大小，数值处处非零，信息压缩在每一维里。
- **几何即语义**：向量之间的余弦相似度对应语义相似度；向量之间的差对应语义关系。一个训练好的词向量空间里，“巴黎 − 法国 + 中国”的最近邻往往是“北京”——这不是人为规定的，是从大量文本里统计出来的。

### 3.2 语言模型：给文本算概率

语言模型回答一个问题：一段文本出现的概率有多大？形式化地说，给定词序列 $w_1, w_2, \dots, w_n$，语言模型估计的是联合概率 $P(w_1, w_2, \dots, w_n)$。按链式法则，它可以拆成每个词在给定前文下出现的条件概率的乘积：

```text
P(w1, w2, ..., wn) = P(w1) · P(w2|w1) · P(w3|w1,w2) · ... · P(wn|w1,...,w(n-1))
```

早期做法是 n 元模型（n-gram）：只看前 n−1 个词估计下一个词，例如三元模型用前两个词预测第三个词。n-gram 的问题是数据稀疏——词组合的数量随 n 指数增长，大多数长组合在训练语料里从未出现过，概率只能靠平滑、回退等办法凑。神经语言模型用神经网络代替查表计数：前文先变成向量，再由网络预测下一个词的分布，相似的前文会得到相似的预测，稀疏问题因此大为缓解。现代大模型在本质上仍是神经语言模型，只是规模与结构变了。

## 4. 分类/关键方法

### 4.1 静态词向量：一个词，一个向量

静态词向量的意思是：每个词在词表里只对应一个固定向量，与它出现在哪个句子里无关。

- **Word2Vec（2013 年，Mikolov 等人）**：用浅层神经网络训练词向量，有两种训练目标。CBOW 是“看上下文、猜中间词”；Skip-gram 是“看中间词、猜上下文”。Skip-gram 在低频词上表现较好，CBOW 训练较快。训练完成后，网络的权重矩阵就是词向量表。它的成功让“词向量”从研究概念变成工程标配。
- **GloVe（2014 年，Pennington 等人，斯坦福）**：从全局词共现矩阵出发：先统计整个语料里每对词共同出现的次数，再让向量的点积去拟合共现次数的对数。它把“全局统计”和“局部预测”两种思路结合起来，在类比任务上与 Word2Vec 各有胜负。
- **FastText（2016 年，Facebook）**：把词拆成字符 n-gram 子词再求和得到词向量。好处是能处理未登录词：没见过的新词也能由它的子词拼出一个向量，对拼写形态丰富的语言和拼写错误更稳健。

静态词向量的共同局限是**一词多义处理不了**：“苹果”在“吃苹果”和“苹果公司”里是同一个向量，含义只能取平均。这正是上下文相关表示要解决的问题。

### 4.2 从静态到上下文相关：一个词，随语境变

- **ELMo（2018 年，Allen AI 研究所）**：用双向 LSTM 语言模型为每个词生成向量，同一个词在不同句子里得到不同的向量。“苹果”在水果语境和公司语境下的表示终于分开了。ELMo 的用法是把它的向量作为特征拼到下游任务的输入里，原任务模型照旧。
- **BERT（2018 年，Devlin 等人，Google）**：基于 Transformer 编码器（注意力思想见[深度学习与神经网络](02-deep-learning-neural-networks.md)），用两个自监督任务预训练：遮住句子里一部分词让模型猜（掩码语言模型），以及判断两句话是否相邻。BERT-base 约 1.1 亿参数。BERT 之后的主流范式变成“预训练 + 微调”：先在海量无标注文本上预训练一个通用模型，再在具体任务的有标注数据上微调（微调思路见[文本分类与序列标注](09-text-classification-sequence-labeling.md)）。
- **GPT 系列（2018 年起，OpenAI）**：与 BERT 的双向编码不同，GPT 是单向自回归语言模型：只看前文、预测下一个词，生成文本时一个词一个词往外吐。GPT-3（2020 年）约 1750 亿参数，展示出“规模上去后，模型不用微调、只给几个例子就能做新任务”的涌现行为。BERT 与 GPT 的路线分野——理解式编码与生成式解码——至今仍是预训练模型的两条主线。

### 4.3 演进脉络：一句话看懂

```text
one-hot 编号 ──► 静态词向量 ──► 上下文相关表示 ──► 预训练语言模型
（无语义）    （Word2Vec / GloVe）  （ELMo）      （BERT / GPT）
              一个词一个向量        一词多向量     预训练 + 微调 / 提示
```

每一步解决的是上一步的短板：静态向量解决“编号无语义”；上下文相关解决“一词多义”；预训练解决“每个任务都要从头训、标注数据不够”的问题。代价也是一路递增的：参数量、数据量、算力需求逐级放大。

## 5. 典型应用

- **语义检索与推荐**：把查询和文档都变成向量，按向量相似度找相关内容；同义词、近义词不需要人工维护词表，相似度自己算出来。
- **文本分类与情感分析**：词向量或预训练模型提供文本表示，分类器在表示之上做判断（方法见[文本分类与序列标注](09-text-classification-sequence-labeling.md)）。
- **机器翻译与文本生成**：语言模型建模词序列的组合规律，是翻译、摘要、对话系统的底座；生成式模型直接按概率逐词生成文本。
- **拼写纠错与输入法**：语言模型给候选词打分，“吃苹果”比“吃苹国”概率高，纠错与联想输入都靠这个打分。

## 6. 限制与常见误解

- **向量相似不等于真正理解**：余弦相似度高只说明两个词常出现在相似上下文里，不说明模型“懂”它们的意思。换个分布（新领域、新说法），相似关系可能失真。模型的“理解”边界见[模型幻觉与可解释性](17-model-hallucination-explainability.md)。
- **静态词向量处理不了一词多义**：在下游任务里直接用 Word2Vec / GloVe 向量，“苹果”只有一个表示；多义词多的任务要上上下文相关表示或预训练模型，不能只换向量维度指望解决问题。
- **预训练模型不是越大越好**：参数量上去，效果、成本、部署难度一起上去；小任务上一个轻量模型微调，往往比大模型直接用更划算。规模、数据、算力要配套，见[深度学习与神经网络](02-deep-learning-neural-networks.md)第 5 节的取舍。
- **语料有偏，表示就有偏**：词向量与预训练模型从语料里学规律，语料里的刻板印象与偏见会原样进入向量空间；用之前要意识到这一点，关键场景要做偏见检查，不能把“统计上常见”等同于“正确”。
- **“语言模型会预测，所以它会思考”**：语言模型做的是按概率预测下一个词，输出流畅不等于推理正确；它会一本正经地编造不存在的事实，这是概率生成机制的固有产物，不是偶发故障。

## 7. 小结

词向量把离散的词变成稠密向量，让语义能用几何运算表达；语言模型给词序列算概率，是生成与理解的共同底座；演进路线是从静态词向量（Word2Vec、GloVe）到上下文相关表示（ELMo），再到预训练语言模型（BERT、GPT）；表示越强，算力与数据的账也越大，偏见与幻觉的边界始终都在。
