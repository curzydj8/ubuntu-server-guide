# 卷积神经网络入门：局部连接、权值共享与残差连接

## 1. 一句话定义

卷积神经网络（Convolutional Neural Network，CNN）是一种用卷积层从网格状数据（最常见是图像）中逐层提取局部特征、再把特征组合成整体判断的神经网络。

## 2. 为什么需要它

[深度学习与神经网络](02-deep-learning-neural-networks.md)第 4.6 节点出了全连接层看图像的毛病：如果把一张 224×224 的彩色图展平成向量喂给全连接层，光第一层就有 224×224×3 ≈ 15 万个输入，参数量爆炸；更糟的是，全连接层不知道“边缘在左上角还是右下角其实是同一回事”——它把每个像素当成独立的、没有位置关系的输入。

但图像不是一堆散落的像素：有意义的结构是局部的（边缘、纹理都在小区域里），而且同一个模式出现在图里任何位置都该被同样认出来（猫的耳朵无论在左上还是右下，都是耳朵）。卷积神经网络就是为这两个性质量身定做的结构：局部连接看小区域，权值共享让同一个检测器在全图复用。

## 3. 核心含义

### 3.1 卷积：滑动窗口里的加权求和

卷积层的基本操作是**卷积核（kernel，也叫滤波器）**在输入上滑动、逐位置做加权求和。一个卷积核是一个很小的权重矩阵（常见 3×3 或 5×5），每滑到一个位置，就把该位置覆盖的输入小块与核逐元素相乘再求和，得到输出特征图（feature map）上一个点的值。滑完整张图，就得到一张特征图；一个卷积核只检测一种模式（比如竖直边缘），要检测多种模式就用多个卷积核，每核一张特征图。

下面是一段纯 Python 的示意代码（示例未实测，仅演示一次 2×2 卷积核在 3×3 输入上的滑动计算）：

```python
# 示例未实测：2x2 卷积核在 3x3 输入上的有效卷积（valid，无填充）
x = [[1, 2, 3],
     [4, 5, 6],
     [7, 8, 9]]
k = [[1, 0],
     [0, -1]]
out = [[sum(x[i+di][j+dj] * k[di][dj] for di in range(2) for dj in range(2))
        for j in range(2)] for i in range(2)]
print(out)
```

```text
[[-4, -4], [-4, -4]]
```

这个核在做“左上减右下”的差分：输入里沿对角线均匀递增，所以四个位置的差值都是 -4。真实网络里卷积核的权重不是人手写的，是训练学出来的——网络自己决定每层要检测什么模式。

三个控制卷积形状的参数要分清：

- **卷积核大小**：一次看多大的区域。3×3 是现代默认：小核堆叠既能覆盖大范围（见 3.3 感受野），参数又少。
- **步长（stride）**：核每次滑动几格。步长大于 1 时输出尺寸缩小，等于在下采样。
- **填充（padding）**：在输入边缘补一圈 0。没有填充时每卷一次边缘就丢一圈，图像越卷越小；补 1 圈 0 配 3×3 核、步长 1，输出尺寸与输入相同，边缘信息也不至于一开始就被丢掉。

### 3.2 池化：降维与容忍小位移

池化（pooling）把特征图按小窗口（常见 2×2）切块，每块只留一个值：最大值池化（max pooling）留块内最大值，平均池化（average pooling）留块内平均值。2×2 步长 2 的池化把特征图宽高各减半，数据量减到四分之一。

池化干两件事：第一是**降维**，特征图变小，后续层的计算量与参数量跟着降；第二是**容忍小位移**，目标在图里挪一两个像素，同一池化窗口内的最大值大概率不变，输出就基本不变。代价是位置信息变粗糙——池化之后，模型知道“这里有个边缘”，但说不清边缘精确在哪个像素上。需要精确定位的任务（比如图像分割）要为此补结构，不能只靠池化。

### 3.3 感受野：一个输出点“看到”多大范围

感受野（receptive field）是指输出特征图上一个点对应到原始输入上的区域大小。第一层 3×3 卷积的感受野是 3×3；再叠一层 3×3 卷积，第二层的一个点对应第一层的 3×3 区域，而第一层的每个点又对应输入的 3×3 区域，合起来就是输入上的 5×5。层数越深，感受野越大：底层神经元只看小块边缘，高层神经元看到的是大半张图、能判断整体形状。

感受野有个实用推论：**两层 3×3 卷积堆叠，感受野等于一层 5×5 卷积，但参数更少**（两层 3×3 是 18 个参数，一层 5×5 是 25 个参数，通道数相同时），还多了一次非线性激活。现代网络偏爱小核堆叠，原因就在这里。反过来也说明，感受野不够大的网络看不见全局：分类一张图时如果关键结构跨度超过感受野，模型就拼不出完整判断。

### 3.4 残差连接：让深层网络训得动

网络加深后会出现一个反直觉的现象：按理说更深的网络至少能学到和浅网络一样好（多余的层学恒等映射就行），实际却常常更差——这不是过拟合（训练误差也变大了），而是**退化问题**：层数一多，梯度在反向传播中逐层相乘变小，前面的层几乎得不到有效更新，优化本身变得困难。

残差网络（ResNet，2015 年，He 等人）的做法是给每组卷积层加一条**捷径（shortcut）**：输入不经过卷积、直接加到这组层的输出上。用公式写就是输出 = F(x) + x，其中 F(x) 是这组卷积层学到的东西。网络不再需要学“完整的映射”，只需要学“相对于输入的残差”——学恒等映射从“把权重调成恒等”变成了“把残差调成零”，容易得多；梯度也有了一条不经过卷积层的直达通道，反向传播时不再逐层衰减到消失。

残差连接是 2015 年之后深层网络的标配结构：没有它，百层以上的卷积网络基本训不动；有了它，网络深度从十几层一路推到上百层。注意它解决的是优化困难，不是过拟合——数据不够时，深层残差网络照样过拟合。

## 4. 分类与关键方法

### 4.1 经典结构：三代里程碑

- **LeNet-5（1998 年，LeCun 等人）**：最早成型的卷积网络：卷积 → 池化 → 卷积 → 池化 → 全连接。用于手写数字识别，证明了“卷积 + 池化 + 梯度训练”这条路线走得通。规模很小（输入 32×32 灰度图），是理解 CNN 的起点。
- **AlexNet（2012 年，Krizhevsky、Sutskever 与 Hinton）**：把 CNN 搬上大规模图像分类（ImageNet），错误率比传统方法大幅下降，引发深度学习复兴。关键点有三：用 GPU 训练、ReLU 激活（代替 Sigmoid，缓解梯度消失）、Dropout 与数据增强防过拟合。结构仍是“卷积-池化交替 + 全连接”，但规模比 LeNet 大得多。
- **ResNet（2015 年，He 等人）**：引入残差连接，把网络深度推到 152 层仍能训练，在 ImageNet 上继续大幅降低错误率。此后“残差连接”成为深层网络的通用构件，不只用在图像上。

### 4.2 训练 CNN 时常用的配套方法

- **数据增强**：训练时对图像做随机裁剪、翻转、颜色抖动，相当于把数据集变大，缓解过拟合。注意增强要符合任务语义：数字 6 翻转会变 9，这类任务不能乱翻转。
- **批归一化（Batch Normalization）**：把每层输入归一化到均值 0、方差 1 附近再往下传，缓解深层网络训练不稳定的问题，通常与残差连接配合使用。
- **迁移学习**：在大数据集（如 ImageNet）上预训练好的卷积网络，拿来做新任务时只微调后几层——底层卷积核学到的是通用边缘纹理，换任务也能复用。数据少时，这是比从零训练更现实的路线。
- **全局平均池化**：把最后一层特征图的每个通道取平均，直接得到分类用的向量，替代大尺寸全连接层，参数量大减，也减少过拟合。

## 5. 典型应用

- **图像分类**：判断一张图属于哪个类别（猫 / 狗 / 鸟），CNN 的发源地，也是[图像分类与目标检测](10-image-classification-object-detection.md)的基础。
- **目标检测与分割**：在分类的基础上定位目标的位置（画框）或逐像素划出目标轮廓，见[图像分类与目标检测](10-image-classification-object-detection.md)。
- **医学影像辅助分析**：CT、X 光片上的病灶筛查——卷积擅长局部纹理差异，这类任务与它高度契合；但医疗场景的误判代价高，模型输出必须留人工复核，不能直接当诊断结论。
- **工业质检**：生产线上用相机拍产品表面，CNN 检测划痕、裂纹、缺件——模式固定、数据可控，是 CNN 落地最稳的场景之一。

## 6. 限制与常见误解

- **平移不变性是有限的**：权值共享与池化让 CNN 对小位移不敏感，但目标旋转、大幅缩放、遮挡严重时，识别照样会掉。需要旋转不变性或处理遮挡，要靠数据增强或专门结构，不能指望卷积本身解决。
- **位置信息会丢失**：池化与下采样把位置越磨越粗，CNN 天生“知道是什么”，不擅长“精确在哪”。分类任务无所谓，分割与检测任务必须补结构。
- **数据与算力门槛真实存在**：从零训练一个能用的 CNN 需要大量标注图像与 GPU 算力；数据不够时优先用迁移学习，而不是硬训。
- **“卷积核是人在设计特征”**：不是。卷积核的权重是训练学出来的，人只定结构（核大小、层数、通道数）。说 CNN“自动学特征”，指的是这个。
- **“层数越深越好”**：残差连接解决了优化困难，但没有解决过拟合与数据需求。层数超过任务所需，只会更吃数据、更难调。

## 7. 小结

卷积神经网络用局部连接与权值共享把图像的结构先验写进网络：底层学边缘纹理，高层组合成部件与整体；池化降维并容忍小位移，感受野随层数扩大，残差连接让百层网络训得动。它的边界同样清楚：小位移稳、大变换不稳，擅长“是什么”、位置要另想办法，数据不够时先用迁移学习。
