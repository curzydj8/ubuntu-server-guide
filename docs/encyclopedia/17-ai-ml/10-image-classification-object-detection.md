# 图像分类与目标检测：认出是什么，框出在哪里

## 1. 一句话定义

图像分类是给整张图片贴一个类别标签，目标检测是进一步框出图片里每个目标的位置并给出类别。

## 2. 为什么需要它

机器看懂图片，第一步永远是这两个问题：“这是什么”和“它在哪”。分类回答第一个，检测回答第二个。没有它们，后面所有视觉应用都无从谈起：相册按内容搜索要先分类；自动驾驶要先检测出前方的车与行人及其位置；工业质检要先框出缺陷在哪；医学影像要先定位病灶。分类与检测是计算机视觉的入口任务，也是最先大规模落地的视觉任务——今天手机相册的自动分类、扫码与人脸框选，背后都是它们。

两者还是很多更复杂任务的地基：图像分割是在检测框的基础上再精细到像素（见[图像分割与生成模型](11-image-segmentation-generative.md)），视频理解是把单帧检测结果在时间上串起来。分类与检测没做扎实，上层任务全是空中楼阁。

## 3. 核心含义

### 3.1 图像分类：整图一个答案

输入一张图片，输出一个类别（或每个类别的概率）。模型给出的是“整张图最可能是什么”，不回答目标在哪、有几个。经典场景是 ImageNet 式竞赛任务：从上千个类别里挑一个。

分类输出通常是一组概率（经 softmax 归一化后和为 1），取概率最大的类别作为答案。训练时用的是带标签的图片：每张图一个正确答案，模型学的是“像素组合到类别的映射”。特征提取基本靠卷积神经网络（见[卷积神经网络入门](06-cnn-intro.md)），本篇不重复卷积本身的机制，只讲任务与评估。

### 3.2 目标检测：框 + 类别，缺一不可

输入一张图片，输出一组结果，每个结果包含三样东西：一个包围目标的矩形框（bounding box，通常用左上角与右下角坐标表示）、一个类别、一个置信度（模型认为“框里确实是这个类别”的把握）。一张图里可以有多个目标、多个类别；没有目标时输出为空。

检测比分类难在两个地方：第一，位置也要学——类别错了不行，框画偏了也不行；第二，目标数量不固定——模型不能像分类那样只输出一个固定长度的答案，必须自己决定“图里有几个目标”。

### 3.3 框得准不准：IoU

判断一个预测框好不好，要看它和真实框（标注框）重叠多少。标准度量是**交并比（IoU，Intersection over Union）**：

```text
IoU = 预测框与真实框的交集面积 / 两者的并集面积
IoU = 1：两个框完全重合；IoU = 0：两个框完全不重叠
常用判定线：IoU ≥ 0.5 才算“框对了”（宽松标准）；IoU ≥ 0.75 要求更严
```

下面这段纯 Python 代码算了三组框的 IoU，输出附后（示例未实测）：

```python
def iou(a, b):
    ax1, ay1, ax2, ay2 = a
    bx1, by1, bx2, by2 = b
    ix1, iy1 = max(ax1, bx1), max(ay1, by1)
    ix2, iy2 = min(ax2, bx2), min(ay2, by2)
    iw, ih = max(0, ix2 - ix1), max(0, iy2 - iy1)
    inter = iw * ih
    area_a = (ax2 - ax1) * (ay2 - ay1)
    area_b = (bx2 - bx1) * (by2 - by1)
    return inter / (area_a + area_b - inter)

print(f"{iou((0, 0, 10, 10), (5, 5, 15, 15)):.4f}")   # 错开一半
print(f"{iou((0, 0, 10, 10), (0, 0, 10, 10)):.4f}")   # 完全重合
print(f"{iou((0, 0, 10, 10), (20, 20, 30, 30)):.4f}") # 完全不重叠
```

```text
0.1429
1.0000
0.0000
```

IoU 的意义在于把“框得准不准”变成一个 0 到 1 之间的数，检测评估全建立在它上面。

### 3.4 从 IoU 到 mAP：检测的评估链条

检测评估分三步走：

- **定对错**：设定一个 IoU 阈值（常用 0.5）。预测框与某个真实框的 IoU 达到阈值且类别对了，记为真正例（TP）；IoU 不够或类别错了，记为假阳性（FP）；没被任何预测框盖住的真实框，记为假阴性（FN，即漏检）。精确率、召回率的定义与[模型训练与评估](03-model-training-evaluation.md)第 4.3 节一致。
- **画曲线**：按置信度从高到低取预测框，逐步算出精确率–召回率曲线；曲线下面积就是该类别的**平均精度（AP，Average Precision）**。AP 高意味着模型在“少误报、少漏报”两方面同时做得好。
- **求平均**：把所有类别的 AP 平均，得到**平均精度均值（mAP，mean Average Precision）**，这是目标检测最常用的综合指标。

两个最常见的 mAP 版本要分清：

| 版本 | 含义 | 哪里常用 |
|---|---|---|
| mAP@0.5 | IoU 阈值为 0.5 时的 mAP | Pascal VOC 数据集的传统标准，相对宽松 |
| mAP@0.5:0.95 | IoU 阈值从 0.5 到 0.95 每隔 0.05 取一次，10 个 mAP 再平均 | COCO 数据集的标准，更严格、更能区分模型优劣 |

只报一个 mAP 数字而不注明 IoU 阈值与数据集，等于没报——不同版本之间没有可比性。

### 3.5 分类指标：Top-1 与 Top-5

分类评估比检测简单，常用两个指标：

- **Top-1 准确率**：概率最大的那个类别就是正确答案的比例。
- **Top-5 准确率**：正确答案出现在概率前五名里的比例。类别上千时很有用：模型分不清“哈士奇”和“阿拉斯加”可以理解，只要正确答案进了前五，就算它“大致认对了”。ImageNet 竞赛时代，Top-5 错误率是主指标。

类别不平衡时，分类也要看每类的精确率与召回率，不能只看总体准确率——道理与[模型训练与评估](03-model-training-evaluation.md)第 4.4 节相同。

## 4. 分类 / 关键方法

### 4.1 目标检测的两条路线

检测器按“先找候选区域、再分类”，还是“一步到位”，分两大派：

- **两阶段检测器（two-stage）**：先由区域提议网络找出“可能有目标”的候选框，再对每个候选框做精细分类与框回归。代表是 R-CNN 家族：R-CNN（2014）、Fast R-CNN（2015）、Faster R-CNN（2015）。优点是精度高，尤其小目标与密集目标上更稳；缺点是流程长、速度慢。
- **单阶段检测器（one-stage）**：不设候选区域，直接在整张图上密集预测框与类别。代表是 YOLO（2016，You Only Look Once）与 SSD（2016，Single Shot MultiBox Detector）。优点是快，适合实时场景；早期版本在小目标精度上吃亏，后续版本不断追平。RetinaNet（2017）用 Focal Loss 解决正负样本极不平衡的问题，是单阶段精度追赶的关键一步。

两条路线的分界在今天已经模糊：精度与速度的取舍仍在，但“两阶段一定更准、单阶段一定更快”的旧结论不再绝对，选型要看具体模型与部署条件，以官方发布为准（待核实）。

### 4.2 检测器内部的共性构件

不管哪一派，现代检测器都有几个共同部件：

- **骨干网络（backbone）**：提取图像特征的卷积网络，通常是预训练好的分类网络。检测的精度很大程度上继承自骨干的特征质量。
- **锚框（anchor box）**：在特征图每个位置预设一组不同尺寸与长宽比的参考框，模型学的是“相对锚框的偏移量”，而不是凭空画框。锚框是把“框在哪里”变成“在参考框基础上调多少”的技巧。
- **框回归（bounding box regression）**：预测框坐标相对参考框的修正量，让框从“大概位置”收紧到“贴合目标”。
- **非极大值抑制（NMS）**：同一个目标常被多个框同时命中，NMS 只保留置信度最高的框，把与其重叠过多的重复框删掉。没有 NMS，一张图里一个目标会冒出十几个框。
- **特征金字塔（FPN，2017）**：把骨干网络不同层级的特征融合起来，让模型同时看到细节（浅层、高分辨率）与语义（深层、低分辨率），大小目标都能兼顾。这是现代检测器的标准部件。

### 4.3 检测的新路线：Transformer 检测器

DETR（2020）用 Transformer 直接预测一组框，不再需要锚框与 NMS，把检测变成“集合预测”问题：模型一次输出固定数量的框，再由匈牙利算法匹配到真实目标。这条路线去掉了很多手工设计，但训练收敛慢、小目标精度弱是它的早期短板，后续改进版本仍在演进中。原理级介绍见本站后续 Transformer 相关篇目（待后续批次）。

## 5. 典型应用

- **相册与内容搜索**：图片分类让相册按“猫、风景、食物”自动归类，搜索“海滩”就能找回所有海滩照片，不用人工打标签。
- **自动驾驶感知**：检测车辆、行人、交通标志与车道线的位置，是路径规划与避障的输入；漏检与误检直接关系安全，评估要看高 IoU 阈值下的 mAP，不只是 mAP@0.5。
- **工业质检**：在生产线上框出产品表面的划痕、裂纹与缺件，替代人工目检；缺陷样本少是常态，训练数据获取方式见[模型训练与评估](03-model-training-evaluation.md)的讨论。
- **医学影像辅助诊断**：检测影像中的结节、病灶并框出位置，供医生复核。这里检测只是辅助，不能替代诊断；漏报代价极高，召回率优先于精确率。

## 6. 限制与常见误解

- **“分类准确率 99% 就是好模型”**：类别不平衡时，全猜多数类也能刷出高准确率；而且训练集分布与真实场景分布不一致时，准确率会虚高。先看数据构成与每类指标，再下结论。
- **“mAP 高，部署就一定好”**：mAP 是在标准数据集、离线条件下测的。真实场景的光照、遮挡、角度、小目标比例都不同；部署时还要看速度、显存与功耗。离线指标好只是入场券。
- **“框画出来了，就是检测对了”**：框与真实框 IoU 只有 0.3，类别再对也不算检出。评价检测必须同时看“类别对不对”和“框准不准”，只看类别等于把检测当分类用。
- **小目标与遮挡是硬骨头**：目标在图里只占几个像素、或被遮住大半时，检测精度会明显下降。这是所有检测器的共同短板，靠更高分辨率输入、特征金字塔与更多小目标训练样本缓解，但无法根除。
- **标注成本决定上限**：检测要逐个目标画框标类别，标注成本远高于分类。数据量不够、标注不准时，模型再先进也学不出来；数据偏见的影响见[数据偏见与公平性](16-data-bias-fairness.md)。

## 7. 小结

图像分类给整图贴标签，目标检测还要框出每个目标的位置与类别；IoU 衡量框得准不准，mAP 是检测的主指标，报数字必须注明 IoU 阈值与数据集；检测器分两阶段与单阶段两派，共性构件是骨干网络、锚框、框回归、NMS 与特征金字塔；小目标、遮挡与标注成本是它的三条硬边界。
