# 机器学习基础：问题形态、泛化与评估思想

## 1. 一句话定义

机器学习是让计算机从数据中总结规律，再用规律对新数据做预测或决策的方法。

## 2. 为什么需要它

很多问题写不出精确规则：判断一张照片里有没有猫、预测用户会不会点一条推荐、识别一段语音说了什么。这些任务的规则藏在数据里，不在人的头脑里——人说不清“猫长什么样”的完整规则，但可以给计算机成千上万张标好“是猫 / 不是猫”的照片，让它自己总结。机器学习就是干这件事的：规则写不出来时，改从数据里学。

反过来，规则写得清清楚楚的问题不需要机器学习：计算工资税、按固定流程审批、查表换算。拿机器学习做这些，等于用统计猜一个本可以精确算出的答案，又慢又不可靠。选型第一问永远是：这个问题到底有没有“规则写不出、但数据里有规律”这个特征。

## 3. 核心含义

一句话定义里有五个词，缺一不可：

- **任务**：要解决什么问题。常见表述是“给定输入，输出什么”：给定图片输出类别、给定用户历史输出推荐列表、给定传感器读数输出是否异常。
- **数据**：用来学习的例子。每个例子通常是一组特征（输入）和一个目标（输出）。数据质量决定学习上限：标注错了、样本有偏，学出来的规律跟着错。
- **模型**：承载规律的载体。可以是一条直线、是一棵决策树，也可以是一个有上亿参数的神经网络。本质都是“输入到输出的映射”，区别在表达能力和学习方式。
- **学习**：调整模型、让它在数据上表现越来越好的过程。调的是模型内部的参数，不是改代码逻辑。
- **预测（推理）**：学习完成后，拿新输入走一遍模型，得到输出。训练调参数，推理只用参数——这是两个阶段，不要混为一谈。

与传统编程的根本差别在一张表里：

| | 传统编程 | 机器学习 |
|---|---|---|
| 规律从哪来 | 人写规则 | 数据里总结 |
| 改行为靠什么 | 改代码 | 换数据、调模型 |
| 适合什么问题 | 规则明确、可精确描述 | 规则模糊、但数据里有规律 |
| 出错长什么样 | 逻辑错误，可定位到某一行 | 统计错误，表现为某类样本系统性错 |

## 4. 分类

### 4.1 按学习信号分：数据给没给“标准答案”

这是最常用的分法，分的是训练时有没有带标签的目标值：

- **监督学习**：每个例子都带标准答案。学的是“输入到答案的映射”。典型任务：分类（这封邮件是不是垃圾邮件）、回归（预测房价）。工业界大部分落地项目属于这一类，因为目标明确、效果好衡量。
- **无监督学习**：例子没有标准答案。学的是“数据本身的结构”。典型任务：聚类（把用户分群）、降维（把高维数据压到低维看结构）、异常检测（找出和多数不一样的样本）。
- **半监督学习**：少量带标签、大量不带标签。现实中标注贵、无标注数据便宜时用它：先用少量标签定方向，再用大量无标签数据把边界磨细。
- **自监督学习**：答案从数据自己身上造，不用人标。例如遮住一句话里的一个词，让模型猜被遮住的词——“标准答案”就是原文，不用人工标注。这是现代大模型预训练的主流路子。
- **强化学习**：没有现成的标准答案，只有环境给的奖励信号。学的是“在什么状态下采取什么动作能拿到长期奖励”。典型场景：游戏、下棋、机器人控制。它的学习信号是试错，不是样本标签。

### 4.2 按任务输出分

- **分类**：输出离散类别（是 / 否、猫 / 狗 / 鸟）。
- **回归**：输出连续数值（价格、温度、销量）。
- **聚类**：输出分组，不预设组名。
- **生成**：输出新内容（文本、图像、代码），而不是判断。
- **排序与推荐**：输出顺序（搜索结果排第几、推荐哪几条）。
- **序列决策**：输出一连串动作（下棋走子、机械臂动作）。

### 4.3 按模型家族分（定位，细节各有专篇）

- **线性模型**：输入的加权和，简单、可解释、能力有限。
- **树模型与集成**：按特征切分样本，集成多棵树提精度；表格数据上的常用强手。
- **核方法与近邻**：靠样本间相似度做判断，小数据上稳，大数据上慢。
- **神经网络**：多层可学习的非线性映射，表达能力最强，也最吃数据和算力。详见[深度学习与神经网络](02-deep-learning-neural-networks.md)。

## 5. 泛化、过拟合与欠拟合

这是机器学习最核心的一组概念，评估思想全从这里长出来。

- **泛化**：模型在没见过的新数据上的表现。训练集上的分数只是“做题家在做过的题上的分数”，泛化才是“考试分数”。机器学习的全部追求，归结起来就是泛化。
- **欠拟合**：模型太简单，连训练集上的规律都没抓住。表现：训练集上就错得多。原因通常是模型能力不够，或特征给得不对。
- **过拟合**：模型太复杂，把训练集里的噪声也当规律背下来了。表现：训练集上几乎全对，新数据上一塌糊涂。典型症状是“训练分数很高，验证分数很低”。
- **三者的关系**：模型复杂度从低往高走，训练误差一路下降，泛化误差先降后升——升起来的那一段就是过拟合区间。调模型的过程，很大程度上就是找泛化误差最低的那个点。这就是为什么不能只看训练集分数，也为什么需要验证集和测试集（划分与评估方法见[模型训练与评估](03-model-training-evaluation.md)）。

```text
泛化误差
  │   ╲
  │    ╲  过拟合区间：训练误差还在降，泛化误差已回升
  │     ╲
  │      ╲╱ 最优点：复杂度适中
  │     ╱
  │    ╱ 欠拟合区间：模型太简单，两边都差
  └────────────────── 模型复杂度 →
```

## 6. 典型应用

- **图像分类**：给定图片判断类别，是监督学习最直观的落地：输入像素，输出类别。
- **推荐系统**：根据用户历史行为预测下一个可能感兴趣的内容，本质是排序问题，数据里的规律是“相似用户喜欢相似东西”。
- **金融风控**：根据交易特征判断欺诈概率，是分类问题；这里漏报（放过欺诈）与误报（打扰正常用户）的代价不同，指标取舍见[模型训练与评估](03-model-training-evaluation.md)。
- **机器翻译**：输入一种语言的句子，输出另一种语言的句子，属于生成任务；现代做法先自监督预训练、再监督微调。

## 7. 限制与常见误解

- **数据有偏，模型就有偏**：训练数据里某类样本少，模型在这类样本上就差；数据里带的历史偏见，模型会原样放大。数据问题不能靠调参解决。
- **相关不等于因果**：模型学到的是统计关联，不是因果机制。夏天冰淇淋销量和溺水数一起涨，模型能学会关联，但不能据此说“冰淇淋导致溺水”。要干预、要决策时，关联不够用。
- **“AI 理解了”是最常见的误解**：模型是在拟合输入到输出的映射，没有理解、没有意图、没有常识推理。换个分布（新场景、新措辞、新光照），表现可能断崖式下跌，这叫分布外脆弱。
- **不是所有问题都适合**：规则明确、数据极少、出错代价极高且要求可解释的场景，先考虑规则方案或人工流程，不要先上机器学习。

## 8. 小结

机器学习是从数据里总结规律、用规律预测新数据的方法；按学习信号分监督、无监督、半监督、自监督与强化；全部追求归结为泛化，过拟合与欠拟合是复杂度两端的两种失败；数据有偏、相关非因果、分布外脆弱是它的三条硬边界。
