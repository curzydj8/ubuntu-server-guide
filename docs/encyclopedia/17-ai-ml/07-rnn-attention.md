# 循环网络与注意力机制：序列里的记忆与相关性

## 1. 一句话定义

循环神经网络（Recurrent Neural Network，RNN）是一类按序列顺序逐步处理、并把前一步的状态传给下一步的网络；注意力机制（Attention）则是一种对序列中所有位置按“与当前的相关程度”加权汇总信息的计算方式。

## 2. 为什么需要它

[深度学习与神经网络](02-deep-learning-neural-networks.md)里讲的前馈网络一次看全部输入、算一次就结束。这对定长输入够用，但语言、语音、时间序列这类数据有个前馈网络处理不好的性质：**长度不定，而且顺序就是信息**。“狗咬人”和“人咬狗”是同样的三个词，顺序一换意思全变；一段语音、一篇文章，长度事先不知道，模型必须能处理任意长度的输入。

序列任务需要两样东西：第一，**记忆**——处理第 t 个词时，要记得前面出现过什么；第二，**相关性判断**——当前这个词该参考序列里的哪些部分，而不是只看紧邻的前一个词。RNN 负责第一样，注意力机制负责第二样。本篇把两者往深处讲：RNN 为什么在长序列上失效，门控结构怎么补救，以及注意力权重到底是怎么算出来的。

## 3. 核心含义

### 3.1 RNN：把状态沿时间传下去

RNN 的核心是一个**隐藏状态（hidden state）**：处理第 t 个输入时，网络同时看两样东西——当前输入 x_t，和上一步传下来的隐藏状态 h_{t-1}，算出新的隐藏状态 h_t，再传给下一步。公式写成 h_t = f(h_{t-1}, x_t)，其中 f 是带激活函数的加权求和。序列处理完，最后一个（或每个）隐藏状态拿去做预测。

关键点：RNN 在所有时间步**共享同一组权重**——第 1 步和第 100 步用的是同一套参数。这既是优点（参数量不随序列长度增长，任意长度都能处理），也是麻烦的根源（见 3.2）。直觉上，隐藏状态就是网络的“记忆”：它把前面看过的内容压缩成一个向量带在身上。

### 3.2 梯度消失：RNN 在长序列上失效的原因

RNN 训练时用的是沿时间展开的反向传播（BPTT）：把网络按时间步展开成一条长链，误差从最后一步一路乘回第一步。问题出在“乘”上：误差每往回传一步，都要乘上一个矩阵（权重矩阵与激活函数导数的乘积）。传 100 步，就是 100 次连乘——如果每步的因子小于 1，连乘结果指数级缩小到接近 0，叫**梯度消失**；如果大于 1，则指数级放大，叫**梯度爆炸**。

对 RNN 来说，梯度消失是常态、梯度爆炸是偶发：常用激活函数 Tanh 的导数最大只有 1，权重矩阵的谱半径又通常小于 1，连乘几乎注定越乘越小。后果很具体：模型学不会长距离依赖——一句话开头的主语，到句尾动词出现时早已被“遗忘”，因为开头信息传到句尾的过程中梯度已经消失，权重得不到有效更新。梯度爆炸相对好办：梯度裁剪（超过阈值就按比例缩小）就能控制；梯度消失没有这种廉价解法，需要改结构——这就是门控网络存在的理由。

### 3.3 LSTM：用门控保护记忆

长短期记忆网络（Long Short-Term Memory，LSTM，1997 年，Hochreiter 与 Schmidhuber）给 RNN 加了一个**细胞状态（cell state）**：一条从头贯穿到尾的“传送带”，信息可以在上面几乎原样流动，不像隐藏状态那样每步都被重写。细胞状态由三个**门**控制，每个门输出 0 到 1 之间的数，决定“放行多少”：

- **遗忘门**：决定上一时刻的细胞状态保留多少。输出接近 1，全保留；接近 0，全丢掉。网络自己学什么时候该忘（比如新句子开始，旧句子的信息就该清掉）。
- **输入门**：决定当前输入有多少写进细胞状态。重要的新信息放行，噪声挡在外面。
- **输出门**：决定细胞状态有多少输出成当前隐藏状态——即当前这一步对外展示多少记忆。

门控的关键不是“门”这个比喻，而是数学性质：细胞状态的更新是加法（旧状态 × 遗忘门 + 新信息 × 输入门），不是每步都乘一个矩阵再过激活函数。梯度沿着细胞状态这条路往回传时，走的是加法链，衰减慢得多——长距离依赖因此能学到。代价是参数量：一个 LSTM 单元的参数大约是同规模普通 RNN 的 4 倍，训练更慢、更吃数据。

### 3.4 GRU：更轻的门控

门控循环单元（Gated Recurrent Unit，GRU，2014 年，Cho 等人）是 LSTM 的简化版：把遗忘门与输入门合并成一个**更新门**（决定旧状态保留多少、新信息写入多少，两者互补），再加一个**重置门**（决定算新候选状态时忽略多少旧状态）。没有独立的细胞状态，隐藏状态直接兼任记忆载体。

GRU 的参数大约是同规模 LSTM 的四分之三，训练更快；在很多任务上效果与 LSTM 接近，数据量小、算力紧张时常被优先选用。但简化不是免费的：需要精细控制“记住什么、忘掉什么”的长序列任务上，LSTM 的三个门分工更细，有时仍占优。选型没有定论，常见做法是两个都试、在验证集上比。

### 3.5 注意力权重：相关性是怎么算出来的

注意力机制不依赖“上一步传下来的状态”，而是直接回答：当前这个位置，该参考序列里的哪些位置、各自参考多少。缩放点积注意力（scaled dot-product attention，Transformer 的标准做法）的计算分四步：

1. **生成 Q、K、V**：每个位置的输入向量分别乘三个学到的权重矩阵，得到查询（Query）、键（Key）、值（Value）三组向量。直觉是：查询表示“我在找什么”，键表示“我这里有什么”，值表示“我能提供什么内容”。
2. **算相关分数**：当前查询与每个位置的键做点积，点积越大，相关性越强。
3. **缩放与归一化**：分数除以 √d_k（d_k 是键向量的维度），再过 Softmax 变成权重——所有权重加起来等于 1，权重大的位置分到的关注多。缩放这一步不能省：维度高时点积数值大，Softmax 会进入饱和区、梯度变小，除以 √d_k 把数值拉回合理范围。
4. **加权汇总**：用权重对所有位置的值向量做加权求和，得到当前这个位置的输出。

下面是一段纯 Python 的示意代码（示例未实测，仅演示三个位置的相关分数如何变成注意力权重，分数为手工设定的演示值）：

```python
# 示例未实测：分数 [2, 1, 0] 经 Softmax 变成注意力权重
import math
scores = [2.0, 1.0, 0.0]
exps = [math.exp(s) for s in scores]
total = sum(exps)
weights = [e / total for e in exps]
print([round(w, 3) for w in weights])
```

```text
[0.665, 0.245, 0.09]
```

分数最高的第一个位置分到约 2/3 的权重，第二、第三个位置分到剩下的约 1/3。真实网络里的分数不是人手写的，是查询与键的点积算出来的；权重分布也不是事先定的，是训练学出来的——模型自己决定每个位置该关注谁。

注意力相对 RNN 的根本差别：RNN 里两个相隔 100 步的位置要经过 100 次状态传递才能“见面”，信息一路衰减；注意力里任意两个位置直接算相关分数，距离不再是障碍。这就是 Transformer 能处理长距离依赖、又能并行计算的原因——注意力不需要按顺序一步步等，整个序列的相关分数可以一次算完。代价是计算量：序列长度为 n 时，要算 n×n 个相关分数，序列越长越贵。

## 4. 分类与关键方法

### 4.1 循环结构演进

| 结构 | 记忆机制 | 长距离依赖 | 典型定位 |
|---|---|---|---|
| 普通 RNN | 隐藏状态每步重写 | 差，梯度消失 | 教学起点、短序列 |
| LSTM（1997） | 细胞状态 + 三门 | 好，加法链传梯度 | 长序列任务的经典选择 |
| GRU（2014） | 隐藏状态 + 两门 | 较好 | 更轻、更快，效果常与 LSTM 接近 |
| Transformer 注意力（2017） | 无状态传递，直接算相关 | 好，任意位置直连 | 长序列上的主流结构 |

### 4.2 注意力机制的变体与位置

- **自注意力（self-attention）**：序列内部自己对自己算注意力——每个位置参考同序列里的其他位置。Transformer 编码器的核心。
- **交叉注意力（cross-attention）**：一边的序列（比如翻译的译文）对另一边的序列（比如原文）算注意力——查询来自一边，键与值来自另一边。机器翻译解码器的核心。
- **多头注意力（multi-head attention）**：把 Q、K、V 切成多组，并行算多套注意力再拼起来。不同头可以关注不同类型的相关性（一个头看语法、一个头看语义，诸如此类——这是直觉，头的具体分工由训练决定，不可事先指定）。
- **位置编码**：注意力本身不区分顺序——“狗咬人”和“人咬狗”在不加位置信息时算出来是一样的。Transformer 额外给每个位置加一个位置编码，让模型知道谁先谁后。位置编码的细节是后续深入篇的范围。

### 4.3 序列任务的经典结构：编码器-解码器

机器翻译这类“输入一个序列、输出另一个序列”的任务，经典做法是编码器-解码器：编码器把输入序列压缩成表示，解码器一边生成输出、一边用交叉注意力参考编码器的表示。RNN 时代用 LSTM 做编码器与解码器，Transformer 时代两者都换成注意力结构。这个框架本身不依赖具体用 RNN 还是注意力——换的是“表示怎么算”，不是“任务怎么分”。

## 5. 典型应用

- **机器翻译**：输入一种语言的句子、输出另一种语言，见[词向量与语言模型](08-word-embeddings-language-models.md)；注意力让译文每个词直接参考原文的相关词，长句翻译质量因此大幅提高。
- **文本生成与摘要**：按顺序生成文本、或把长文压缩成摘要——序列生成任务的代表，Transformer 是当前主流结构。
- **语音识别**：把音频帧序列转成文字序列，序列长度长、时序依赖强，是 RNN 早期的重要落地场景，现已被注意力结构大量替代。
- **时间序列预测**：股价、销量、传感器读数的多步预测——输入是按时间排列的数值序列，门控 RNN 与注意力都是常用结构；预测结果要附不确定性说明，见[模型训练与评估](03-model-training-evaluation.md)的指标取舍。

## 6. 限制与常见误解

- **“RNN 被淘汰了”**：不准确。长序列主流任务上 Transformer 确实占了主导，但 RNN/LSTM 在短序列、流式处理（数据边到边处理、不能等全序列到齐）、资源受限设备上仍有位置——注意力要等整个序列到齐、算 n×n 相关分数，流式场景并不划算。
- **“注意力就是模型在‘看’哪里”**：注意力权重是“信息按相关性重新分配权重”的计算结果，不是人眼注视的复刻。权重大的位置确实贡献了更多信息，但把权重图直接解读成“模型在想什么”会过度解读——多头、深层堆叠之后，单层权重与最终决策的关系并不直观。
- **“LSTM 彻底解决了梯度消失”**：是大幅缓解，不是根除。细胞状态的加法链让梯度衰减慢得多，但门本身是乘法（遗忘门小于 1 时仍在衰减），极长序列上问题仍会出现；另外 LSTM 训练慢、参数多，本身也是成本。
- **“注意力算的是相似度”**：点积分数衡量的是查询与键的匹配程度，但 Q、K 是学出来的投影——模型可以学出“查询要找的不是相似的键，而是互补的键”。分数的含义由训练决定，不是预设的相似度。
- **序列越长，注意力越贵**：n×n 的相关分数是实打实的计算与显存账，超长序列要靠稀疏注意力、分块等工程手段，细节是后续深入篇的范围。

## 7. 小结

RNN 用共享权重的隐藏状态把记忆沿时间传下去，但梯度连乘让长距离依赖学不到；LSTM 与 GRU 用门控把记忆的读写交给网络自己控制，细胞状态的加法链让梯度衰减变慢；注意力则绕开状态传递，让任意两个位置直接按相关程度加权汇总——距离不再是障碍，代价是 n×n 的计算账。三者不是谁取代谁：短序列与流式场景仍有 RNN 的位置，长序列主流是注意力。
