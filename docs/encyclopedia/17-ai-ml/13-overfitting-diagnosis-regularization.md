# 过拟合诊断与正则化：认出过拟合，再把它压回去

## 1. 一句话定义

过拟合诊断是判断模型是否把训练数据里的噪声当成了规律；正则化是给模型加约束、限制其自由度，让它学规律而不背噪声的一类方法。

## 2. 为什么需要它

[机器学习基础](01-ml-basics.md)第 5 节讲过核心图像：模型复杂度从低往高走，训练误差一路下降，泛化误差先降后升，升起来的那一段就是过拟合区间。但那张图是事后诸葛亮——训练进行时，你手里只有训练集分数，看不到泛化误差曲线。现实中的问题是操作性的：怎么在训练现场认出“已经过拟合了”？认出来之后，除了“换个简单模型”，还有哪些可落地的手段？

[模型训练与评估](03-model-training-evaluation.md)第 4.5 节已经把早停与正则化定位为“限制模型自由度”的手段，并把细节留给了后续篇。本篇就是那个细节篇：先讲诊断的信号与流程，再讲每种正则化方法具体在约束什么、代价是什么。

## 3. 核心含义

### 3.1 诊断信号：训练与验证误差的 gap

过拟合最直接的症状是**训练误差与验证误差之间的 gap**：训练集上几乎全对，验证集上明显差一截。gap 本身不是坏事——训练误差通常低于验证误差；关键是 gap 的**大小与走向**：

- **gap 小、两者都高**：欠拟合。模型连训练集规律都没抓住，问题在能力不足或特征不对，不是过拟合。
- **gap 小、两者都低**：拟合良好，是想要的状态。
- **gap 大、训练低而验证高**：过拟合。模型在训练集上多出来的那部分“本事”，是背下来的噪声，换到新数据上不成立。

只看一个分数诊断不了过拟合：训练误差 0.01 可能是真学会了，也可能是背下来了；必须同时看验证误差，gap 才是诊断依据。

### 3.2 学习曲线：把 gap 画成随时间或数据量的变化

学习曲线是诊断的主要工具，有两种画法：

- **随训练轮数的曲线**：横轴是训练轮数，纵轴是误差，训练误差与验证误差各画一条。典型轨迹是训练误差一路下降，验证误差先降后升——升起来的拐点就是过拟合开始的地方，[模型训练与评估](03-model-training-evaluation.md)第 4.2 节的早停正是盯住这个拐点。
- **随训练数据量的曲线**：横轴是训练样本数，纵轴是误差。数据量增加时，两条曲线会靠拢：如果靠拢后两者都低，模型没问题；如果靠拢后两者都高，是欠拟合（加数据没用，要加模型能力）；如果 gap 随数据量增大而缩小，是过拟合，加数据本身就是解药。

### 3.3 偏差–方差视角：过拟合与欠拟合是两种误差的此消彼长

同一组概念换个说法：总误差可以拆成偏差（模型本身离真实规律有多远）与方差（换一批训练数据，模型结果抖动多大）两部分。欠拟合是偏差主导——模型太简单，再多数据也学不到规律；过拟合是方差主导——模型太灵活，对训练数据的细节过度敏感，换一批数据结果就变。正则化的本质，就是拿一点偏差去换方差的大幅下降：让模型稍微“笨”一点，换来它在新数据上的稳定。

### 3.4 正则化统一思想：限制自由度

L1、L2、Dropout、数据增强、早停看起来各不相同，目标只有一个：**限制模型拟合训练数据的自由度**。区别只在约束加在哪：L1/L2 约束权重大小，Dropout 约束神经元之间的依赖，数据增强约束模型对输入扰动的敏感，早停约束训练轮数。选方法时先问“自由度是从哪漏出去的”，再选对应的约束。

## 4. 分类与关键方法

### 4.1 L1 与 L2 正则化：罚权重

两者都是在损失函数上加一项，惩罚过大的权重：

- **L2（岭回归，Ridge）**：加 `λ·Σw²`，即权重平方和。效果是把权重整体往小压、分布变均匀，没有一个权重会变得特别大。几何上相当于把权重限制在一个球里。L2 不产生精确的零，适合“所有特征多少都有点用”的场景。
- **L1（Lasso）**：加 `λ·Σ|w|`，即权重绝对值之和。效果是倾向于把一部分权重精确压到零——等于自动做了特征选择：不重要的特征直接被踢出模型。适合特征很多、怀疑其中大量无用的场景。
- **λ 的作用**：λ 是正则化强度，λ=0 等于没有正则化，λ 越大约束越强。λ 太小压不住过拟合，λ 太大把有用信号也压没了、变成欠拟合。λ 本身是超参数，要用验证集或交叉验证选，见[超参数调优与交叉验证](12-hyperparameter-tuning-cross-validation.md)。
- **细节**：正则化项通常不罚截距项（偏置），因为偏置只决定整体平移，不决定模型复杂度；特征要先标准化再加正则化，否则量纲大的特征会被不公平地重罚。

### 4.2 Dropout：训练时随机关闭神经元

Dropout 是神经网络专用的正则化：训练时每轮随机关闭一部分神经元（按设定比例），被关闭的神经元本轮不参与前向与反向传播。逼模型做到的事是：**不依赖任何个别神经元**——因为任何一个神经元都可能在下一轮被关闭，模型必须把知识分散到多个神经元上，相当于每次训练一个不同的子网络，最后的效果接近多个子网络的集成。

两个实现细节不能错：第一，推理时 Dropout 要关闭，全部神经元都参与，否则预测结果每次都不一样；第二，推理时权重通常要按保留比例缩放（或训练时做等价处理），否则训练与推理的激活规模对不上。Dropout 的比例是超参数，常用 0.2–0.5；比例过高会欠拟合。

### 4.3 数据增强：拿更多样的数据约束模型

数据增强不改模型，改数据：对训练样本做保持标签不变的变换，生成新样本。图像任务里是裁剪、翻转、旋转、调亮度；文本任务里是同义词替换、回译；语音里是加噪、变速。它的正则化作用来自“模型见过同一内容的多个版本”：只背住某一张图原样的模型，在增强后的版本上照样要答对，背答案的收益被摊薄了。

红线是**标签语义**：变换不能改变样本的正确答案。翻转一张猫的照片还是猫，但翻转数字“6”就变成了“9”——增强方式必须按任务定，不能照搬别的任务的增强清单。

### 4.4 早停：用训练轮数控制复杂度（细节）

[模型训练与评估](03-model-training-evaluation.md)第 4.5 节已讲早停的原理，这里补实现细节：

- **监控指标**：通常监控验证误差或验证损失，不是训练损失——训练损失几乎一直在降，盯它没有意义。
- **耐心值（patience）**：验证误差回升一轮就停太敏感（验证误差本身有噪声），常见做法是等它连续 P 轮没有改善再停，P 就是耐心值。P 太小会提前停在噪声波动里，P 太大则多训了无用轮数。
- **恢复最佳权重**：停的时候，模型权重是“回升后”的版本，正确做法是回滚到验证误差最低的那一轮的权重，而不是停在哪就用哪。很多训练框架的早停回调自带这个功能，要确认它开了。
- **早停的定位**：早停不花额外算力，是最便宜的正则化手段之一；但它只能控制“训多久”，管不了“模型本身有多复杂”——模型结构过大时，早停只能缓解，不能根治。

### 4.5 更多数据：最直接的正则化

数据量增加时，模型想背下全部噪声的成本越来越高，泛化误差与训练误差的 gap 随之缩小。第 3.2 节的学习曲线就是判断这条路是否有效的工具：如果 gap 随数据量增大而缩小，加数据有效；如果两者都高且靠拢后不再下降，是欠拟合，加数据没用。更多数据常常是最有效的手段，也常常是最贵的——标注成本、采集成本都要算进去。

### 4.6 一个可跑通的演示：过拟合 gap 与正则化的压制

下面这段代码用 numpy 手算多项式回归与岭回归：25 条训练样本、35 条验证样本，目标是 `y = sin(x) + 噪声`。本机实测输出附后（Python 3.12.3、numpy 1.26.4）：

```python
import numpy as np
rng = np.random.default_rng(0)
x = rng.uniform(0, 2*np.pi, 60)
y = np.sin(x) + rng.normal(0, 0.3, 60)
x_tr, y_tr = x[:25], y[:25]
x_va, y_va = x[25:], y[25:]

def poly_design(x, deg):
    return np.vander(x, deg+1, increasing=True)

def ridge_fit(X, y, lam):
    d = X.shape[1]
    A = X.T @ X + lam*np.eye(d); A[0,0] -= lam  # 不罚截距项
    return np.linalg.solve(A, X.T @ y)

def mse(X, y, w):
    return float(np.mean((X @ w - y)**2))

for deg in [1, 3, 9]:
    w = ridge_fit(poly_design(x_tr, deg), y_tr, 0.0)
    print(f"deg={deg} lam=0: train_mse={mse(poly_design(x_tr,deg),y_tr,w):.4f} val_mse={mse(poly_design(x_va,deg),y_va,w):.4f}")
for lam in [0.0, 0.1, 1.0, 10.0]:
    w = ridge_fit(poly_design(x_tr, 9), y_tr, lam)
    print(f"deg=9 lam={lam}: train_mse={mse(poly_design(x_tr,9),y_tr,w):.4f} val_mse={mse(poly_design(x_va,9),y_va,w):.4f}")
```

```text
deg=1 lam=0: train_mse=0.2037 val_mse=0.4261
deg=3 lam=0: train_mse=0.1038 val_mse=0.1152
deg=9 lam=0: train_mse=0.0467 val_mse=1.7974
deg=9 lam=0.0: train_mse=0.0467 val_mse=1.7974
deg=9 lam=0.1: train_mse=0.0611 val_mse=0.1303
deg=9 lam=1.0: train_mse=0.0619 val_mse=0.1111
deg=9 lam=10.0: train_mse=0.0628 val_mse=0.0866
```

三点解读：第一，9 次多项式无正则化时，训练误差 0.0467、验证误差 1.7974，gap 近 40 倍——这是过拟合的教科书式症状，训练分数越漂亮、验证越惨；第二，1 次多项式两者都高（0.2037 / 0.4261），是欠拟合，不是过拟合；第三，给 9 次多项式加 L2 后，训练误差只轻微上升（0.0467 → 0.0628），验证误差从 1.7974 掉到 0.0866——这就是正则化“拿一点偏差换方差大幅下降”的现场演示。

## 5. 典型应用

- **小数据建模**：样本少、特征多时，L1/L2 是默认配置；L1 还能顺带指出哪些特征重要。
- **图像分类**：数据增强 + Dropout + 早停是标准组合，三者约束的位置不同，可以叠加使用。
- **表格数据竞赛与工业模型**：L2 与早停（树模型的早停轮数）是控制过拟合最常用的两招，因为便宜、可解释、好调。
- **上线前诊断**：学习曲线与训练/验证 gap 是模型上线评审的常规检查项——gap 大到离谱的模型不能上线，不管训练分数多好看。

## 6. 限制与常见误解

- **“正则化能治一切过拟合”**：不能。数据泄露、标签错误、分布漂移造成的“验证分数差”，正则化治不了；数据有偏造成的某类样本差，正则化也治不了。先诊断病因，再选手段。
- **“正则化越强越好”**：λ 过大、Dropout 比例过高、早停过早，都会把模型压成欠拟合。正则化强度本身是超参数，要用验证集选，不是用信念选。
- **“训练误差降到零就是学会了”**：训练误差为零而验证误差很高，恰恰是过拟合的定义。训练误差只是“做过的题的分数”，见[机器学习基础](01-ml-basics.md)第 5 节。
- **“Dropout 推理时也要开”**：错。推理时 Dropout 关闭、全部神经元参与；训练时随机关闭、推理时全开的行为不一致是设计如此，不是 bug。推理时要不要缩放权重，取决于训练实现用的是哪种约定。
- **“数据增强随便加”**：增强必须保持标签语义。翻转、裁剪、加噪之前，先确认变换后的样本答案没变——变了的增强等于往训练集里掺错标签。

## 7. 小结

过拟合认的是训练与验证误差的 gap，学习曲线把 gap 画成随轮数或数据量的变化；正则化统一做一件事——限制模型自由度，L1/L2 约束权重、Dropout 约束神经元依赖、数据增强约束输入扰动、早停约束训练轮数；代价是对称的，约束过头就是欠拟合，强度要用验证集选；数据泄露与数据有偏不在正则化的治疗范围内。
