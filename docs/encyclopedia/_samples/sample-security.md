# 样例骨架：弱口令风险的防御研究（安全研究类）

> 本页是安全研究模板的样例骨架：只写结构与防御侧内容，不写成正式文章，不进导航。
> 本页不含任何口令猜测、爆破、字典生成、凭据获取的操作步骤；只讲风险、检测与防御。

## 1. 技术原理

（示例结构）口令是“你知道的东西”这一类身份凭证；弱口令的风险在于可猜测空间小，攻击者不需要攻破系统本身就能通过正常登录入口进入。原理讲到这里为止，不展开猜测方法。

## 2. 合法研究范围

本专题的研究只限自有设备、授权系统或隔离靶场；用自有测试账号做实验。未授权测试他人系统是违法行为，本文不提供相关指导。

## 3. 实验环境

- 环境：（示例）隔离虚拟机 + 自有测试账号，与生产账号隔离
- 软件与版本：（示例）只列检测与防御侧工具，成文时补
- 权限要求：（示例）查看登录日志需要管理员权限

## 4. 风险

（示例）弱口令导致账号被盗用的风险；同一口令多处复用会放大损失；规避做法：每个系统独立口令、开启多因素认证。

## 5. 检测方式

（示例）登录失败日志短时间内大量出现、异地登录告警；只写检测侧，不写规避检测的方法。

## 6. 修复与防御方法

（示例）口令长度与复杂度策略、多因素认证、登录失败锁定与告警、定期复核长期未换口令的账号。
