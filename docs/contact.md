# 联系方式

本站不公开个人邮箱与电话，请通过以下渠道联系，看到后会处理。

## 内容问题与建议

指南正文有误、命令在新版本上失效、或有更好的做法，请到内容源码仓库提 Issue：

- [curzydj8/ubuntu-server-guide · Issues](https://github.com/curzydj8/ubuntu-server-guide/issues)

提 Issue 时请说明出错的章节链接、你的 Ubuntu 版本、以及复现步骤或报错原文，方便核对。

## 隐私与账号删除

如需删除登录账号，请在仓库 Issue 中说明你的登录用户名（不要贴密码、Token 或其他凭证），核对后本站会删除该账号及其第三方绑定记录。

## 其他说明

广告投放相关的问题同样走仓库 Issue。本站不接受通过聊天软件私信提交的账号、密码或密钥，任何凭证请只在你自己的服务器与第三方后台操作，不要发给站长或贴在公开 Issue 里。
