# 第 15 部分：Linux 命令速查手册

本部分是《Ubuntu Server 终极指南》的速查手册，与前面各部分的教程分工明确：**速查给参数与示例，教程给原理与完整流程**。遇到具体命令记不清参数时，先在本部分按分类定位条目，抄示例改参数即可执行；需要理解背后的机制、做系统性的配置变更或处理生产故障时，再顺着条目中的链接回到对应教程章，按完整流程操作。

两者互相链接：速查条目在「用途」或文末给出对应的教程章节，教程章中涉及的常用命令也会回链到本部分的条目。不要只看速查就去改生产配置——速查默认你已经知道自己在改什么；不确定时先读教程。

本部分面向 Ubuntu Server 22.04 / 24.04 LTS。示例中的 IP 地址统一使用文档专用段 `192.0.2.x`，示例用户为 `ubuntu`，实际执行时替换为你的真实地址与账号。Ubuntu 26.04 不在本部分的验证范围内，不宣称已验证。

## 条目结构说明

本部分每条命令都按同一结构编写，方便快速扫读：

| 小节 | 内容 |
|------|------|
| **用途** | 一句话说明这条命令解决什么问题 |
| **语法** | 命令的通用写法：`命令 [选项] 参数` |
| **参数表** | 只列 3–6 个最常用参数，不堆冷门选项 |
| **示例** | 一段真实可跑的 bash 示例，必要时附输出示例与一句解读 |
| **常见错误** | 1–2 句点出新手最容易踩的坑 |
| **风险提示** | 一句话说明误用后果；危险操作单独用红色警示块标注 |

阅读约定：

- 示例中出现的路径、IP、用户名都是示例值，执行前替换为你的真实值。
- 带 `sudo` 的示例表示需要管理员权限；不带 `sudo` 的查询类命令不要习惯性加 `sudo`。
- 参数表只收高频参数，完整参数以本机 `命令 --help` 与 `man 命令` 为准。

!!! danger "危险命令总警示：先确认，再执行"

    以下操作一旦执行错对象，数据通常不可恢复。任何一条命中时，先停下来逐项核对路径、主机与备份：

    - `rm -rf`：递归强制删除。在 `/`、`/etc`、`/home`、`/var` 等系统或家目录上误用会直接删掉系统或全部用户数据。执行前先用 `ls` 看清目标，先不带 `-f` 试跑，需要批量删除时优先考虑可恢复的删除方式。
    - `chmod -R` 与 `chown -R`：递归改权限或属主。作用在系统目录上会让服务无法读取文件、SSH 拒绝登录甚至系统无法启动；只对明确的业务目录使用，并先小范围验证。
    - `dd`、`mkfs`、重定向覆盖系统文件等写盘操作：写错设备或文件即覆盖原数据，先用 `lsblk`、`df` 确认目标。
    - 涉及远程主机的命令（`ssh`、`scp`、`rsync` 删除同步）：先确认连的是哪台机器——在错的机器上执行正确的命令，同样是事故。

本部分各章还会针对本章的危险命令给出单独警示与安全替代写法，全站原则一致：**命令可以抄，目标必须自己核对**。

速查解决「怎么写」，教程解决「为什么与何时用」。配合使用，先查后做，改前备份，改后验证。
