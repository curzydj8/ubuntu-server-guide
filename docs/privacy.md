# 隐私政策

最后更新：2026-11-01。本政策适用于 crozz.me 上的指南浏览与登录服务（`/login`、`/dashboard`、`/auth/*`）。本站由署名“火星极客”的站长运营，内容源码见 [curzydj8/ubuntu-server-guide](https://github.com/curzydj8/ubuntu-server-guide)。

## 一、浏览指南时收集什么

浏览指南正文不需要登录，本站不主动收集你的姓名、邮箱等身份信息，也不使用统计分析工具。

为保障服务运行与排查故障，服务器与 Cloudflare Tunnel 在提供服务时可能记录 IP 地址、访问时间、请求的页面、浏览器标识等技术日志。这些日志仅用于保障服务运行与故障排查，不出售，也不用于制作个人画像。

## 二、登录时收集什么

本站只支持 GitHub 与 Google 第三方登录，没有账号密码注册。登录由第三方完成，本站不获取、不存储你的第三方账号密码。

登录成功后，本站保存的只有：用户名（GitHub 登录名，或 Google 邮箱前缀，冲突时加后缀）、第三方账号标识、账号创建时间。登录时从第三方获取的邮箱仅用于生成用户名建议，不单独保存为联系方式。

登录依赖以下 Cookie：

- `session_id`：登录会话，HttpOnly、Secure，有效期 7 天；登出时会删除服务器端的会话。
- `csrf_token`：防伪造提交用的 Cookie，不含身份信息。

## 三、Cookie 与广告

本政策发布时，本站尚未投放广告，指南页不设广告 Cookie。

本站计划投放 Google AdSense。投放后，第三方广告商（含 Google）可能在你的浏览器中放置或读取 Cookie，或使用网络信标、IP 地址等信息，根据你此前访问本站或其他网站的情况投放广告。你可以按以下方式退出个性化广告：

- Google 广告设置：https://www.google.com/settings/ads
- 行业退出页：https://optout.aboutads.info/

在浏览器中禁用第三方 Cookie 不影响本站登录（登录 Cookie 属于本站自身），但禁用全部 Cookie 会导致无法保持登录。

## 四、第三方服务

本站使用的第三方服务及用途：

- Cloudflare：域名解析与隧道，指南流量经其网络到达本站服务器。
- GitHub：第三方登录，以及内容源码仓库。
- Google：第三方登录，以及未来的广告投放。

点击本站内的站外链接后，适用对方的隐私政策，不适用本政策。

## 五、数据共享与安全

本站不出售个人信息，不向广告商提供可识别你身份的信息。登录数据与会话存储在站长自有服务器上，数据库与缓存不对公网开放。法律要求披露的情形除外。

## 六、你的权利

你可以随时登出以结束会话。如需删除登录账号，请按[联系方式](contact.md)说明你的登录用户名，核对后本站会删除该账号及其第三方绑定记录。

## 七、政策变更

本政策更新后会在本页发布，重大变更会在[更新日志](changelog.md)中说明。继续使用本站即表示你了解本政策的当前版本。
