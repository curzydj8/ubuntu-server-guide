# 隐私政策

最后更新：2026-11-06。本政策适用于 crozz.me 上的指南浏览、账号服务（`/login`、`/register`、`/forgot`、`/dashboard`、`/board`、`/auth/*`）与广告投放。本站由署名“火星极客”的站长运营，内容源码见 [curzydj8/ubuntu-server-guide](https://github.com/curzydj8/ubuntu-server-guide)。

## 一、浏览指南时收集什么

浏览指南正文不需要登录，本站不主动收集你的姓名、邮箱等身份信息，也不使用统计分析工具。

为保障服务运行与排查故障，服务器与 Cloudflare Tunnel 在提供服务时可能记录 IP 地址、访问时间、请求的页面、浏览器标识等技术日志。这些日志仅用于保障服务运行与故障排查，不出售，也不用于制作个人画像。

## 二、注册与登录时收集什么

本站提供两种注册登录方式：用户名密码注册，以及 GitHub / Google 第三方登录。

密码注册时需要提供：用户名、密码、姓、名、生日、年龄、邮箱。本站保存用户名、加密后的密码（只存哈希，不存明文）、姓、名、生日、邮箱、注册 IP 与注册时间。生日与年龄仅用于核对两者是否一致，不作其他用途。一个 IP 只能注册一个账号。

第三方登录由 GitHub / Google 完成，本站不获取、不存储你的第三方账号密码。登录成功后，本站保存用户名（GitHub 登录名，或 Google 邮箱前缀，冲突时加后缀）、第三方账号标识、账号创建时间。登录时从第三方获取的邮箱仅用于生成用户名建议，不单独保存为联系方式。

登录会话只在当天有效（到北京时间当天午夜过期），第二天需重新登录。登出时会删除服务器端的会话；重设密码后，该账号在其他地方的登录会话会立即失效。

留言板：登录后可留言，人人能看。留言保存用户名、留言内容与发布时间。留言只用于公开展示，不作其他用途；你可以删除自己的留言。

登录依赖以下 Cookie：

- `session_id`：登录会话，HttpOnly、Secure，当天有效；登出时会删除服务器端的会话。
- `csrf_token`：防伪造提交用的 Cookie，不含身份信息。

## 三、Cookie 与广告

本站投放 Google AdSense 广告。Google 及其他第三方广告商可能在你的浏览器中放置或读取 Cookie，或使用网络信标、IP 地址等信息，根据你此前访问本站或其他网站的情况投放广告。广告 Cookie 与本站登录 Cookie 是两回事：在浏览器中禁用第三方 Cookie 不影响本站登录（登录 Cookie 属于本站自身），但禁用全部 Cookie 会导致无法保持登录。

你可以选择退出个性化广告：

- Google 广告设置：https://www.google.com/settings/ads
- 行业退出页：https://optout.aboutads.info/
- Google 合作伙伴网站政策（说明 Google 如何使用合作网站的数据）：https://policies.google.com/technologies/partner-sites

来自欧洲经济区、英国、瑞士的访客首次访问本站时，会看到本站的意见征求提示（由 Google 的意见征求管理工具提供），可选择同意或拒绝个性化广告；拒绝后仍可正常浏览本站，广告将以非个性化方式投放。来自美国的访客会看到美国州级法规相关的隐私提示，可选择退出个人信息的出售或共享（本站不出售个人信息，见第五节）。

## 四、第三方服务

本站使用的第三方服务及用途：

- Cloudflare：域名解析与隧道，指南流量经其网络到达本站服务器。
- GitHub：第三方登录，以及内容源码仓库。
- Google：第三方登录，以及广告投放（含 AdSense）与意见征求管理。
- 阿里云邮件推送（DirectMail）：仅用于发送注册与找回密码的验证码邮件，发信地址为 noreply@mail.crozz.me。

点击本站内的站外链接后，适用对方的隐私政策，不适用本政策。

## 五、数据共享与安全

本站不出售个人信息，不向广告商提供可识别你身份的信息。广告投放中使用的数据（例如 Cookie 标识、IP 地址、浏览记录）由 Google 及其他广告商按其自身政策处理，本站不掌握、不转售。

登录数据、留言与会话存储在站长自有服务器上，数据库与缓存不对公网开放。法律要求披露的情形除外。

## 六、你的权利

你可以随时登出以结束会话。如需删除登录账号、删除留言或查询本站保存的你的数据，请按[联系方式](contact.md)说明你的登录用户名，核对后本站会删除该账号及其第三方绑定记录。

位于欧洲经济区、英国、瑞士的访客还享有：访问、更正、删除、限制处理、数据可携、反对处理，以及随时撤回同意的权利；行使方式同上（按[联系方式](contact.md)联系站长）。

位于美国加州等有州级隐私法规地区的访客享有：知情、删除、更正个人信息的权利，以及选择退出个人信息出售或共享的权利；本站不出售个人信息，如需行使上述权利，按[联系方式](contact.md)联系站长即可。
