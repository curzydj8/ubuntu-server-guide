## 6. 技术原理

CSS 的全称是 Cascading Style Sheets，层叠样式表。它不是编程语言，没有“运行”，只有“匹配”和“应用”两件事：

1. **匹配**：浏览器读到一条 CSS 规则，先看选择器，看页面里哪些元素符合这个选择器；
2. **应用**：符合的元素，就按规则里的声明去显示：声明是一组“属性: 值”，比如 `color: red` 是“文字颜色红色”，`font-size: 20px` 是“字号 20 像素”。

“层叠（Cascading）”是 CSS 名字的核心，意思是：同一个元素可能同时被多条规则选中，浏览器要按一套固定的顺序决定最后用哪条——这套顺序就是第 12 节讲的优先级。理解了层叠，就理解了 CSS 一大半的“为什么没生效”。

浏览器处理一个页面的顺序，大致是：下载 HTML → 按标签搭出页面结构 → 下载 CSS（外部样式表或内部 `<style>`）→ 按选择器匹配每个元素 → 按优先级算出每个元素的最终样式 → 显示出来。所以 CSS 写错了不会让页面打不开，只会让某块样式没生效或生效错了，排查时先看“选择器有没有选中”，再看“优先级有没有被盖住”。

## 7. 架构说明

一个 CSS 文件（或一段内部样式）的基本结构只有一种，就是“规则”：

```text
选择器 {
  属性: 值;
  属性: 值;
}
```

- 选择器在前，告诉浏览器“这条规则给谁用”；
- 大括号里是声明块，每条声明是“属性: 值;”，冒号分隔属性和值，分号结束一条声明，最后一条声明的分号可以省略，但建议每次都写，少写分号是新手最常见的 CSS 报错来源；
- 注释用 `/* 注释内容 */`，HTML 的 `<!-- -->` 在 CSS 里是无效的，不要混用。

三种引入方式在页面里的位置不同，作用也不同：

```text
行内：写在某个标签的 style 属性里，只对这一个标签生效
内部：写在 head 里的 <style> 标签里，对当前这一个页面生效
外部：写在单独的 .css 文件里，用 <link rel="stylesheet" href="style.css"> 引入，对所有引用它的页面生效
```

正式网站用外部样式表，是因为多个页面可以共用一份样式，改一处就全站都变了；学习阶段用内部样式，是因为一个文件就能看效果，不用来回切换文件。本篇的完整示例用内部样式，方便你一个文件跑通；第 10 节后面还给了外部样式表的写法，两个都要会。

## 10. 完整代码

下面是本篇的完整示例，没有省略号，复制下来就是一个能打开的页面。存放位置：练习文件夹里的 `css-basics.html`，样式写在 `head` 里的 `<style>` 标签里，是内部引入方式。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>CSS 基础语法与选择器示例</title>
  <style>
    body {
      color: #333333;
      font-size: 16px;
    }
    h1 {
      color: #1a5276;
    }
    .highlight {
      color: #c0392b;
    }
    #main-title {
      font-size: 28px;
    }
    nav ul {
      list-style: none;
    }
    nav > ul {
      margin: 0;
    }
    h2 + p {
      color: #2e7d32;
    }
    h2 ~ p {
      font-size: 16px;
    }
    h1, h2 {
      font-weight: bold;
    }
    input[type="text"] {
      border: 1px solid #999999;
    }
    a:hover {
      color: #e67e22;
    }
    p::first-letter {
      font-size: 20px;
    }
  </style>
</head>
<body>
  <header>
    <h1 id="main-title">CSS 基础示例</h1>
    <p class="highlight">这一段用了类选择器，文字是红色的。</p>
  </header>
  <nav>
    <ul>
      <li><a href="#notes">学习笔记</a></li>
      <li><a href="#links">相关链接</a></li>
    </ul>
  </nav>
  <main>
    <section id="notes">
      <h2>学习笔记</h2>
      <p>这是紧跟在 h2 后面的第一段，颜色是绿色的（相邻兄弟选择器）。</p>
      <p>这是同一节里的第二段，字号和 body 保持一致（通用兄弟选择器只改了字号，没有改颜色）。</p>
    </section>
    <section id="links">
      <h2>相关链接</h2>
      <p><input type="text" placeholder="请填写姓名"></p>
      <p><a href="https://developer.mozilla.org/zh-CN/docs/Web/CSS">MDN CSS 文档</a></p>
    </section>
  </main>
  <footer>
    <p>© 2026 CSS 基础示例</p>
  </footer>
</body>
</html>
```

外部样式表的写法（和上面内部样式的效果相同，只是文件分开了）：

先新建文件 `style.css`，放在和 HTML 同一个文件夹里，内容就是上面 `<style>` 标签里面的全部规则，不要带 `<style>` 标签本身：

```css
body {
  color: #333333;
  font-size: 16px;
}
h1 {
  color: #1a5276;
}
.highlight {
  color: #c0392b;
}
```

然后在 HTML 的 `head` 里删掉 `<style>` 标签，换成下面这一行，位置同样在 `head` 里：

```html
<link rel="stylesheet" href="style.css">
```

## 12. 每个关键选择器和概念的解释

### 选择器总表

| 选择器 | 写法 | 选的是什么 | 本篇示例 |
|---|---|---|---|
| 通用选择器 | `*` | 页面里所有元素 | 本篇没用，因为它会选中所有元素，性能和可控性都不好，只在“全局清零”这种极少数场景用 |
| 元素选择器 | `h1`、`p`、`body` | 所有叫这个名字的标签 | `h1 { color: #1a5276; }` |
| 类选择器 | `.highlight` | 所有 `class` 里有 `highlight` 的元素 | `<p class="highlight">` 那一段变红 |
| ID 选择器 | `#main-title` | `id` 等于 `main-title` 的那个元素，一个页面里 `id` 只能出现一次 | `<h1 id="main-title">` 的字号变 28px |
| 后代选择器 | `nav ul` | `nav` 里面的所有 `ul`，不管隔了几层 | `nav ul { list-style: none; }` 去掉导航列表的圆点 |
| 子代选择器 | `nav > ul` | `nav` 的直接子元素 `ul`，隔了一层就不算 | `nav > ul { margin: 0; }`，如果 `ul` 外面还包了一层 `div`，这条就不生效 |
| 相邻兄弟选择器 | `h2 + p` | 紧跟在 `h2` 后面的那一个 `p`，中间不能隔别的元素 | “学习笔记”那一节的第一段变绿，第二段不变绿 |
| 通用兄弟选择器 | `h2 ~ p` | 在 `h2` 后面的所有同级 `p`，不管隔了几个 | 同一节里的两段字号都受这条影响 |
| 分组选择器 | `h1, h2` | 逗号两边的选择器选中的所有元素，共用同一组声明 | `h1, h2 { font-weight: bold; }` |
| 属性选择器 | `input[type="text"]` | `type` 属性等于 `text` 的 `input` | 文本框的边框变灰，密码框不受影响（因为它的 `type` 是 `password`） |
| 伪类 | `a:hover` | 元素处于某种状态时：`hover` 是鼠标悬停时 | 鼠标移到链接上，链接变橙色，移开恢复 |
| 伪元素 | `p::first-letter` | 元素的某个部分：`first-letter` 是每段的第一个字 | 每段的第一个字变 20px；注意伪元素写两个冒号 `::`，伪类写一个冒号 `:`，不要混用 |

### 优先级：冲突时谁赢

优先级按“权重”算，权重高的赢，权重相同、后写的赢。权重记成四组数字（行内样式，ID 个数，类/属性/伪类个数，元素/伪元素个数），从左往右比，左边大就赢，不用加起来算总分：

| 规则 | 权重示例 | 说明 |
|---|---|---|
| `!important` | 最高，慎用 | 写在声明后面，比如 `color: red !important;`，它会盖过一切正常声明；用多了以后想改都改不动，本篇只讲概念，不建议日常用 |
| 行内样式 | （1, 0, 0, 0） | 写在标签 `style` 属性里的样式，权重最高（仅次于 `!important`） |
| ID 选择器 | （0, 1, 0, 0） | 一个 ID 算 1 个 ID 位 |
| 类、属性、伪类选择器 | （0, 0, 1, 0） | 一个类、一个属性、一个伪类各算 1 个类位 |
| 元素、伪元素选择器 | （0, 0, 0, 1） | 一个元素、一个伪元素各算 1 个元素位 |
| 通用选择器、继承 | （0, 0, 0, 0） | 权重最低，任何正常规则都能盖过它 |

举三个例子，算一遍就明白了：

- `p { color: red; }` 是（0, 0, 0, 1），`.highlight { color: blue; }` 是（0, 0, 1, 0），类赢，所以 `<p class="highlight">` 是蓝色；
- `#main-title { font-size: 28px; }` 是（0, 1, 0, 0），`h1 { font-size: 20px; }` 是（0, 0, 0, 1），ID 赢，所以那个 `h1` 是 28px；
- 两条权重完全相同的规则，比如两个 `p { color: ...; }`，后写的那条赢，这就是“层叠”里“后来者居上”的部分。

### 继承：哪些属性子元素会跟着变，哪些不会

- **会继承**：文字相关的，`color`、`font-size`、`font-family`、`line-height`、`text-align` 等。给 `body` 写了 `color: #333333`，页面里所有文字默认都是这个颜色，除非子元素自己又写了别的颜色——本篇示例里 `body` 的颜色就是这么传到各段去的。
- **不会继承**：盒子相关的，`margin`、`padding`、`border`、`background`、`width`、`height` 等。给父元素写了边框，子元素不会自动有边框；给父元素写了内边距，子元素不会自动有内边距。
- 强制继承：给某个属性写 `inherit`，就是明确说“跟父元素一样”，比如 `a { color: inherit; }` 是让链接颜色跟父元素一致，而不是浏览器默认的蓝色；这个技巧在后面做主题时会经常用到。

## 15. 常见错误

| 错误 | 现象 | 改法 |
|---|---|---|
| 漏写大括号或分号 | 后面的样式全乱了，或者整段样式不生效 | 每条规则检查一遍：选择器后面有 `{`，声明后面有 `;`，规则最后有 `}` |
| 选择器写错一个字母 | 那条样式完全不生效，页面其他部分都正常 | 对照 HTML 里的 `class`、`id`、标签名，一个字母一个字母对 |
| `class` 和 `id` 混用 | 类选择器写了 `.` 却去选 `id`，或反过来 | 类用 `.`，ID 用 `#`，HTML 里 `class="highlight"` 对应 `.highlight`，`id="main-title"` 对应 `#main-title` |
| 一个页面多个相同 `id` | 样式时有时无，JS 以后也会出问题 | `id` 全页唯一，需要复用的样式用 `class`，不要用 `id` |
| 权重算错，以为后写的总能赢 | 后写的元素规则盖不过先写的类规则 | 按第 12 节的四组数字算权重，类永远大于元素，不管先后顺序 |
| 滥用 `!important` | 一开始好使，越改越乱，最后到处都要加 `!important` | 删掉 `!important`，用提高选择器权重或调整顺序解决冲突 |
| 指望 `margin`、`border` 继承 | 给父元素写了边框，子元素没有 | 盒子属性不继承，需要的子元素自己再写一遍 |
| HTML 注释写进 CSS | 注释没生效，后面的样式也可能乱 | CSS 注释用 `/* */`，不要用 `<!-- -->` |
| 外部样式表路径写错 | 页面全是默认样式，像没写 CSS 一样 | 检查 `<link>` 的 `href` 和 `style.css` 的文件名、文件夹是不是一致，大小写也要一致 |
| 伪类和伪元素冒号混用 | `p:first-letter` 写成一个冒号，或 `a::hover` 写成两个冒号，样式不生效 | 伪类一个冒号（`:hover`），伪元素两个冒号（`::first-letter`） |

## 16. 故障排查

- **样式完全没生效**：先看 `<style>` 是不是在 `head` 里、`<link>` 的路径对不对；再看选择器是不是选中了元素（开发者工具里搜一下选择器对应的元素名）；再看是不是被更高优先级的规则盖住了（开发者工具里被盖住的规则会显示删除线）。
- **只生效了一部分**：从生效的那条往下查，第一条不生效的规则前面很可能漏了 `}` 或 `;`，导致后面的规则被当成前一条的一部分。
- **颜色变了，字号没变（或反过来）**：说明两条规则的优先级不一样，或者字号被 `body` 的继承和某条直接规则打架了——按第 12 节算一遍权重，直接写在元素上的规则永远大于继承来的。
- **外部样式搬过去后效果变了**：检查是不是搬漏了某条规则、是不是把 `<style>` 标签本身也搬进了 `.css` 文件（`.css` 文件里不能有 `<style>` 标签）。
- **改了 CSS 刷新没变**：确认保存了，再按 Ctrl+F5 强制刷新，排除浏览器缓存；外部样式表尤其容易被缓存，改完看不到变化先强制刷新一次。

## 17. 安全注意事项

- CSS 本身不能直接偷数据、不能运行脚本，但从不可信来源引入的外部样式表（比如随便贴来的 `<link>`）仍然有风险：对方可以换掉样式表内容、记录你的访问、甚至用 CSS 技巧试探页面结构。正式网站只引用自己站内或可信 CDN 的样式表，不要贴来路不明的 `<link>`。
- 不要把真实用户的隐私信息写进示例 CSS 里，颜色值、字号这些占位数据就够了。
- `!important` 不是安全问题，是维护问题：用多了以后别人（包括以后的你）改不动样式，团队项目里要约定好不用或少用。

## 18. 回滚和恢复

本篇和 WEB 系列一样，没有服务器、没有数据库、没有配置改动，回滚就是：

- 改错了：编辑器里 Ctrl+Z 撤销，或把第 10 节的完整代码重新复制覆盖一次；
- 外部样式搬错了：删掉 `style.css` 的引用，把 `<style>` 版本恢复，效果就回来了；
- 文件删错了：重新新建 `css-basics.html`（和 `style.css`，如果练了外部写法），把第 10 节代码再贴一遍；
- 没有任何线上内容会被影响，因为本篇文件只在你的练习文件夹里，还没有部署到 crozz.me。
