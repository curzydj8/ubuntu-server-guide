# 第 01 部分 基础入门与安装

欢迎来到《Ubuntu Server 终极指南》的起点。本部分解决一台服务器从无到有的问题：选对版本、装好系统、连上网络、管好软件。四章环环相扣，学完即可得到一台能远程登录、地址固定、软件源顺畅的生产就绪主机，后续所有服务部署都建立在这块地基之上。

## 本部分地图

```text
01 版本选择与生命周期 ── 决定装什么、用多久、何时升级
          │
          ▼
02 系统安装 ─────────── 制作启动盘、Subiquity 安装、分区与 LVM
          │
          ▼
03 首次登录与网络初始化 ─ Netplan 静态地址、DNS、网桥与 VLAN
          │
          ▼
04 软件源与包管理 ────── APT 镜像加速、snap 与 flatpak 与 dpkg 对比
```

这条主线对应真实的装机顺序：先决策，再安装，再联网，最后补给。任何一步跳过，后面都会以更贵的方式补回来，例如版本选错要重装，地址没固定会失联，软件源没配好则每次更新都在等待。

## 每章一句话

- **01 版本选择与 Lifecycle**：讲清 LTS 与普通版的区别、支持周期与升级路径，帮你在安装前就选对未来五年的版本。
- **02 系统安装**：从校验镜像、制作启动盘到 Subiquity 逐屏操作与 LVM 分区，给出一套可照抄的装机流程。
- **03 首次登录与网络初始化**：完成首次登录检查，并用 Netplan 配好静态地址、DNS、网桥与 VLAN，让服务器稳定可达。
- **04 软件源与包管理**：换好 APT 镜像源并讲透 apt、dpkg、snap、flatpak 的分工，让装软件又快又不乱。

## 推荐学习顺序

按 01 到 04 的编号顺序学习，不要跳章。01 的版本结论决定 02 用的镜像，02 留下的网卡名与磁盘布局是 03 写 Netplan 的输入，03 的网络连通又是 04 更换软件源的前提。已有经验的读者可快速浏览 01 与 02，但 03 的网桥与 VLAN、04 的包管理对比建议完整阅读，这两处是日常运维的高频操作。

## 前置知识与准备

开始前你需要：一台 x86_64 物理机或虚拟机，最低 2 核 CPU、4 GB 内存、25 GB 磁盘；一个 8 GB 以上 U 盘用于制作启动盘；一个能下载镜像的网络环境；以及基础的命令行常识，知道如何打开终端并执行命令即可。本部分所有命令默认在 Ubuntu Server 22.04 LTS 与 24.04 LTS 上验证，示例地址只用文档段 192.0.2.0/24 与 198.51.100.0/24，示例域名只用 example.com 与 example.org，示例用户只用 ubuntu 与 opsadmin，请在实操时换成你自己的真实规划。

!!! tip "阅读约定"

    本部分每章都按概述、环境准备、操作步骤、效果验证、排坑、生产实践六段展开；遇到标注了版本号的提示块，说明该处 20.04、22.04、24.04 之间存在差异，请先确认自己系统的版本再执行命令。

学完本部分，你应当能独立完成一台 Ubuntu Server 的选版、安装、联网与软件源配置，并能用验证命令确认每一步真的生效，而不是停留在命令执行成功的错觉上。
