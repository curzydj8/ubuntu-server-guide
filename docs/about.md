# 关于本站

本站是《Ubuntu Server 终极指南与实战教程》，主站为 crozz.me，内容源码公开在 [curzydj8/ubuntu-server-guide](https://github.com/curzydj8/ubuntu-server-guide)，作者署名火星极客。

## 本站写给谁

面向真实生产环境的 Ubuntu Server 运维读者：从装机、安全加固、存储网络、容器监控、数据库，到自动化与故障应急，全部给出开箱即用的完整命令与配置文件，不省略关键步骤。

## 写作与验证口径

每章统一六段式结构：概述与场景 → 前置条件 → 手把手步骤（改配置前先备份、关键参数逐行讲解）→ 效果验证 → 排坑指南 → 生产最佳实践。

验证口径如实说明，不夸大：核心流程已在 Ubuntu 22.04 / 24.04 LTS 实机上实际使用过；其余章节为与官方文档逐项核对后的“文档核对”级别，未在实机完整验证；Ubuntu 26.04 LTS 的兼容性目前一律为“待核验”。各主题的详细状态以[版本兼容与验证状态](compatibility.md)为准，正文与该页冲突时以该页为准。

## 运营方式

本站指南正文免费公开阅读，不需要登录。登录仅用于本站个人页，当前只支持 GitHub 与 Google 第三方登录，数据处理方式见[隐私政策](privacy.md)。

本站计划通过 Google AdSense 维持运营，广告上线后以隐私政策中的广告说明为准，广告代码与 ads.txt 只在获批后按谷歌给出的信息添加。
