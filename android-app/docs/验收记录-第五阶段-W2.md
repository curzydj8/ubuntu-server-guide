# 验收记录 · 第五阶段 W2（功能 UI）

日期：2026-10-24　对应计划：docs/实施计划-第五阶段.md（W2 功能 UI）　版本：仍为 0.5.3（0.6.0 按计划于 W3 真机验收后定版）

## 交付内容

- **新模块 `feature:servers`**（按计划入口：底部三栏不变，从「工具」页顶部卡片进入 `servers/...` 路由）：
  - **主机列表**：别名/地址/标签/用户名搜索、分组筛选 chips、连接状态（未连接/连接中/已连接/失败原因）就地展示；卡片操作：连接/断开、终端、诊断、编辑、删除（二次确认）。
  - **主机编辑**：别名/地址/端口/用户名/分组/标签/备注；认证方式切换（密码/私钥+口令）；凭据只写入 Keystore 保险库（引用 `ssh-host-<id>/pw|key|kp`），档案表不落明文；编辑时凭据留空 = 不修改；表单纯逻辑校验（HostForm）含错误中文提示。
  - **连接与指纹确认**：连接走 W1 的 TOFU 流程；首次连接弹出指纹确认（主机、密钥类型、短指纹+完整指纹可选中复制，90 秒无操作自动拒绝）；指纹变更时连接失败并在卡片上给出「忘记旧指纹」入口。
  - **终端**：core:ssh 新增流式 shell 通道（PTY）；输出流式追加（ANSI 剥离、\r 归一、200K 上限保留尾部）；命令逐行发送；HIGH 风险命令发送前被拦截，弹出「目标主机+命令+风险等级」二次确认，取消则不发送；断线自动提示并更新连接状态。
  - **只读诊断**：8 项预设（系统版本/内核/运行时间/内存/磁盘/块设备/监听端口/失败服务），逐项执行分段展示（命令原文、退出码、输出或错误），单项失败不影响其余；运行前经 CommandRisk 自检，非只读条目会被护栏跳过。
  - **操作审计**：列表页入口；记录 connect/connect-failed/disconnect/diag/term-exec/profile-delete，含时间、主机标签、（脱敏后）命令、风险、退出码，倒序 200 条。
- **core:ssh 增量**：`SshSession.openShell()` + `ShellChannel`（W1 仅有一次性 exec，终端流式能力按计划在 W2 补齐）；CommandRisk 只读白名单增加 `systemctl --failed`（诊断预设所需，本身确为只读查询）。
- **接线**：settings include、app 依赖、AppContainer.serversViewModel()、MainActivity 五条路由（servers / server-edit/{id} / terminal/{id} / diagnostics/{id} / audit）均带返回栏；工具页高亮覆盖服务器各路由。
