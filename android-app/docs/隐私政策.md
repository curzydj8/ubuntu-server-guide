# 隐私政策 — Linux Server Toolkit

生效版本：1.0.0（2026-10-24）。以下陈述以代码为准，如后续版本改动，以新版文档为准。

## 一句话

本应用离线优先：知识、工具、服务器凭据、操作审计全部只存本机；除用户主动触发的网络检测、SSH 连接和版本清单拉取外，不向任何服务器发送数据。

## 1. 收集什么

- **不收集**：无账号、无手机号、无设备标识上报、无统计、无广告、无第三方 SDK。
- **本机数据**：知识库文章（随包内置，首启导入本机 Room）、服务器档案（别名/地址/端口/用户名/分组/标签/备注）、主机密钥指纹（TOFU 信任记录）、操作审计（命令文本、风险等级、退出码，均已脱敏，不含命令输出）。
- **权限**：仅 `INTERNET` 一项，用于 SSH 连接、网络检测工具、版本清单拉取。

## 2. 凭据怎么保管

- 密码、私钥、密钥口令只写入 Android Keystore 保护的保险库（AES-256/GCM 密钥不可导出，密文存应用私有目录 `filesDir/vault/`）；数据库只存保险库引用名，永不存凭据本体。
- 凭据只通过 sshj 通道发往用户自己的服务器；删除档案时保险库凭据一并删除。
- 更新检查不传输凭据、不传输档案信息。

## 3. 联网行为（全部写实）

| 行为 | 触发 | 发出什么 |
|---|---|---|
| N-01 DNS 检测 | 用户在工具页主动点 | DoH 查询（Cloudflare / Google 公共 DNS），查域名解析 |
| N-02 TLS 检测 | 用户主动点 | 与目标站点的 TLS 握手信息 |
| N-03 响应头检测 | 用户主动点 | 目标站点的 HTTP 响应头 |
| 检查更新 | 设置页主动点，或用户触发 | 拉取版本清单 JSON（版本号、说明、APK 地址），不带设备标识 |
| SSH 终端/诊断 | 用户主动连接自己的服务器 | sshj 加密通道，只到用户填的地址 |

其余 30 项 A 类工具、全部 B 类分析器、知识库浏览、审计查看均为纯本地运行。

## 4. 数据去向与删除

- 所有数据只在本机；卸载应用即删全部数据（含保险库与审计库）。
- 本应用不上传、不备份、不共享任何数据到开发者或第三方服务器。
- 审计与日志中的敏感写法（`password/passwd/token/secret/api-key` 键值、Bearer、PEM 私钥块）经集中脱敏后才落盘；主代码一处直接 Log（openShell 失败记异常）不含口令材料（W3 审计建议项，已记录）。

## 5. 联系与变更

本应用为站长个人项目（Ubuntu Server 指南配套工具），无客服通道；隐私政策随版本更新，变更内容写入版本记录。
