# 已知限制 — Linux Server Toolkit 1.0.0

以下为 1.0.0 发布时已知、未修复或受环境制约的事项；不影响核心功能验收，但用户与后续维护应知晓。

## 功能性

- **终端重连后旧 transcript 残留**：SSH 会话断开后重进终端，界面仍显示旧会话 transcript、标题却显示已连接，不会自动重连刷新。 workaround：强制停止应用后重开，点连接，再进终端。
- **空发送被忽略**：终端输入框为空时点发送不传输任何内容；需要回答空行的交互提示无法从应用终端完成。
- **终端为文本流**：不支持 vim/top 等全屏程序（应用内已有提示）。
- **N-10 / N-32 为引擎就绪 + 种子数据**：两项 A 类工具未内置完整数据集，不可冒充完整功能。

## 兼容性与环境

- **仅一台真机验证**：OPPO PEQM00 / Android 13；其他机型、其他 Android 版本未测。
- **ColorOS 拦截 adb 安装测试包**：logcat `PC install attack detected` → `Failure [-99]`，不弹框；测试包须手动安装（不影响正式包安装）。
- **手机网络可污染 workers.dev 解析**：更新检查主清单失败时自动换 Pages 备用清单并重试，污染网络下检查可耗时约 55 秒才报已是最新。
- **到服务器的 Tailscale 路径断**：muse-1 的 Tailscale 通道在验收期不可达，当前主路径为桥接局域网 192.168.1.19；Tailscale 恢复后需重新验证该路径。

## 仓库与流程遗留

- GitHub main 上仍有 `android-app/local.properties`（仅 sdk.dir 路径，无密钥；快照工具无法删除，须站长网页端删）。
- W3 审计建议项（低）：唯一一处直接 Log 未过脱敏器；`Redact` 未覆盖 `mysql -pSecret` 这类无分隔符口令写法。
- 发布密钥由站长自备自管（见 `docs/签名指南.md`）；代理从不经手发布密钥与口令。
