# 发布检查清单 — Linux Server Toolkit

每项发布前逐项打勾；任一项未过不得发布。发布指：更新清单（主备）升版 + release APK 上线 + 快照同步入仓。

## 发布前

- [ ] 版本号：`app/build.gradle.kts` 的 versionCode / versionName 与版本记录一致。
- [ ] 门禁：`./build.sh` BUILD+TEST+LINT 全绿（单测、Lint 0 错误）。
- [ ] R8 回归：release 包（bench 包亦可）真机冒烟通过：启动、知识库 99 篇列表、设置页版本号、服务器列表页。
- [ ] APK + SHA-256：release APK 已签名（站长签名，见签名指南），`sha256sum` 已记录。
- [ ] 文档齐：隐私政策、许可证清单、版本记录、已知限制均为当前版本。
- [ ] 审计建议：W3 建议项状态已确认（可带建议发布，但须在已知限制中列出）。

## 发布时

- [ ] 主清单：Workers 侧 `app/latest.json` 升版（versionName / versionCode / notes；apkUrl 指向直发 APK 地址）。
- [ ] 备清单：gh-pages 分支 `app/latest.json` 同升（与主清单内容一致；CDN 约 90 秒后线上一致）。
- [ ] 线上验证：curl 主备两地址，versionCode 与预期一致。
- [ ] 快照同步：App 源码快照 + `docs/app/latest.json` 经 PR 入 ubuntu-server-guide main，回读验证 versionCode 与验收记录。
- [ ] 真机验证：手机检查更新显示新版（污染网络下走备用清单亦可接受，须报已是最新/可更新且无报错）。

## 回滚

- [ ] 清单回退：主备两份 `app/latest.json` 同时改回上一版 versionCode（单改一份会在污染网络下造成主备不一致）。
- [ ] 旧版覆盖安装：上一版 APK 经 adb 覆盖安装（同签名可直接覆盖；换签须卸载重装，数据重置，提前告知）。
- [ ] 回滚后验证：手机检查更新报已是最新（上一版），知识库 99 篇正常。
