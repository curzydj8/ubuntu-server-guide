# 验收记录 · 第五阶段 W1（核心层）

日期：2026-10-24　对应计划：docs/实施计划-第五阶段.md（W1 协议冒烟 + 核心层）

## 交付内容

- **依赖冒烟（已验证通过）**：sshj 0.41.2（com.hierynomus）、bcprov/bcpkix 1.86、EdDSA、slf4j、测试用 mina-sshd-core 2.14.0 全部经本机 Maven 镜像实测 HTTP 200 可拉取，并已锁定进 Version Catalog。
- **新模块 `core:ssh`**：
  - `Fingerprint`：OpenSSH 风格 SHA256 指纹（与 ssh-keygen 对齐，含固定测试向量比对）。
  - `CommandRisk`：命令风险分级（只读/一般/高风险；sudo 与破坏性模式必为高风险，高风险须二次确认）。
  - `Redact`：日志/审计脱敏（显式机密替换 + password=/Bearer/PEM 私钥块兜底）。
  - `SshTransport` / `SshSession`：连接、TOFU 主机密钥校验（首次回调确认、已存自动比对、变更以 Security 错误拦截并拒绝）、密码/私钥认证、`probeFingerprint` 预检、exec 单次执行**绝不重试**、IO 线程执行、完整 BC 注册。
  - `HostKeyStore` 接口由数据层实现（AppContainer 已接线 Room 实现）。
- **数据库 v2 → v3**：ssh_hosts 扩展 groupName/tags/authType/note；新增 host_keys（TOFU 信任库，迁移时回填既有指纹）与 op_audit；MIGRATION_2_3 + schema 3.json 已生成并核对（6 表、ssh_hosts 11 字段）。
- **数据仓库** `ServerDataRepository`：主机档案 CRUD、信任库读写、审计追加（注释强制调用方先脱敏）。
- **构建适配**：App 打包排除 BC 三件套重复的 META-INF 文件；core:ssh 修正 API 33 的 ByteArrayOutputStream.toString 以兼容 minSdk 26。
